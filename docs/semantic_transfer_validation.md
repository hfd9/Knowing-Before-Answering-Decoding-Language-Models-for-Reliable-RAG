## 两种表达、四种语义关系

每底题固定问题、范围、五文档背景多重集和槽位，构造A近原文自然表达与B独立改写。每种表达包含：

| 条件 | 需要独立检查的关系 |
| --- | --- |
| S完整一致支持 | 必要实体/关系/时间/事件前提齐全，可支持完整答案 |
| K兼容支持 | 互补、宽窄或不同兼容属性共同支持完整答案，作为充分条件的假冲突负对照 |
| I缺必要前提 | 移去一个关键支持关系，背景不得残留该依据，也不增加真实相关矛盾 |
| C真实相关冲突 | 同目标/事件/时间/属性的互斥主张，不能被其他文档、范围差别、明确纠正或来源优先级消解 |

总预算严格为30×2×4=240单元；无额外措辞候选、无源底题替换。语义不变的A/B配对测表达迁移；同表达内S/I/C近邻测支持关系敏感性；K单列检验兼容事实误报。必要唯一性应源于问题关系并在各条件中一致，不能为制造矛盾随意缩窄题意。记录所有编辑与token差，不为凑等长删除必要事实。

每个材料须在GPU之前由两位未接触AGENTS/历史/作者标签/probe结果的输入评审检查；分歧/不可构造保留unknown或incomplete，不按作者条件自动赋金标准，不看结果补题。当前40的背景暴露补评不满足这一门槛。材料不足就记录覆盖不足，不扩网格追求成功。

## 旧probe与必要时语义重训分开

旧probe固定现有chat L28的scaler和router，不改层、校准和阈值。主评估为semantic_eval12底题×8变体=96输入；6开发底题48输入只用于预设训练触发，训练分区96输入仅作开发诊断。旧probe和语义重训probe结果分别保留。

候选层只有[28]，超参数组合1组，新增训练最多1次。触发只看开发分区：旧probe宏F1<0.75，或S/K→conflict率>0.20，或A/B标签一致率<0.80；语义确定覆盖<0.90不能宣布通过。数值是本轮预设操作门槛，不是通用标准或原分类基线新资格门槛，不改旧no_qualified_baseline。

若触发且语义标签质量门槛满足，使用12训练底题的A表达×4条件，最多48条独立复核标签，StandardScaler与LogisticRegression仅拟合这些训练数据。固定C=1、class_weight=balanced、lbfgs、max_iter=2000、seed42，不校准、不扫描层/参数、不二次拟合。训练B表达不参与拟合；缺类或标签不足则记录无法训练，不扩容。小训练集的高方差必须披露。

评估输出揭示前，封存旧probe设置与可选新probe哈希。评估A、B分别报告，B是新表达家族；不根据评估结果改设置。主指标含语义覆盖、确定标签分母下Accuracy/MacroF1/混淆矩阵、S与K假冲突率、A/B同语义类别一致率及双侧均正确率、同表达S→I/C双侧均正确转换率、三概率/token差。仅类别不变可能是稳定地错，不能单独证明可靠。按底题bootstrap10000次，分母12底题，变体不作独立样本。

## 行为独立评估与停止规则

最多240条chat自由回答，greedy128、旧指令、无probe反馈；实际实现、tokenizer检查和耗时须在材料冻结后完成，长期GPU仍由用户启动。本轮未启动。

行为评审另看问题/文档/实际回答，隐藏probe、输入评审标签和旧评分。主评估分区分别报告全部语义不足作答、全部真实冲突选边及无消解选边、S/K有据正确回答与错误不足拒答；D式无关编辑不额外扩网格。训练/开发行为另列。probe条件率只作次要描述，不以命中筛选主样本；现有1/2继续只作小分母描述。未知保持完整分母与识别上下界，输入语义归属未知另报覆盖和可能影响。

| 后续结果 | 允许推进的方向 |
| --- | --- |
| 旧probe失效，一次语义重训后跨底题/表达泛化 | 用可靠测量重新检验信号与行为关系 |
| 语义probe仍不稳定，但行为失配稳定 | 保留行为研究，收缩“内部已识别”论述 |
| 语义测量与行为失配均稳定，且近邻差异明确 | 再单独冻结有限因果干预及控制，不自动patching |

独立确认、稳定规律及相对既有工作的具体增量仍待证明。此设计不是可发表贡献已成立的声明。达到构造/拟合预算后停止本轮，不因未成功再加表达、层或训练。380保留题不动。
