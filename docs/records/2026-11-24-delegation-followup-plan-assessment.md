# 2026-11-24 授权方向后续诊断、留出与投稿计划评价

日期按 Asia/Shanghai。用户询问后续计划是否合理，本轮完成评价。

## 32 格 CPU 诊断

建议在已知失败的八个新措辞上，对同一题面的 `grant` 和 `exception` 做 2×2 替换，分别运行原解析、仅替换 F1、仅替换 R3、两侧替换。只使用已封存的逐世界作者参照补字段，固定原文、`solve(records, structure)`、计分与证据口径。现有回放已验证完整参照结构和逐世界结果、证据一致；新诊断的增量主要是把单侧恢复和两侧共同依赖逐题列出。按仅缺 F1、仅缺 R3、同时缺两侧各 2、2、4 条报告，保留结构、逐世界适用性、规则、答案和证据及合并标签。两侧恢复时优先改输入解析；两侧仍失配时定位字段接口、证据计分、逐世界求值或合并逻辑的首个分歧。此轮四个底题用于故障定位。[冻结措辞检验](2026-11-23-delegation-new-wording.md) · [回放代码](../review/2026-11-23-delegation-new-wording-v1/check.py)

## 独立留出与消融

整组留出底题及 F1/R3 措辞族，保留同题方向、措辞配对，保障唯一准入、唯一不准入、明确异答与未决边界的覆盖。冻结提示、解析器、输出合法性、补字段触发、核验判断及去留口径后再看留出结果。参照应在看输出前由另一评审逐世界核对并封存；条件不足时，如实使用独立留出、知情作者参照的表述。既有八条全部进入开发诊断。强直接先在开发集走通输出接口，留出的格式失败单列且计入全量分母。[上轮配对材料](../review/2026-11-23-rule-applicability-paired-v1/README.md) · [上轮直接路线结果](2026-11-23-rule-applicability-live-results.md)

四条路线共用题面、证据口径、计分和预定调用预算。结构化路线共用求值器。选择性补字段触发只使用推理时可见的缺失、非法或原文核验冲突，预定何时调用、合并及返回未解决。全量抽取与选择性补字段在相同模型设置下比较。按底题与措辞族报告严格正确有据配对增益、原本应返回 U/X 却给 Y/N、可判定题返回 X、技术无效，以及每题调用和输入输出 token。保留自然应返回 X 的正确处理，和可判定题被搁置的区分。提前写明最小收益、错误唯一答案容差和调用预算，报告配对不确定性，不把同底题版本视为独立样本。

方向核验消融复用同一批抽取结果，只切换核验。逐项记录关闭时错误唯一到开启时正确解决或未解决的变化，以及正确有据变未解决的代价。区分检测到角色反转、不一致和原文核验器未覆盖。现有核验会把未确认的 F1 一并置空，留出时如把所有置空均算成角色反转拦截，会夸大该机制的作用。[核验实现](../../scripts/query_determinacy_delegation_source.py)

## 投稿去留

若新底题及措辞族配对收益稳定，错误唯一答案和成本在预定容差内，且选择性补字段相对全量抽取提供有据覆盖或成本优势，可形成围绕同题双冲突来源和授权方向的完整 C 类目标候选稿。诊断单独成稿需要在独立材料上复现明确的失效模式和代价。更高目标优先补同题面强近邻对照及语义结构不同的第二类规则，再以更自然的材料及多模型验证外部有效性。Logic-LM 已有自然语言形式化、符号求解和反馈修复，NormWorlds-CF 已有求解器验证的规则世界与配对变体，RuleArena 已有真实场景规则推理。比较应落到同题并呈冲突来源、授权方向核验及选择性补字段的具体增量。CCF 类别用于选择投稿目标，适用会议的正式长文要求按当前目录核对。 [Logic-LM](https://aclanthology.org/2023.findings-emnlp.248/) · [NormWorlds-CF](https://arxiv.org/abs/2607.03957) · [RuleArena](https://aclanthology.org/2025.acl-long.27/) · [CCF 第七版正式目录](https://www.ccf.org.cn/Academic_Evaluation/By_category/2026-03-31/870181.shtml)
