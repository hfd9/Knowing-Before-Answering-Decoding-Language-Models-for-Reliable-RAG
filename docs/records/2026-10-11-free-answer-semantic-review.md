## 结果与解释边界

以下均为本次 LLM 首轮语义标注下的诊断结果。unknown 保留完整分母，区间为未知项全部取 no/yes 的识别上下界，
不是置信区间；标注完整的指标另外提供按底题 bootstrap 的 95% 区间。

| 指标 | plain | chat |
| --- | --- | --- |
| 全部真实缺证的实质作答率 | 15/100 = 15.00% | 21 确认 / 100，1 未知；21.00%–22.00% |
| 真实缺证且探针判缺证后仍作答 N_RRA/N_RR | 8/80 = 10.00% | 12/82 = 14.63% |
| 上述“判缺证后仍作答”占全部缺证 N_RRA/N_R | 8/100 = 8.00% | 12/100 = 12.00% |
| 真实缺证但探针未判缺证的作答率 | 7/20 = 35.00% | 9 确认 / 18，1 未知；50.00%–55.56% |
| 全部真实冲突的单一答案选择率 | 67 确认 / 100，14 未知；67.00%–81.00% | 79 确认 / 100，4 未知；79.00%–83.00% |
| 真实冲突且探针判冲突后的选择率 | 57 确认 / 86，12 未知；66.28%–80.23% | 72 确认 / 88，4 未知；81.82%–86.36% |
| 真实冲突的明确冲突报告率 | 26 确认 / 100，4 未知；26.00%–30.00% | 12/100 = 12.00% |
| 真实充分的实质作答率 | 78/100 = 78.00% | 82/100 = 82.00% |
| 真实充分的有据正确回答率 | 59 确认 / 100，10 未知；59.00%–69.00% | 62 确认 / 100，9 未知；62.00%–71.00% |
| 真实充分但明确以信息不足为由不作答 | 22/100 = 22.00% | 18/100 = 18.00% |

N_RRA/N_RR 的底题 bootstrap 95% 区间分别为 [3.85%, 17.07%] 和 [7.32%, 22.78%]。
补充按相同 original_id 配对重采样、分别重算两种格式的条件分母：chat−plain 差 +4.63 个百分点，
95% 区间 [−3.45, +12.73] 个百分点，10,000 次、seed=42，跨零。
全部缺证作答率 chat−plain 的未知项识别上下界为 [+6, +7] 个百分点，不能当作统计显著性区间。
现有报告的 paired_behavior_differences 为空，是因为两项预定配对指标有 unknown，未强行填补或删除未知样本。

首要问题已有明确计数：在当前样本中，生成前探针判缺证后，模型仍有实质作答，plain 8 条、chat 12 条。
探针未判缺证组的作答比例更高，但这是关联，不能据此说模型“知道却故意忽略”，也未进行因果干预。
充分证据组仍存在 22/18 条不作答，评价可靠性时须同时关注回答机会损失。

必须保留的限制：

- 标注覆盖完成不等于所有字段确定；分析脚本按任一字段 unknown 仍输出 `pending_or_ambiguous`，
  plain 103 条、chat 96 条。这些是已审核但未能确定的项，不是漏读或未保存。
- 本次单一 LLM 判断没有独立人工复核。文档辅助阅读使用片段/差异，部分案例读全文；
  正确性判断尤其需要后续独立复核，不能将有据正确回答率当作人工核验准确率。
- plain 154/300、chat 1/300 触及 128-token 上限且未 EOS；可见完整答案仍算作答，
  截断影响最终承诺或冲突说明的项保留 unknown。行为差异可能受输出长度和模板影响。
- `conflict` 是发布数据的证据配置标签，不等于每个改写都在语义上互斥。
  审核中发现 singer/musician 等兼容改写和不改变主要答案的措辞变体；
  因此不能把全部 conflict 类选答统一解释为无视明确矛盾，应另行审计证据配置质量。
- 本轮测试已用于诊断，剩余 380 个测试底题须在设置冻结后用于确认；本次没有新 GPU 或确认集结果。
