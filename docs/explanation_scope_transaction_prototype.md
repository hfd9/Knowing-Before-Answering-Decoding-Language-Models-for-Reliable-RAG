# 解释行为采集事务：仅供合成数据的文件原型

日期：2026-11-06，Asia/Shanghai。状态：**临时目录中的真实文件事务原型及CPU测试完成**；不是模型采集器、真实缓存验证器、独立语义批准或GPU就绪协议。应用户要求，后续检查由助手继续，不要求用户逐条人工审核。

## 实现和边界

[原型](../scripts/explanation_scope_transaction_prototype.py)只能使用系统临时目录的已有子目录，绑定[候选执行预案](review/2026-11-06-explanation-scope-cpu-preflight-v1/execution-draft.json)及其来源哈希，初始化的manifest和记录都标记为synthetic。它没有命令行采集入口，不加载模型、tokenizer或probe；本轮测试只传入虚构文本、虚构token ID及虚构EOS声明，没有生成真实实验答案。synthetic标记本身不能识别数据是否来自真实模型。原型计算文本SHA，但**不验证token是否能解码为文本、不检查实际EOS、不核对真实输入prompt或权重指纹**。

在持有锁时才允许操作。原型使用非阻塞POSIX `flock`排斥协作进程；attempt标记使用独占创建、文件与目录`fsync`；合成记录先写同目录临时文件、`fsync`，再用`os.replace`替换并同步目录。未知文件、损坏数据、未提交标记、未完成临时文件或失败标记均阻止继续，保留原文件，不自动删除或重答。初始化只接受空目录，部分初始化也不会自动修复。

为避免中断后把旧attempt当成新生成机会，只有**在当前进程的当前持锁会话中创建该标记**，才能提交对应的合成记录；解锁、进程退出或fork后不会继承这一提交权限。前四个已提交合成记录需单独生成绑定记录摘要的技术smoke收据；空输出、无EOS或触顶会失败，不得进入第五条。代码只使用技术条件，不按语义结果筛选。手工插入第五个标记也不能绕过这一检查。达到48条合成记录后拒绝第49次attempt；账本状态始终返回collection_permitted=false、gpu_launch_ready=false。
