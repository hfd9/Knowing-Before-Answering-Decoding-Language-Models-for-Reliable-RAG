# 证据关系编辑、隐藏状态读出与回答行为：Qwen2.5-3B阶段研究报告

日期：2026-10-23（Asia/Shanghai）。性质：已完成的探索性研究汇总，包含两项行为对照及事后文本复核。实际独立语义批准为0；可靠语义测量和原机制假设尚未确立。

## 摘要

本阶段研究考察冻结语言模型的生成前线性读出能否迁移到证据语义任务，以及读出变化如何与回答行为对应。在30个底题、240个证据变体中，旧chat L28探针对不足和冲突编辑呈方向性概率响应，缺证后的实质作答减少，但仍有23/60缺证作答。对这些输出的文本审计发现多种关系或答案值问题，不能统一解释为实体误绑定或参数记忆。随后两项简单虚构绑定对照中，不足条件分别为0/24和0/36实质目标作答，未支持预期误绑定假设。原48输入的补充读出将全部24条不足输入判为Answer，而生成器正确保留未知；取消校准未修复这一判定。唯一一次作者参照重训减少部分误报，同时降低冲突召回，未确证跨底题可靠迁移。另有三条回答正确保留目标代码未知，却附加无据冲突解释，提示目标回答与解释主张需要分别测量。

全部语义结论受作者和历史暴露限制，三条解释案例仍待独立核验。本轮按既定上限结束，保留行为证据、测量失效与零事件对照，不进入patching，不恢复拟合预算，380个保留底题继续封存。本报告只整合已保存结果，没有新实验、评分或统计检验。

## 1. 研究问题与测量对象

研究模型为冻结的Qwen2.5-3B-Instruct。旧chat L28线性探针读取生成前提示末位置的隐藏状态，输出answer、refuse、conflict三类及其概率；层号从0编号。自由回答生成器没有接收probe预测作为反馈。后来拟合的新探针只改变保存状态的离线读出，没有重新生成回答。

本报告分别检验三个层次：

| 层次 | 需要回答的问题 | 能采用的证据 |
| --- | --- | --- |
| 连续读出响应 | 证据关系改变时，相应类别分数或概率是否改变？ | 同题证据变体的配对差及原已保存重采样区间。 |
| 语义类别有效性 | 冻结三分类是否可靠对应充分、不足、冲突？ | 输入语义参照、类别混淆、换表达和换底题表现。当前参照有作者暴露。 |
| 回答与解释行为 | 是否给目标答案、该答案有据吗、解释每项主张有据吗？ | 完整输出及文档支持关系。保留未知、目标答案正确和全文主张有据分别评估。 |

概率随编辑上升不能自动认证三分类；目标答案正确也不能认证整段解释。要进一步声称模型“内部已可靠识别但没有执行”，还需要可靠测量、题内预测关系及实际因果证据，本阶段尚未具备这些条件。

### 3.2 旧23条提供具体文本证据，来源机制仍未确定

23条来自13个底题，按原作者不足且原行为实质作答选取，未按细分结果更换样本。原审计保留三种互斥的表面文本模式：

## 4. 结论强度与研究限制

本阶段可保留三个结论。第一，旧材料中存在有具体文本对应的缺证作答现象，其形式多样并伴随语义边界。第二，两类简单绑定对照未支持预期误绑定假设，保留零事件结果，不扩展为自然泛化或总体零错误。第三，旧冻结probe对新输入有连续响应，但三分类尚不能作为可靠语义状态测量；原机制叙述的测量前提没有建立。

主要限制决定结论范围：

- **评审暴露。** 实际独立语义批准0，当前作者复核不能替代独立确认；技术核验也不能认证语义真值。
- **材料与独立单位。** 240变体只有30底题；96评估输入只有12底题；两个绑定任务分别只有12和6场景。变体、主张和重复读出不能当独立样本。
- **材料可判性。** 来源补充、关系修订、词义与分类推理、时间/范围和指代歧义都可能影响参照。unknown保留在完整分母或另列适用切片，不能自动记对、记错或清零。
- **跨任务混杂。** 简单虚构记录与旧材料多因素不同，不能从23/60对0/24或0/36直接识别长度、真实实体、参数记忆或绑定机制。
- **评估与选择。** 评估来源已见；55条审查包按问题选取，三条冲突解释是事后观察。它们均不是新的前瞻确认。
- **计算与因果。** 重放证明保存计算可复现；状态补读、离线换probe及生成文本本身没有识别某一语义表征对生成的因果作用。

因此本报告不声称可靠语义迁移、稳定题内预测优势、内部已知却不执行、参数记忆来源、机制定位或独立创新性已经成立，也不以已有方法流程复现冒充论文全部数值复现。
