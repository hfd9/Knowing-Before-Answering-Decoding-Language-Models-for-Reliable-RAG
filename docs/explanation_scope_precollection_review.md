## 1. 研究问题及旧证据

在目标字段没有记录支持时，其他实体同字段的互斥记录，是否使回答更常出现“有据保留目标未知、同时无据声称目标字段冲突”的联合行为？主比较为12对J(IU)−J(I0)，不是对旧三个案例的直接复现。旧的Q004/Q026/Q052均有更宽泛的无据冲突表述，但[知情裁定](assistant_adjudication_and_study_decision.md)对狭义E的判断依次为unknown/no/unknown；两条同底题，三个均事后选择，不能估计发生率。

旧作者判断155主张与单次CLI复评172主张由不同方式拆分；已有13个分歧回答的知情判断，16个关注或分歧回答的部分语义对应，未将其余39条对齐。CLI输入先封存及可见隔离轨迹支持一次实际复评，但完整私有上下文无法由此认证，接收状态的context_audit_pending和正式独立批准0不能被知情裁定替代。

本轮另读[原始暴露自述](review/2026-11-06-isolated-cli-review-v1/context_audit.json)、[协调者证据](review/2026-11-06-isolated-cli-review-v1/coordinator/context_assessment.json)、两阶段交付/封存及评审声明。支持隔离的可见证据包括：五类项目背景自述未见、第一阶段记录未交付回答及作者结果、输入SHA封存于02:44:42 UTC、第二阶段回答交付记录为02:46:03 UTC、协调者检查的29个已完成命令中未见已知项目路径或父目录引用。注意29是当时协调者报告，并非本轮重新逐条审计所有命令；上下文与命令自述不能证明未暴露的全部来源，工作目录也不构成操作系统级禁止访问。memory功能关闭的观察是在回答审核之后作出，不能倒称事前独立证明。候选审计的`can_proceed=false`经第一阶段文字澄清为等待独立任务与输入，不能静默改写原报告。

可见时间字段还有一个记录边界：第一阶段评审自述完成时间为02:41:08 UTC，而第一阶段交付记录的`recorded_at`为02:41:49 UTC；后者是协调者记录时间，文件未将其定义为实际交付时间，因此不能据此断言交付顺序错误，也不能用它证明具体交付时刻。审计判断应明确采用什么证据标准、由谁作正式裁定及怎样处理这些不可见或未精确记时的部分；既不能宣称绝对独立已认证，也不能因不能证明绝对独立而否认已有受限的隔离证据。

## 2. 本轮材料核对与仍需判断的语义

已直接读v2的共同指令与代表性四条件原文，并用不导入项目生成器的临时只读脚本解析48条的三个赋值、问题目标、字段和槽位。12场景×四条件均符合下表；12对I0/IU各恰有一个文档槽文本不同。这里是对固定英语模板的结构检查，不是逐条独立自然语言审核。

| 条件 | 目标字段记录 | 记录内冲突 | 助手对固定模板的知情判断 |
| --- | --- | --- | --- |
| S | 一条赋值 | 无 | 有一条记录支持目标值；记录可能有误，不能证明世界真值。 |
| I0 | 无 | 无 | 不同目标值均与所给赋值兼容。 |
| IU | 无 | 另一单位、同目标字段的两值互斥 | 任何一个局部修复都不提供目标字段值；不可声称所有记录同时为真。 |
| CT | 两条不同赋值 | 目标单位、目标字段冲突 | 无优先级时不能仅凭记录选一边；识别冲突与是否选边分别评分。 |

本轮重跑原材料生成器verify、独立文本/见证/tokenizer验证和有限域审计，分别为exit0；48条均287 tokens，12对token长度与多重集一致。独立文本验证与有限域审计仍共享部分既有材料和假设，不是自然语言金标准。另以独立临时解析检查的槽位为：exs01–12依次3、2、1、5、4、3、2、1、5、4、3、2。每个场景仅为相同模板下的符号变体；token多重集相同不代表顺序相同，也不排除字段位置或措辞等局部因素。

材料强调记录可能分歧、没有来源优先级，但没有提供各记录可靠性的进一步证据。因此S的“有据”只表示所给记录支持；如果要求证明真实世界唯一值，S也不成立。此区别是研究要保留的操作口径，不可由有限域穷举消解。模型把IU解释成“所有记录必须同时为真，因此系统整体矛盾”也可能反映对记录语义的不同理解；遇到实际回答必须按全文判断，不能用关键词把它自动计成目标字段冲突。

## 3. 预定评分和假想边界

原[评分契约](explanation_scope_scoring_contract.md)不变。I0/IU的W是“未给未撤回目标值并明确承认目标字段不能由记录确定”；E是“明确无据断言所问目标字段或答案有互斥证据”。逐主张记录原文、所指实体与字段、文档依据和支持判断，再填汇总表。没有解释、广义解释支持与W/E分别保存。

| 假想回答，非真实模型输出 | W | E | 边界 |
| --- | --- | --- | --- |
| “目标字段无法确定。” | yes | no | 没有实质解释另计，不能证明解释能力。 |
| IU：“另一单位的同字段有冲突；目标字段没记录。” | yes | no | 正确报告其他实体冲突。 |
| “目标字段有两条相互矛盾的记录，因此无法确定。” | yes | yes | 在I0/IU中明确捏造目标字段冲突。 |
| “记录有冲突，所以不能回答。”，全文范围和理由指代仍不清 | unknown | unknown | 不推断冲突所指或目标缺口处理。 |
| “目标值为a，虽然记录没有足够信息。” | no | no | 仍给出具体值；没有冲突断言。 |

J=W且E；一个no即J=no、两个yes才J=yes，其余unknown。所有12场景配对保留，不能先按W=yes筛选主分析。影响J的unknown使主点估计null，另报识别界，识别界不是置信区间；未审null与已审unknown分开。S的有据回答、CT的目标冲突识别及无依据选边、W/E各自分布、解释缺席及整段支持另报。12对同模板，单个条件的1例相当于1/12，不能当总体发生率；无新增显著性检验或bootstrap。

## 4. 近邻文献逐项比较

本节是定向阅读论文方法、任务与指标，不是系统综述，也没有逐例扫描外部完整数据集。不能据论文示例未展示某组合就声称其数据不存在该组合。

| 研究 | 输入和任务 | 输出或机制端点 | 与本设计的关系 |
| --- | --- | --- | --- |
| [Hidden Commitment，arXiv v2](https://arxiv.org/html/2610.38296v2) | FaithEval同一目标槽位的两篇文档给出互斥答案；用文档顺序交换、闭卷及同意/单文档对照。 | 关注选用哪一来源、是否披露目标冲突，并用残差读出及激活干预分析来源选择。 | 与冲突披露和解释透明性紧邻，但论文主要设置有目标槽位冲突；本主对照是目标缺证、另一实体冲突，并评分虚假目标冲突断言。不能以本输出推断其内部来源选择机制。 |
| [ContextConflict，arXiv v1](https://arxiv.org/pdf/2609.03148v1) | 多领域、多种上下文冲突，涵盖推理和摘要，含显式与隐式冲突。 | 推理答案准确率、摘要的证据平衡，以及逐主张faithfulness；另分析表示和位置偏差。 | 已研究冲突下输出忠实度及证据范围，本设计的候选增量仅在于固定目标缺证、成对改变其他实体冲突，并将W和E联合测量；未逐条核对其数据，不能宣称其不含类似实例。 |
| [CONFLICTS，arXiv v2](https://arxiv.org/html/2506.08500v2) | 真实检索结果、问题相关内容的多类冲突，包含标注和期望回答。 | 冲突类型和回答是否符合所需行为。 | 同样要求区分问题相关与不相关内容；论文最终数据排除无相关来源的18项，但此事实不证明没有本项目的目标缺证/其他冲突组合。 |
| [Ragability，LREC 2026](https://aclanthology.org/2026.lrec-1.182/) | 虚构实体的模块化文档组合，比较冲突、非冲突及不足情形。 | 冲突识别、可答时作答和不可答时拒答；报告冲突提示也可能影响无冲突情况。 | 构造材料、缺证与误报均有明显近邻；仅根据论文示例不能排除相同局部结构或端点。 |

有潜力的定位是**对已提供记录中目标缺证与其他实体冲突的作用范围作精细配对，并同时评估目标未知和冲突归属**。这是待取得数据并扩大文献核查后才能评价的候选增量；不是首创、自然分布发生率或内部冲突迁移的结论。
