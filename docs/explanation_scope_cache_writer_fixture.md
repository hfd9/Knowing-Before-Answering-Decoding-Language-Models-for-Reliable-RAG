# 解释行为：候选缓存格式的合成写入与输入连接

日期：2026-11-06。状态：候选磁盘格式的**临时目录合成事务**和未来生成输入的离线重建得到测试；没有真实模型采集器、非合成写入器或GPU启动入口。

[合成写入器](../scripts/explanation_scope_cache_writer_fixture.py)使用与[只读检查器](../scripts/explanation_scope_disk_cache.py)相同的attempt、记录及smoke文件格式，只允许系统临时目录下的已有子目录，按固定顺序写入合成token，前四项技术smoke合格后才能继续。完整48项可以通过只读检查并连接空评分包，其中空或截断输出保留技术状态。清单增加 `synthetic_fixture_only: true`，只读检查结果会显示该标记；无该字段的候选清单不等于证实来自模型，检查器始终给出 `output_origin_verified: false`。标记是声明而非防篡改的来源证明，也不能让不可信数据自动变为真实数据。

非阻塞排他锁需为普通文件，每次操作检查当前锁路径仍指向已持有的锁inode；发现替换、未知文件、软链接、格式损坏、未提交attempt等情况即停止。记录替换使用同目录临时文件、文件和目录fsync。当前进程当前持锁会话才能提交本会话创建的attempt；锁会话内一旦文件事务异常，后续操作停止，释放锁后只能重新检查实际可见状态，不自动补答。已提交完整前缀经重新校验后可继续；中断在attempt之后则保留标记并阻止继续。发生写入后但返回前的错误时，重新打开只能确认文件系统当前可见状态，不能证明断电持久性。锁仅协调遵循协议的进程，不是对恶意并发操作、文件系统故障或网络文件系统的安全认证。

[运行时](../scripts/explanation_scope_runtime.py)新增 `generation_input(item_id)`，重新渲染材料并核对问题/文档、prompt、token IDs哈希及长度，再返回候选prompt和token IDs。它不加载权重或调用生成；使用方仍须确保传给模型的输入确为已核对的ID及正确attention mask。未来真实运行还需要在实际执行时核验权重、设备与生成参数，记录和检查模型返回的token，使用真实写入/恢复实现，并重新验证整个路径。

合成和真实运行仍有明确缺口：本文件写入器的生产工厂受现有门禁阻止；不能把它改名或仅移除合成标记当作经过验证的生产采集器。无真实回答、真实run、语义评分或独立批准。formal_gate=false、gpu_launch_ready=false、拟合预算0、正式标签null和380题封存保持。
