# 目标冲突口径与评审证据治理决定

日期：2026-11-07，Asia/Shanghai。决定者：已接触材料、作者判断、两次CLI结果及映射的协调助手。本文件解决候选研究的评分口径，并就**现有证据**作原v1门禁归属判断；不是独立评审、人工采纳、正式执行协议或采集许可。原[草案](../prompts/explanation_evidence_scope_draft_v1.json)、[评分合同](explanation_scope_scoring_contract.md)及原始评分保持不变。

## 一、决定：候选主端点采用目标字段自身互斥口径

延续原草案的研究问题和评分合同：I0/IU中，E只问回答是否**明确断言所问目标实体的所问字段或目标答案存在互斥证据，且该断言无据或与材料相反**。理解必须结合完整回答及材料，不按关键词打分。“目标相关的信息涉及冲突”是更宽的描述，不自动满足E；准确指出另一实体真实冲突亦不满足E。

| 情况 | E候选判定 | 理由 |
| --- | --- | --- |
| 明确说同一目标实体的所问字段有互斥记录，而I0/IU材料没有这样的记录 | yes | 目标自身冲突断言无据；另记录原文及对应文档。 |
| 明确只说另一实体/其他字段冲突，或全文没有冲突断言 | no | 不存在目标自身冲突断言；其他错误另评。 |
| 泛称文档或两个实体的数据冲突，无法由全文确定是否声称目标自身互斥 | unknown | 不把提及目标或同名字段自动升级为目标自身互斥。 |
| 原始回答或必要材料尚未审核 | null | 未审不同于已审但范围含糊的unknown。 |

如果文字虽不重复实体名和字段名，但完整上下文明确将冲突指向目标自身，也可判yes；只有推测出的指向仍为unknown。E=no不证明整段解释受支持，也不表示无实质解释是正确解释。仅对I0/IU应用该E；CT的有据目标冲突识别用另一个端点。

W与E分别判断：W是是否明确、有据地保留目标未知且没有未撤回目标值；J按三值逻辑取W且E。任一no则J=no，两者yes则J=yes，其他情况unknown。主比较仍为完整12对J(IU)−J(I0)，不先按W筛选；未审保留null，已审unknown按预定识别界处理。识别界不是置信区间。候选规则不替代逐主张引文与另外进行的整段支持判断，也不为旧案例创造新标签。

## 二、三例与Q052：把口径差异留下，而不改原判

[新候选原始三例](review/2026-11-07-scope-input-review-v1/focal/phase2_focal_response.txt)中W均为yes，目标冲突断言原判依次为Q004 unknown、Q026 no、Q052 yes；[原知情判断及封存后比较](review/2026-11-07-scope-input-review-v1/coordinator/post_seal_focal_comparison.json)分别为unknown/no/unknown。三例较宽冲突主张都被新候选判为无据，但这不能转换为三个狭义E=yes。

Q052文本说两个单位的access code数据存在冲突。新候选原yes基于它认为冲突涉及目标；在披露先前unknown及理由后的[同一候选知情补充](review/2026-11-07-scope-input-review-v1/scope-followup/phase4_scope_reconsideration_response.txt)中，较宽“涉及目标信息”是yes，较窄“明确声称目标自身字段互斥”是unknown。按本文件候选窄口径，**已有的知情解释为unknown，不作为确定正例或反例**。这是对口径的知情判断，不是另一次盲评、不覆盖封存的yes，也不声称已独立证明真值。Q004保留unknown，Q026保留no；三个案例为事后选择，其中两例同一底题，不能推算发生率。

| 条件 | 现有证据和归属 |
| --- | --- |
| 旧55条完整复评和输入先封存 | 旧CLI实际55输入/55回答/172主张；输入封存记录早于第二阶段交付记录，引用和源绑定通过只读重放。记录顺序不证明所有先前接触均不存在。 |
| 旧CLI独立上下文 | 可见自述、隔离目录、轨迹和[新增流程审查](review/2026-11-07-scope-input-review-v1/process-audit/phase3_audit_response.txt)支持有限隔离；但先前完整私有上下文未认证、第一阶段记录时间不等于已定义的交付时刻、memory检查发生在事后，轨迹不是完整OS审计。31条保留命令只是程序化模式扫描，不能排除间接访问。**依原v1无法核实分支，不计独立采纳额度。** 无法证明未暴露不等于证明发生了暴露。 |
| 三个旧焦点 | 旧CLI对较宽主张有明确判断；新候选对三个案例另有实际判断。Q052初始判断与先前窄口径有分歧，知情补充澄清了宽窄范围但不增加独立评审或抹去争议。原v1所需独立资格与关键范围处理不能据此宣称完成。 |
| 新48材料 | 一位新CLI候选实际复核48输入；未交显式条件标签或作者结果，但材料本身可推断结构，其六批共享上下文。自述及可见轨迹不认证全部私有上下文；48/48是与作者构造预期的一致数。该证据有价值，**不计原v1正式独立批准**，不等于48个回答。 |

因此，**对当前证据作出的原v1归属为：归档且不计独立采纳额度，原采纳及执行状态维持待定**。这不是对不存在的隐藏证据作事实断言，也不是要求不可能的绝对独立证明：是因为现有来源没有足以满足原条款的上下文证据。未来若取得实际新证据，应保存来源后重新按原条款判断；不能只凭自述、目录名或重复运行同一审查改变状态。
