## 1. 来源条款：收缩为不保存正文的研究核查

直接读取此前固定提交的FaithEval数据卡：[不足I](https://huggingface.co/datasets/Salesforce/FaithEval-unanswerable-v1.0/resolve/4a14e0e9860e270a8c9ff57c511821f4f50dce57/README.md)、[冲突C](https://huggingface.co/datasets/Salesforce/FaithEval-inconsistent-v1.0/resolve/e29508db3955db2c82a80a1f3c3aadc11f93fc3f/README.md)。两卡均称该发布用于论文研究，但未见明确的独立数据许可标识；[项目代码Apache-2.0](https://github.com/SalesforceAIResearch/FaithEval)不能替代数据及上游文本条款。就上游，[DROP作者材料](https://github.com/allenai/allennlp-website/blob/master/drop.html)列CC BY-SA 4.0，[BioASQ数据页](https://participants-area.bioasq.org/datasets/)列CC BY 2.5及相关来源条件，[RACE发布页](https://www.cs.cmu.edu/~glai1/data/race/)列非商业研究限制，[NewsQA原仓库](https://github.com/Maluuba/newsqa)说明CNN内容权利。各原许可不自动证明FaithEval/MRQA的每项派生文本享有同样的再发布权。

**本轮收缩决策：**只在研究核查中内存读取候选上下文做不带身份的统计，不保存或公开候选正文、答案、ID、逐题标记，也不构造实验输入。是否能保存、改写、公开和分发未来最终数据，当前仍未核实，不能称整条许可链已解决；不向任何人发送消息。若实际用途超出目前可核实的研究范围、无法取得适用条款或来源映射，则停止该来源，不以更换目录绕过。

## 2. 已用材料的问题与文档碰撞

此前[问题聚合](../2026-11-09-faitheval-feasibility-followup-v1/README.md)在785个同qid/同subset的I/C记录中发现1个候选问题与旧训练规范化一致；其余未检出不能证明无碰撞。本轮继续检查上下文，固定相同的I/C版本和785个严格连接，使用已用的旧训练200、验证95、诊断100底题及30题v5材料为参照。旧数据manifest、样本文件及v5材料SHA核实；**不读取原始测试归档或380题正文**。

[筛查脚本](../../../scripts/faith_eval_document_overlap_20261109.py)只在内存读取候选`qid`、`subset`、`context`：先解码I的2,492行和C的1,500行，再限定为785个连接做比较；没有解析问题/答案或保存候选文本、ID、逐题结果。远程Parquet范围可能包含邻近字节，未完整重算原文件SHA。所有文本只用于三种事先写定的机械筛查：NFKC/casefold/Unicode词元后，至少16词的整段相等或完整包含，以及两侧各至少9个不同8词连续片段时、交集占较小片段集合至少80%的线索。所有命中都只表示待审可能性，不自动判定相同底题或来源。

### 380封存题：只检查了现有编号索引

历史文件`runs/qwen2.5-3b-classification-grid/audit.json`已有380个保留底题的本地`original_id`清单；本轮读取该**已有编号索引**及其哈希，不读取380个问题/文档。380个本地编号全部是`test_数字`，本次785个FaithEval `qid`全为32位十六进制字符串；原样字符串交集为0只是两套不同命名空间的结果，**不是底题、文档或语义无碰撞的证据**。若无既有可用的跨命名空间映射或经允许的指纹，380相关碰撞仍为unknown，不能以0冒称查清。
