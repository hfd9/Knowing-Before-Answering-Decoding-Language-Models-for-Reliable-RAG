# 等值表达与引用充分性：开发修订草案

这是查看 7B 输出后的修订草案；不能追溯称为运行前冻结评分，也不得直接据此重新定义本轮指标。下一批新规则选择前，须在开发材料上演练、记录更改并冻结。

## 等值与严格比较

题目问“是否超过”，规则是严格大于。回答给出数值 A、阈值 T 后：明确写 A 大于 T 则该分支为 Y；明确写 A 等于或小于 T 则为 N，前提是回答没有其他互相矛盾的分支结论。“不超过”“等于门槛所以未超过”亦可判 N。如果仅写“meet the guideline”而不能确定其意为数值相等还是满足 SGA 判定，标 unknown；若明确写 “$1,620 meet ... $1,620”，可记录数值比较为等于、并单列最终法律／任务结论是否明确，不能把这两项合并。按字面可计算等值并不证明系统最终无歧义回答。

SSA D 逐版在新日提供相同金额和门槛，称 meet 并表示依日期而异：**数值等值 yes；明确说未超过 no；语义是否传达新日 N 暂 unknown**。如果后续在开发评分手册中决定允许由明确等值推导 N，应设为预先定义的宽松口径并让另一评审核验；同时保留明确任务答案及潜在歧义，以免事后选择有利口径。

## 引用的两个评价层次

1. 机械引用：可核对引用标识是否出现、是否存在、与原有精确 ID 集合是否一致；不据此自动认定语义支持。数字、版本、比较规则和范围分别列出需要支持的命题。
2. 语义充分性：对每个实际主张检查引用所指原文是否支持日期、门槛、比较方向和适用范围，以及必要事实是否来自题面。证据可跨句组合，但不自动把全文任意一处的无关引用绑定到所有版本。可判为充分／不充分／unknown，附命题、原文及理由；题面事实可直接引用 F1，若说明书允许不显式标 F1，须在新规则冻结前说明。

本轮赠与直接两题明确引用两个版本门槛，未引用比较规则与范围；按旧的要求四个角色全列的严格 ID 口径不完整。语义上用户可在同一证据包看到其他文本，但输出自身是否充分引用，不能因为相关原文存在就自动通过。独立盲评尚未实施。

## 第二轮设计约束

如果首轮追问了具体相关日期，第二轮保留该路线同一条第一轮原输出，只向该会话补充预设的一个具体日期；每个候选日期可分别作为独立分支，不能把两个后续分支串成一段对话。若第一轮已经给出条件式答案且未追问，不要把模拟的补日期当作自然发生的追问结果；可单列“主动补充日期的压力测试”，分母和问题不同。若第一轮给错误唯一答案且未追问，同样不能放入“追问后正确率”。具体后续用户消息、适用日期、原始 token 和路线映射应提前固定，避免依据回答正确性选回复。
