# 目标冲突与非目标冲突：符号可满足性及新增近邻

2026-11-12，Asia/Shanghai。用户要求持续推进至可固定的研究选题。本轮在既有门禁内完成三实体穷举和定向文献核查；这解决了一个结构可行性问题，但不把尚未满足的参照、资源及研究增量写成已经通过。

## 新结果：两个冲突实体数相同，目标是否冲突可以不同

假设A、B、C为不同实体，x、y、z为不同值，每篇文档对三个实体各赋一个值且三值各出现一次；两篇独立文档讨论相同时间和字段、无来源优先，目标问题固定询问A。文档1固定 A→x、B→y、C→z。三条件的文档2如下：

| 条件 | 文档2 | 冲突实体 | 对A的目标状态 |
| --- | --- | --- | --- |
| 无冲突 | A→x、B→y、C→z | 无 | 充分，x |
| 仅非目标冲突 | A→x、B→z、C→y | B、C | 若只以A相关证据裁定，充分，x |
| 目标冲突 | A→y、B→x、C→z | A、B | A的x/y冲突 |

三个条件两篇文档的**逐文档无序符号词袋均为A/B/C/x/y各一次**；问题和文档1固定。后两条件各有两个冲突实体，故严格只依赖这些词袋和冲突实体数量的函数不能区分“目标冲突”和“仅非目标冲突”；目标相关判断则需要区分。但目标冲突仍伴随另一实体冲突，并没有解决“只有目标实体冲突”。前一[二实体枚举](../2026-11-12-binding-value-feasibility-v1/README.md)的结论也没有被推翻。

[enumerate.py](enumerate.py) 用标准库穷举文档2六个排列与三个目标，共18个符号行：无冲突3、非目标冲突2实体3、目标冲突2实体6、目标冲突3实体6。每个目标的两冲突实体目标条件有2排列、非目标条件有1排列；不能当成均衡的18个独立底题。脚本实际 `python3 -B .../enumerate.py` 退出0，检查关系集合和逐文档词袋；它不是对自然语言的独立语义评审、真实tokenizer测试或模型实验。

## 实际可测的区别和剩余难点

- **目标相关性与全局冲突是不同定义。** 若任务要求只依据A相关证据，非目标冲突条件可回答x；若任务要求报告文档包中任何冲突，则该条件标为冲突也可能合理。[KBA v1 §2](https://arxiv.org/html/2608.27661v1)将Answer描述为对问题只有一个有依据答案、Conflict描述为对问题有多个有依据答案；这支持以问题为中心的候选解释。但原构造并未在所查段落单列“其他对象冲突而目标唯一”，论文表述不能替代对新材料的明确约定与审核，也不能证明旧probe的训练覆盖了这种情况。
- 在符号模型上，目标条件与非目标条件的文档2存在不同配对和顺序；以实体和值的邻接或固定位置写出的规则可以区分，不必使用抽象语义。因此，即便旧probe未来输出不同，也不能据此定位内部绑定机制。非目标是否 truly 不相关还依赖领域规则，例如不同对象是否必须采用不同值；自然语言必须明确排除这样的隐含约束。
- 对同一文档和不同目标提问，可直接保持证据完全相同，但问题文字改变，且目标位置、词频和实体名称可能成为线索；可用多目标平衡并单列问题变化效应，不能宣称单因素机制。无冲突相对另外两条件在完整文档重复和冲突数量上不同；两个冲突条件才匹配冲突实体数。
- 一个明确的、无需拟合的关系查表规则在本符号世界可以准确识别目标是否跨文档改变；它是有用的可解释上界，但并非证明自然语言简单基线同样有效。任何学习基线或阈值选择需新预算与数据隔离，原拟合预算仍为0。

## 更直接的近邻：RINSE

[Chen 等，RINSE，arXiv:2609.37469v1](https://arxiv.org/html/2609.37469v1) 已经研究**生成前**证据充分性，使用替换、删除、固定证据的问题交换形成配对，审核问题覆盖、词项、问题单独及证据单独线索，并用底题组内排序和组级bootstrap。其潜在读出使用冻结Qwen2.5-1.5B、末token第17层及训练集估计方向；不能把“生成前Qwen隐藏状态”“配对与线索审计”本身称为新贡献。论文报告的是充分/不足排序与组合评分，本轮所读部分并非本项目的目标冲突／非目标冲突三分类；未完整审计代码或排除等价实验。

原文表2报告在HotpotQA加入共享文档后，一项覆盖率线索接近机会水平，但只看证据的分类器仍可用其他差异；这说明匹配一个线索不代表排除全部伪迹。以上是论文作者结果，本轮未复现。其基线/方向与校正涉及训练，不能在原拟合预算0条件下直接照搬。

## 选题判断和真实停止点

可保留的候选问题是：**对预先确定的、面向问题目标的证据状态定义，固定读出是否能区分目标冲突和仅非目标冲突，同时不把证据足够但其他对象冲突的情形混为目标冲突？** 它有明确用途及可证伪预测，且本轮证明一个限定符号结构可生成竞争条件；不是已证实有论文创新的完整选题。

将其完全固定并开展确认，仍需：明确新材料中非目标冲突的预定用途和语义裁定；扩大近邻排查并证明区别有实际价值；构造合法、未暴露且经独立审核的自然语言材料；确认多个简单替代规则、状态和变换的可识别性；落实评审者、覆盖/unknown、容差及资源。KBA的按问题标签说明是积极证据，但不认证新材料。不能仅通过符号枚举宣布通过，也不能将尚未运行的旧probe判定为失败。

本轮无确认底题构造、评审、模型前向、GPU、拟合、阈值搜索、patching或380正文访问。原v1/E1-r1门禁false、正式独立批准0、标签null、拟合预算0，380正文封存；必要GPU由用户执行。
