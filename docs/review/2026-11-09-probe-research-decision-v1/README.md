## 可证伪的收窄问题

**在预先限定的五文档问答范围内，对同一底题及相同目标事实，旧chat L28冻结三分类读出能否同时满足：对经可审计语义参照判定的充分、缺证、目标冲突作正确区分，并在经审核保持证据关系的表达改变下维持判定？** 与仅测标签翻转不同，需要分别报告稳定但两端都不符合参照的情况；同题S→I/C是关系变化，表达A→B应经参照审核，不可预先当作等价。

研究对象是特定模型/提示/旧probe及规定输入分布，不是所有模型或隐藏状态。候选主端点应以**底题为统计单位**：各状态两表达均符合参照的底题比例，并分开给出S/I/C各条件单端混淆矩阵、同题双端符合/一端/均不符合、unknown与失效分母；配对区间应以底题重采样或其他事先确定的方法计算，不把同题变体当独立。连续分数及S→I/C方向变化只作为预先界定的次端点，不能用它事后换阈值。对于拟议使用场景，应在看新确认数据前单独预定每类最低可接受表现、配对稳定性的容差、信心区间要求、样本量/有效参照覆盖率及停止规则；目前没有依据选择可信的数值门槛，也不能用旧结果反推门槛。

可反驳的例子：若预定的类别正确性或表达稳定性未达到预定下限，则该固定配置在该预定范围的测量用途不成立；即使达标也只支持该范围和参照下的表现。若两表达稳定但均不符合参照，不能称语义测量成功。负结果不证明所有读出或隐藏状态无信息；拟合新的probe也不能用于证明旧probe已可靠。

## 原论文和近邻：已覆盖什么、剩下什么

以下是定向核查，非穷尽性综述；“未见”表示在所列章节未发现，不代表全文或代码不存在。版本与章节均可直接追溯。

1. **[Knowing Before Answering v1，§2.1、§5.2、附录G](https://arxiv.org/html/2608.27661v1)**：2,391底题各构造充分/缺证/冲突三例，问题级70/10/20拆分；缺证用非金文档，冲突用答案实体替换，自动核查及作者抽样检查不能等同每例独立语义审核。路由器训练后跨P0–P5测试：词汇小改较稳定，问题前置和格式/长度变化可影响结果。RAGTruth零样本转移是**二分类**，论文明确说没有三状态冲突标注；论文模型列表不包括本项目Qwen2.5-3B-Instruct。论文也有patching和表面控制。我们的候选差异是把同题的已审核语义关系和证据表达变化连接到同一冻结三状态读出的可靠性评估；不是首次三状态、同题构造、迁移或提示稳健性。原文已指出自然三状态标注缺口，故这最多是一个具体评测缺口，尚非已证明创新。
2. **[Err Knowingly v3，§3.2及附录B](https://arxiv.org/html/2508.18760v3)**：研究SUM等数学题的可答/不可答与拒答，按问题对训练/验证，分类器读取推理轨迹的注意力输出，逐层拟合、验证集选层；对轨迹概率聚合并与行为/干预相联。其命题和标签来自题目可解性，而本候选只研究给定RAG文档的生成前三状态，不能将其行为结论迁移到旧probe。论文已研究内外差异与probe监测，故不能把这类一般命题称为新贡献；已查章节未确认与本方案同样的跨表达三状态评估。
3. **[Hidden Commitment v2，附录B/C](https://arxiv.org/html/2610.38296v2)**：FaithEval冲突数据、Qwen 0.8B/Gemma 1B，拟合源选择及冲突披露方向；文档顺序交换、同文档一致、单文档和改写一致控制均已出现。源选择池按qid分128/32/340；披露标签使用LLM评审并审计、保留边界噪声。其主要读出目标是选源及披露，不是固定三状态RAG triage；但同题改写和冲突控制的通用设计已不是空白，候选必须具体说明与其控制及目标的不同。
4. **[ContextConflict v1，§2、§4、附录D.1](https://arxiv.org/html/2609.03148v1)**：5,781个推理/摘要样本，包含显式和隐式冲突；冲突版配对保留问题及背景，按类型筛改证据获得一致版。逐层拟合冲突/一致线性分类器，以五折分层交叉验证；文中列出样本级折数，但未清楚证明每对始终同折，不将它称为题级隔离。该研究已有语义不同难度、证据顺序及配对probe；其报告主要是二状态冲突意识而非本候选一个预先冻结的三状态读出。不能以“首次配对”“首次测表面/语义”作为差异。
5. **[Probing-RAG v2，§3](https://arxiv.org/html/2410.13339v2)**：Gemma-2B根据已生成的推理和答案状态判断是否再检索，训练标签来自答案正确性，26,060训练/500验证，跨多个QA数据集；关注自适应检索，而非生成前给定文档的充分/不足/冲突测量。两者任务、时点和标签不可互换；论文已说明probe可服务RAG决策。
6. **[Hewitt与Liang 2019，控制任务](https://aclanthology.org/D19-1275/)；[Hewitt等2021，条件探测](https://aclanthology.org/2021.emnlp-main.122/)**：前者用随机词类型标签测probe记忆与selectivity；后者研究超过指定基线的可用信息。随机标签控制不能直接证明语义有效，简单文本/长度/模板对照表现好也不能单独证明捷径因果；若未来对照需要拟合，须另外规定训练集、底题隔离、预算与授权，不把旧probe冻结误写为所有对照都无需拟合。

文献访问覆盖上述原始页面对应章节，未运行各论文代码或穷举其数据。尤其需要进一步验证公开数据是否能提供真实三状态、经一致审核且每个底题带表达变化的可用样本，及其授权/重叠/分组；当前资料不足以声称该组合尚无人做过，或对KBA的全部实现作完全审计。

## 去留与可行性决定

**保留有限的测量边界研究问题；暂停将其作为已确立的论文创新或启动新确认实验。** 具体潜在差异是“同一冻结三状态读出，在独立可审计参照的同题证据关系和表达变化上同时报告正确与稳定”，但关键部件分别已有强近邻，本次未证明组合新颖，且现有样本/评审不足以提供未暴露确认。候选不是测试隐藏状态是否有信息，也不是行为因果解释。

当前不能合理认定验证已可行：需要先定位未暴露于旧probe训练、选层、校准及本轮探索的合法底题来源；明确逐条可追溯的充分/不足/冲突及表达等价参照、相互独立评审是否可实现与unknown覆盖；确认合理最低表现、底题级样本量与预算；审查一个预先冻结或无需拟合的简单对照能否有意义。原380题仍封存，不能把它当可调用资源；现有作者与CLI判定也不能改称独立金标准。缺任何一项时应停止，不以新目录或新名称绕过。即使这些条件以后具备，还需另行审查差异的价值与计划。

因此根据既定条件，**本轮不写或放行候选实验协议，也不准备GPU命令**；上述端点和停止前提是问题定义与可行性判断，不是运行协议或执行授权。若未来用新的可审计来源与资源证明差异及可行性，再制定独立协议与必要审批；否则以现有受限负结果结束该研究分支。原v1/E1-r1门禁false、独立批准0、正式标签null、原拟合预算0、380封存；不自动扩样、重训、搜索阈值或patching。必要GPU由用户执行的约定不变。
