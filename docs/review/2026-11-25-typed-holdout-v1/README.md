## 金额标点影响

预先构造的“金额和日期”范围段写作 `$17, for ...`。旧金额解析器不识别金额后的逗号，因而这两个范围段各被识别为仅含日期。本批 48/48 保持原样，干扰强度按实际输入与解析结果解释。发现后另做[真正含可解析金额与日期的补充测试](../2026-11-25-typed-ambiguity-v1/README.md)，12/12 返回版本形状歧义，无法给出动作。

严格通过的 48 格共用两条法律规则、四种范围段格式、两种金额及三个日期条件。范围摘录和适用条件由作者编排，日期区间固定为相邻两天，人工参照并非独立法律评审。Rule 504 与上一批 Regulation Crowdfunding 同属证券发行的金额上限，遗产申报与上一批赠与税有共同税法领域。该留出支持在所用结构化短摘格式下继续验证候选，完整版本形状的干扰仍是明确限制。
