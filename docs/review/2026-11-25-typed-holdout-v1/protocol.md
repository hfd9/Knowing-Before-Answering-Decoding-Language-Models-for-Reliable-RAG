# 版本形状筛选候选的未见规则验证

沿用六规则事后诊断的版本候选规则。证据段必须恰有两个有序日期及一个整数美元金额，两个候选区间必须分离。剩余段用原模型评分定位比较与范围。候选不唯一或重叠时，该条规则返回未解决。继续使用原范围判断、求值器、直接路线提示及严格评分。[事后诊断](../2026-11-25-date-multi-rule-pilot-v1/README.md)

先冻结代码及本协议，再选取完整未见的法规规则，先固定题面和参照再模型运行。每条规则设同答、异答的缺日期以及各自明确两个日期的六格。每条另设范围段带金额、带两个日期、同时带金额与两个日期的干扰变体，变体与原题分别报告。两条路线读取相同题面及范围条件。人工字段接原求值器做参照。严格检查动作、逐日结论、证据及追问。冻结候选遇到两个以上版本形状时应保留未解决，由直接路线独立作答。

重点记录原题与干扰变体逐规则通过情况、同答多问、异答错误唯一、明确日期正确有据、规则结构歧义下的未解决。来源和人工编辑内容逐项归档。直接使用固定 Qwen2.5-3B-Instruct CPU、贪心 160 token。结果用于评估候选的适用边界。
