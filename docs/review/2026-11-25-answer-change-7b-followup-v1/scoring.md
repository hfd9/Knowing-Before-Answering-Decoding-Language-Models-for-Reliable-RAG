## 第二轮的分析单位

每条首轮输出分别接收旧日期和新日期，两个会话都从相同首轮历史开始，不串联、不由模型回答选择日期。本轮两日均为**用户主动补充**：逐条人工检查首轮 8 条未发现向用户询问日期的直接问句，其中有条件回答和确定回答；不把这 16 条称为追问后的轨迹。因此“有效追问后最终正确率”的实际分母为 0，记未定义，不记 0% 或 100%。本轮对照是：给定某次已经出现的首轮输出，再观察主动补日期后的答案，不能代表真正主动澄清的效果。

每条记录：原案例和路线、日期、参照结论及参照版本、答案内容、是否与指定日期匹配、是否保留矛盾的旧结论、引用、输出状态、评分理由。主分母固定为计划的 16 条；失败、截断、缺失及 unknown 单独列出，不从主分母中删除；若执行中途停止，未运行项按未执行列出，不能当模型错误或有效回答。按四道题及两日期分别展示，每条规则内相关样例不当独立规则。

## 结论判读与等值

先标注数值关系，再标注针对题目“超过／在排除额内”的实际结论；不因引用存在而推断答案正确。

| 题目与输出特征 | 数值关系 | 严格任务结论 | 宽松内容判断 |
| --- | --- | --- | --- |
| 问是否严格超过，明确说“等于，因此没有超过” | 相等 | N | N |
| 问是否严格超过，只明确陈述数值与门槛相等，没有作结论 | 相等 | unknown | 在事先公布的宽松口径下可推为 N；另报该推断而不写成模型明确回答 N |
| 明确写“超过”，但给出相等数值 | 相等 | 内部矛盾，不计正确 | unknown，不能只采有利部分 |
| 问是否不超过，明确写相等且在范围内 | 相等 | Y | Y |
| 没有提供足够的数值或任务立场 | unknown | unknown | unknown |

严格口径要求对所问结论作清楚承诺；宽松口径接受明确数值关系与规则共同蕴含的结论，但必须披露是评分推断。两口径均将内部矛盾单列。真实含义不清时 unknown；后续若找其他评审，只能称其实际达到的独立／盲化程度。

## 引用和任务事实

机械层分别记 ID 是否有效、是否完整匹配旧参照所列 ID；额外合理引文不得因单纯集合不同就自动判语义错误。语义层逐命题核对：适用日期、该日门槛、比较方向、范围条件、案情金额。必须给出可定位的支持，注明具体引文位置；不能因材料中存在文字就当回答已引用。可使用跨句引用，但须实际指向相关命题；不同版本门槛不得错绑。题目本身直接给出的金额或日期，可在语义层视为事实来源，**是否显式引用 F1 单独记**，旧严格 ID 集合口径仍保留 F1 要求。未提供规则／范围引用而材料存在，语义充分性评为不充分或必要时 unknown；标注支持与不足的具体原因。

每次分别报告：严格 ID 匹配、语义引用是否充分、内容是否正确、两者联合；内容对但引用不充分不能称严格有据。固定参照由知情作者整理，独立法律复核和引用盲评尚未落实。
