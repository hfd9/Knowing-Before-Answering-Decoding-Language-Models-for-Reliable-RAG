## 来源表述线索与评分边界

逐值提示的4个代码分歧题中，**双来源表达**有3条唯一回答“否”、1条未知；相同底题的4条**双候选表达**均合理保留。三条选边包括 `G01_split_dual_sources__decompose`、`G03_split_dual_sources__decompose` 和 `G04_split_dual_sources__decompose`：回答在具体代码分支或资料归属上发生错误。`G02_split_dual_sources__decompose` 把两个互斥代码同时成立作为可能情况，后续虽称无法确定，但前述条件矛盾未明确撤回，依据评分合同保守记X；若另一评审将其最终U视为有效，逐值分歧结果会变为13/16合理保留、3/16选边。两个表达的整套措辞不同、仅4底题，这只是来源表述相关线索，不证明来源标签或顺序是原因。

另有数值题把较小数误写成大于阈值，例如 `F01_same_no_dual_alternatives__decompose`；该条最终仅称“可能大于”，且列出错误条件，按合同保守记X。`F04_same_no_single_b__decompose` 先称不大于、最终称不小于，记X。其他输出即使最终目标正确，也可能含不支持的推理或无关假设；评分表仅标出已识别的问题，没有对全部解释作充分性保证。
