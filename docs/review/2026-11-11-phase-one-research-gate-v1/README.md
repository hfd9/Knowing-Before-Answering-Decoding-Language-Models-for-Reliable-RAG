## 一、关键输入和参照：有可复核依据，但仅为知情观察

本轮重新逐条读取已有36条最终五槽输入和36条作者参照，核查目标、S/I/C两表达、槽变更及作者引用。[语义复核表](semantic-audit.md)对每题列出I的五槽各自含义、目标字段、两个可满足原文的假设值、S/C依据和边界。两个假设值仅用于解释“不唯一”，来自既有S/C，**不加入I输入、不构造新样本**。例如05的I材料仅说明排练、协调者、表格存放及每场一个开始时间，无法由这些关系推出14:10或15:20；06的dry/cold冲突依赖输入明示不同类别名称代表不同类别。03的“both quays”指代未明，不能用它确定渡船目的地，表达及指代的独立审核仍未完成。

[机器核对](evidence-audit.json)显示36输入与36作者记录绑定、72处引用均出现在对应槽，42对的变化槽与预定结构一致；校验材料及参照封存哈希。引用核对不证明语义、无间接推断或表达保持。[逐题复核](semantic-audit.md)未发现必须改写既有作者参照的确定反例，给出了每个I输入的不唯一理由；但本助手已知全部状态和预测，不能视为新盲评或形式证明。原36判断不改，语言边界和未认证独立性保留。

现有6底题的12个I输入读出4 answer/0 refuse/8 conflict；S→I的12对没有一对两端同时符合作者映射，S→C为9对两端符合、3对充分端已判conflict。两个I表达对均稳定为conflict但不符参照，另外四对在answer与conflict间翻转。参照是知情作者判断，输入非独立底题样本，不能当独立错误率。更多数值、42对概率和编辑见[既有逐项分析](../2026-11-11-controlled-probe-interpretation-v1/README.md)。

## 四、决策及第二阶段前提

**收缩而非进入候选协议。** 本轮技术和知情语义核查支持保留“这个固定读出在这些已知构造中，分数有方向响应而类别常偏离作者参照”的诊断；未证明独立准确率、自然RAG发生率、隐藏状态无信息、内部检测后不行动或机制因果。E1未绑定同批probe，不能跨批接合推断行为。

如未来有新的、可核实的来源权利与材料范围，具名可审计的语义审核资源、用途容差及成本，再首先审查状态变化与表达保持的具体增量是否值得投入；两项均成立后才另立候选协议，固定参照、底题分组、主要比较、对照、预算和停止条件。行为失配若被另立，必须绑定同批生成前读出和实际回答；这只是条件，不是已批准采集。

本轮无新样本、独立评审、模型加载、前向、GPU、拟合、阈值搜索、patching或380正文访问。原v1/E1-r1门禁false、正式独立批准0、正式标签null、原拟合预算0，380正文继续封存。用户未来必要GPU工作由用户执行，本阶段没有GPU命令。
