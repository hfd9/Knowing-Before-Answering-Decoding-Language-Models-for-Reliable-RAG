# 按出处日期和逐条件范围核查的第三版协议

沿用前两版的 20 个案情、共同规则短摘、人工参照及严格通过条件。第二版的一对一选择已定位四份证据，但把两个年度先后排反，且整段范围分类把两个拒答控制判为适用。第三版对已选中的两个版本按出处中的起始日期排序，保留每版金额和区间所绑定的来源。比较符仍由模型选自比较证据。案情金额、两个候选日期、明确日期和控制事件沿用确定性抽取及来源校验，原求值内核不变。[第二版协议](../2026-11-25-date-evidence-first-v2/protocol.md) · [第二版结果](../2026-11-25-date-evidence-first-v2/README.md)

范围条件由作者从各范围证据整理为短陈述，每项保留逐字源文锚点，作为公开输入。程序在模型已定位的范围段落验证锚点，然后逐项给模型该陈述与 F1，要求判支持、反驳或资料不足。金额和日期独立处理，范围提示截取 F1 的案情前缀并规范化金额，内容相同的范围条件与案情共用模型前向。对三种选项次序分别采分，按同语义候选得分之和选择。有反驳则为范围不符，否则任一项资料不足则范围未知，全支持才通过。范围条件的拆分是明确的人工作业，未自动从通用法律原文获得。

开发门槛及留出设计沿用第二版。开发 20/20 和归档重放通过后冻结，并在搜寻新条款前保存冻结记录。留出来源也按同一格式提供四段证据、带原文锚点的范围条件和 F1。固定模型与 CPU 下一 token 评分，记录每个分数、真实输入 token、逐字段、分支、证据与动作结果。
