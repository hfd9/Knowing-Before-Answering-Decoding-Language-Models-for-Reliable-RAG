2026-11-12，Asia/Shanghai。**结论：此批已暴露开发题没有支持预期的“候选版正确而登记版过度拒答”在数值与查表任务中同方向出现；更明显的现象是结论确实分歧时经常给出唯一答案。** 这是单模型、单套表述、小样本的知情探索，不是独立确认或总体发生率。

6条技术缺失中一条为双来源断言，五条为单来源假设；不重答、不作为拒答或正确结果。v1首条采用128新token，其余采用384；v5在观察截断后改为空/无EOS自动留痕继续。运行设置的事后变化、缺失及所有原始分母须报告。

本次助手读取了完整输出及参考，已知问题和条件、并有历史设计暴露；138条完整输出均为**同一知情助手**逐条判断，不是独立盲评或人工金标准。先有原评分规则，本轮逐题记录对所问结论的最终承诺：Y=是、N=否、U=无法唯一确定/明确分支依赖、X=对所问结论含混或未撤回矛盾、T=技术缺失。若最终目标结论明确，目标口径允许解释中存在其他错误；因此“目标正确”不等于全部推理或额外事实正确，也不证明模型确实使用了两份来源。X不归入错误、拒答或正确；技术缺失与未知分别保留。

[逐题判断](commitments.csv)为36题×4条件，[逐项映射](review-items.csv)列出144项、原始记录路径和哈希，[聚合](summary.json)由[脚本](../../../scripts/query_determinacy_results_audit.py)生成。原 attempt/record 和3个自动缺失凭据共295个现场来源文件哈希见[清单](source-hashes.json)，分析前后重新计算一致；原输出及用户材料保存在本地未跟踪目录，**不随本提交备份**，哈希不是原件。原始记录供逐项查看，评分和计数不由关键词自动判定。分类是有参照暴露的人工语义判断，X及边界例不排除另一评审有不同意见。

配对主现象：**候选版目标正确、登记版过度保留 1/24；反方向 2/24**。另有1对登记版技术缺失、2对候选版正确但登记版未知，不能当作未发生过度保留；全24对转换分布见[聚合](summary.json)。数值题的两个方向分别0和1，类别题分别1和1，不符合“两个任务族同方向”的探索性推进条件。

唯一预期方向的类别例子 D07/Q1 中，登记版把一个来源对应的规则值读错，继而认为结论取决于代码；该题一条单来源对照也给出错误目标结论。因此这条现象不能直接解释为只因来源冲突导致的过度拒答。反方向两个例子为数值 D05/Q1 和类别 D08/Q3；后者的一个单来源对照也读错。D05/Q1虽在最终目标口径两条单来源均判断正确，但解释中有额外矛盾，不能当成完全无误的基础能力证明。

上述“过度保留”包括明确声称答案取决于分支而未给出题面可确定结论；它不要求模型原文一定使用“拒绝”一词，也不保证出错原因是冲突本身。对题意最终结论自相矛盾的 D03/Q2、D04/Q3、D09/Q1 登记版保守记 X；D06/Q1 登记版为截断 T。

## 72条单来源对照与解释

单来源按对当前问题的最终承诺比较参考：目标正确 **58/72**、明确错误6、未知/矛盾3、技术缺失5。数值题的5条技术缺失均保留，且有一些完整回答的解释与给定数值不一致；类别题出现6条明确目标错误。上述58只表示此目标口径的知情判断，并非正确推理率。

24个可判定问题中，18题的两个单来源对照均按目标口径判断正确；这是观察输出后的条件子集，非独立预先选定样本。其中预期方向0题、反方向1题。它仍含有一题双来源技术缺失，不能把18当18个可评价配对，也不能据此推断没有效应。

用户提出的推进条件包括两种题型的同方向配对差异与单来源基础能力；本批结果**没有满足该探索条件**。优先保留本先导与完整轨迹，不直接把此版差异当成稳定的来源断言效应，也不据此启动大规模确认。模型还存在查表、数值表达和无依据选边问题；一组问题无法分离它们各自的机制。继续研究同一问题如需后续复验，须另行确定如何改善基础任务、独立措辞和模型，不能用这批材料宣称自然RAG或因果机制的泛化。
