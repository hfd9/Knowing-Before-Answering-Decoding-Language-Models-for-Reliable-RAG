## 研究决定

52条在技术上可严格连接，另一会话复评在这些选例上为前述受限参照提供了可追溯的独立于本次汇总代码的第二份判断；其完整私有上下文、语义真值与模型族错误独立性无法认证，不等同正式独立语义批准。在26条CLI记不足的选例中旧probe仅2条输出refuse，而且两个来自同一底题；在26条CLI记可答的S对照中13条输出conflict。这加强了**所选材料中旧probe类别不宜当作可靠语义测量**的描述，没有改变原总分母，也不说明所有自然任务或隐藏状态均失败。

本批不支持恢复“probe已可靠检测不足却没有行动”的主张。保留九项范围分歧和所选个案证据，收束为冻结probe测量边界的探索结论；若未来确要确认或区分表面痕迹与语义，需另立参照、底题隔离和预定方案，而不是利用这批选例调整阈值、追认正式测试或重新拟合。当前无需追加GPU；用户无需本人逐条审核。
