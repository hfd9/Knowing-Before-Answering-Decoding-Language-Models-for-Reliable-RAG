## 解释边界

素材为12个已暴露虚构底题，两种形式及同背景三问相互关联。三种句式按底题分配；同一助手参与设计、已知历史并执行核查，参考不是独立金标准。受控文本明确两值且穷尽，严格适配器仅覆盖固定句式；自然来源中的抽取、穷尽性、未知分支以及实际系统延迟未得到检验。两种方法调用数量不同，组合还依赖旧单世界输出，两个分支共同出错仍可能给出错误结论。
