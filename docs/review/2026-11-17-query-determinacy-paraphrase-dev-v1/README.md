## 目的和材料

检查人工明示两个可能值的文本换一种句式后，模型抽取与直接回答怎样变化，以及抽取输出能否连接旧单世界缓存。沿用12个旧底题×两个表达形式：24背景分别抽取一次；每个背景3个问题，共72直接回答。每个底题内同为是、同为否、不同的三问共用背景；两形式和各问题均不独立。三种改写按底题编号分配，每种每题族与形式各2背景；不是同一底题的三种改写配对。

完整96条[材料](material.jsonl)含24抽取及72直接输入，模型只接收`prompt`字段。助手阅读了24背景并形成[知情核对表](informed-background-review.csv)，按旧问题、两个世界及参考重算，检查主体、值、原子代码前提与穷尽声明；同一助手参与设计并了解历史，非独立审核或金标准。两个来源的语义和措辞不保证自然语言普遍等价；该批不能当作未暴露确认集。旧144输入的两个不同实现审核和本轮[材料审计](../../../scripts/query_determinacy_paraphrase_audit.py)通过，但程序符合不证明语义完美。

## 冻结评估与成本

抽取严格按旧JSON规则：两个互异非空字符串，分别报告按顺序正确、逆序正确、其他、invalid及技术失败；不把数字数组转字符串。直接回答使用旧的严格是/否/无法确定解析。对每个直接问题，先以模型实际抽取的值构造分支，严格匹配72条旧单世界缓存；输出无效、语法不支持或缓存缺失均标未解决，不使用参考值补全。两个合法分支的模型旧回答按旧规则组合，Y/N一致则输出该值、不同则U；U/X分支标X，技术缺失标T。最后才用构造参考评分。

两表达各36个计划问题，分别报告直接与组合的正确、过度保留、无依据选边、错误、无效/未解决和技术失败；按同为是、同为否、分歧分层并给出配对变化。抽取24背景单独统计；同一次抽取失败影响对应3个问题，不能按3次独立失败解释。抽取技术失败传递为T；格式/分支不支持/缓存缺失传递为X。直接回答本身的技术失败与组合结果分开保留。该结果是**新抽取与旧缓存的事后连接**，不是联机端到端运行；不测未知分支的新调用，也不能推断总时延。

本次新增96次生成：24抽取和72直接回答，另复用之前72条单世界回答。若真实调用而不复用，组合每问题还需要两个分支，准确总调用受跨表达共享及失败策略影响；直接每问题一次。两路调用成本不匹配，不将结果表述为同成本优势。
