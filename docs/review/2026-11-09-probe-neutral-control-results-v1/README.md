## 解释与下一步

这些匹配完整prompt token总数的输入，在本批仍出现不同的conflict概率，故**token总数单独不足以完整解释这些具体差异**；D中两题方向相反，也不支持宣称否定后缀在所有题上都高于中性附注。中性附注本身也改变读出。否定语句和中性附注的词语、token身份/位置、附带语义与格式均不同，已见单题桥接也不涵盖每个旧端点；不能从此孤立出否定词因果效应，也不能证明读出是真实语义状态。6个已暴露底题与两种表达不支持总体泛化、准确率或统计确认。
