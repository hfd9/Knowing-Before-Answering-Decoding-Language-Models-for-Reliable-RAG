# 已有单世界回答的离线规则组合：探索性上界

2026-11-15，Asia/Shanghai。按来源顺序对照后的下一步，**复用已有模型单世界回答和知情评分，离线模拟逐世界回答后按规则汇总**；没有新模型前向或GPU。这是看过结果后的开发分析，不是已实现的端到端系统、真实RAG实验或独立验证。

## 做了什么

从8底题×3问题的两个单世界输入中，读取已经逐条审过的最终立场Y/N/U/X/T；先假定我们已知道两个穷尽的可能值，并能给每个世界各创建一个明确的单世界输入。如果两个分支均为Y/N：相同则输出该立场，不同则输出U；任何分支截断则整体记T，其余任一分支U/X则整体记X，不把分支自身的不确定变成正确的世界分歧。规则不使用参考答案决定输出，但依赖知情助手对模型回答的人工立场标签。[48个问题×提示组合的逐项表](pairs.csv)、[汇总](summary.json)和[代码](../../../scripts/query_determinacy_offline_world_aggregation.py)可重放。原评分不覆盖；直接双世界对照显式采用[已记录的1条更正](../2026-11-15-query-determinacy-source-order-results-v1/prior-correction.csv)。

## 结果

| 方式 | 简短提示：24问题 | 逐值提示：24问题 |
| --- | --- | --- |
| 单世界两回答经规则组合 | 23目标正确、1错误 | 19目标正确、2未知、3技术缺失 |
| 原双来源直接回答 | 13目标正确、11过度保留 | 19目标正确、1过度保留、1未知、3无依据选边 |
| 原双候选直接回答 | 14目标正确、10过度保留 | 19目标正确、3过度保留、2未知 |

每列包含16个两世界同答案问题与8个分歧问题，每个问题在“来源”和“候选”直接输出中各对应一次；**不要把两种表达重复计算成独立问题**。简短单世界组合的唯一错误是F01同为是问题：两个单世界回答都误判否，规则不能修复分支一致错误。逐值单世界组合的3个T来自先前截断，2个X来自单世界未知/不确定，均保留。3个逐值双来源选边仍反映直接路径的目标错误。

表面上的简短提示差异只说明：在这组已知世界的虚构题和手工语义标签下，把两次单世界回答组合有探索价值。它使用**两次模型回答加人工判读**，而直接路径使用一次；世界列举由材料构造者提供，不测从现实来源中发现世界、抽取和去重，也没有衡量人工成本、延迟或真实系统性能。单世界/双世界提示语句本身不同；同一底题多问相依、只有8底题，且方案是看过结果后构造，不能声称因果或泛化。代码题采用明确原子代码的受控语义，非自然文档。

## 验证与下一步

经原始388文件及来源顺序34文件、旧评分/明确修订映射核验；全部25种分支标签组合的缺失/未知传播测试、48行及汇总重放通过，未新建模型回答或修改原标签。下一步若要检验方法，应另立有固定输出格式的新开发批次：在明确给定两个世界的受控输入上，对同一问题分别收集两条单世界回答和直接双世界回答，冻结解析规则与未知处理，计入两次调用及失败；若解析不可靠，不把模拟结果冒称端到端成功。之后还需独立材料和世界抽取验证，才能讨论自然RAG应用。
