# 从固定来源模板重建世界：CPU缓存重放

2026-11-15，Asia/Shanghai。**在上一轮72个双世界提示的固定人工模板内，代码能从文本直接重建两个与已有单世界输入完全一致的提示，并重用缓存得到先前同样的33/36目标正确。** 这是后验模板重放，没有新模型调用，也不是自然语言世界抽取的一般能力。

## 具体做法

[抽取器](../../../scripts/query_determinacy_template_world_extraction.py)只接受固定的4行结构、指定问题/输出指令、甲乙或候选两种原始句式、明确恰有两值且无区分信息的原句，以及指定格式的数值或原子代码。它从文本中解析主体和值，把每个值代入单世界输入模板；没有读取原材料 `world_a`/`world_b` 或参考答案来生成分支。遇到不匹配、缺少穷尽保证、两个相同值或额外文本时直接报错，不猜测、不把失败记为U。

[重放器](../../../scripts/query_determinacy_template_world_replay.py)先核验[上一轮289个原始文件及其结果](../2026-11-15-query-determinacy-oracle-results-v1/README.md)，以完整提示字节匹配已有模型输入，检查匹配到同一底题、问题和两个单世界条件。72个双世界输入（各36来源/候选）重建144个分支槽，指向已有72个去重单世界输出；复用[冻结解析与组合](../../../scripts/query_determinacy_oracle_parser.py)。72个可重放结果和原直接答案见[逐项表](pairs.csv)及[汇总](summary.json)。

两种来源形式各36问题，组合均 **33正确/3过度保留**，与上一轮的已知世界组合是同一批模型输出，故不是重复实验或新准确率；原双来源直接12正确/24过度保留，原双候选15/21。三个组合失败仍是先前的单世界错误。构造和规则由看过材料及结果的助手设计，目标值、穷尽规则和代码语义都有模板明示，不能把这批结果说成未暴露确认、一般源文档处理或模型推理机制。

## 局限与检查

抽取器刻意只识别当前格式：将“资料甲”改成“资料一”，或将穷尽与无优先级保证改写，即使人可理解其意思，也会拒绝。这是明确边界，不应把拒绝的场景算为正确、没有冲突或不确定。未验证包含第三来源、相互一致重复、时间、来源优先级、间接事实或模糊文本等现实情况；也没有证明文本中所列的两个事实是完整可能世界，程序只检查了题设原文的明确声明。

测试检查全部72对精确重建，以及缺少穷尽保证、额外文本、标签变体、相同值和原子代码约束变化等拒绝行为，共3项CPU测试通过；289来源、144解析和36问题的原始结果重放通过。没有新GPU、回答、评分、训练、阈值搜索、patching或380正文访问。实际方法还需评估更灵活的世界抽取、歧义和失败处置，并在不依赖已暴露题的材料上比较，不能将精确模板重放当成端到端RAG有效性。
