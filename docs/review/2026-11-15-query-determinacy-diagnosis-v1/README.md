# 查询可判定性：先导诊断、复验设计与研究去留

2026-11-15，Asia/Shanghai。基于既有 144 项先导的评分表重新分组，并定向核读公开论文。**决定：保留为受控有限世界下的探索性行为测量，暂停直接扩大和确认；现有证据不能支持稳定的登记/候选表述效应，也不能证明不存在效应。** 本文的复验方案是可审查候选，尚未采纳或放行，不创建新题或启动模型。现有评分是同一位知情助手的语义判断，以下统计不是独立金标准。

## 一、失败现象和可解释范围

数据源为[逐项表](../2026-11-12-query-determinacy-results-v1/review-items.csv)、[原汇总与限制](../2026-11-12-query-determinacy-results-v1/README.md)。本轮用独立小脚本按 reference、commitment 重新分类并按任务族计数；不重审原回答或更改既有标签。单来源的目标正确只说明最终结论符合知情参照，不保证解释正确或模型使用了来源。

| 现象 | 可复核观察 | 能推断什么 |
| --- | --- | --- |
| 基础数值任务 | 36个单来源槽：28目标正确、3矛盾/未知、5技术截断 | 无明确目标错误不等于基础能力可靠；5缺失不能剔除后称28/31总体准确率，3矛盾也不等于正确。 |
| 基础查表任务 | 36个单来源槽：30目标正确、6目标错误 | 至少观察到给定简单条件下的最终结论错误，单靠双来源输出不能确定错误来自冲突。 |
| 过度保留的三个配对 | D07/Q1为候选正确/登记过度保留，但一侧单来源错误；D05/Q1、D08/Q3为反方向，后者一侧单来源错误。D05两单来源目标正确，但其解释另有矛盾 | 这些是**输出模式与已记载的局部线索**，不能归因于表述或证明内部过程；事后挑两侧单来源正确的子集也不能替代全样本。 |
| 双来源分歧 | 登记与候选各10/12无依据唯一回答；另分别1/2恰当不确定，登记另1未知 | 支持在此已暴露材料上继续研究选择性回答，但并未证明模型选择了哪一来源或发现普遍发生率。 |
| 回答前后矛盾 | 可判定问题的登记版有3个X；单来源数值题另3个X | 最终立场不能判定，既非明确错误也非过度保留；不能通过强制分配消除不确定性。 |
| 技术缺失 | 共6项无EOS：一项双来源、五项单来源；最初128上限与后续384上限、事后自动继续策略不同 | 保留原尝试；不得当作拒答、正确或同条件完整输出。没有原进程最终退出状态。 |

两种双来源表达的完整提示只在两处分别替换“登记值/候选值”，但两词的含义、语用和词元并不保证等价。由于问题中世界穷尽与来源优先级的理解也可能变化，只能称特定提示包的配对差异；不能把词语变动自动解释成来源冲突的纯因果效应。三问共用底题，24可判定问题不是24个独立底题。

## 二、具体复验候选：先验证参照，再探测能力，再估计差异

目标是估计**明示恰有两个许可世界、无来源优先级时**，同一问题在两种预先指定表述下的最终行为差异；分别观察跨世界答案一致与不一致的问题。并不声称测自然检索、隐藏状态或识别机制。下列数字是供审查的工作量示意，不是授权、样本量计算或将来通过门槛。

1. **语义与构造。** 另立未暴露虚构底题，先封存世界集合、数值或规则、每个世界逐题答案及答案集合；分别用两个不同实现计算，并由未参与构造者核对题面是否真的穷尽、优先级、单位边界及措辞。若两个表述不能被审计为同一许可世界和同一查询，剔除该底题并公开原因；正式评估冻结后不得按模型输出剔除。程序一致只验证编码规则，不验证自然语言歧义或真实分布。保留这批旧题作开发，不当未暴露评估。
2. **四种独立会话的输入。** 每题同问题分别给单世界甲、单世界乙、双世界表述A、双世界表述B；前两项直接给单世界假设，后两项明确许可世界与无优先级。每底题至少包括跨世界同为是、同为否、答案不同的三个查询。预先平衡来源顺序、是/否、任务族和提示顺序；相同底题各输出单独会话。每类至少两套独立撰写、预先审核的措辞模板，在底题层分配和记录；主比较在每套模板内配对，跨模板一致性单列。标明操纵的是整套表达而非纯单一词汇因果。
3. **两阶段而非事后挑题。** 在独立开发底题上先预定基础能力筛查：每个任务族两个单世界槽的计划分母单列，正确、错、未知、截断完整报告。可供讨论的操作性标准是每族至少90%目标正确、且完整率至少95%；它们只是明确何时继续研究所用的候选，未由用户或用途采纳，样本太小时不能作为总体能力保证。若不达标，诊断材料、提示或模型后新版本重新开发，不在同批结果上只保留答对的题继续推断。若达标，仍不代表评估集每题基础能力无误。
4. **冻结后评估。** 在开发之外的新底题上，用独立固定主端点：可判定查询的“过度保留率 A−B”，分母是每组全部计划可判定问题；完整报告A/B每类和配对转换。为处理未知/缺失，分别计算每端点的可识别下界和上界：明确过度保留记1，明确其他立场记0，未知/技术缺失取0至1；对配对差逐对求最小、最大并按计划分母平均。不能只做完整案例分析。分歧查询的无依据唯一回答率、恰当条件回答、未知及技术缺失作为共同报告的安全性结果；单来源能力与解释错误作为诊断。若目标是研究配对中正确与过度保留的转换，还需另外报告两方向，不将错误算正确。预先规定最小有意义差值、区间方法和资源可承受的样本量；在底题层抽样/聚类，不能把同底题的三问当独立样本。小先导只作描述，不产生确认性显著性结论。
5. **执行与审查。** 每条件随机固定顺序、冻结完整文本/token/模型/参数及上限，在正式前用不同开发材料预检长度和循环；统一处理无EOS、空答及中断，留存attempt，失败不得自动当成拒答或默默重答。按最终立场评分，区分Y/N/U、矛盾未知和技术缺失；额外记录推理与引用错误，但不推断内部机制。先封存输出及独立评审原始判断，再连接条件；未能证明评审隔离时如实降级为探索复评，不冒称独立。保留用户无需本人逐条审核的约定。

**资源算账示意：** 若每任务族6个新底题、每底题3问、4条件，每模型144次生成；若每底题两套完整措辞则每模型288次、两模型576次。底题不是单次生成，72个或144个问题也非独立底题。288条完整回答若全部双评至少576次回答判断，另有题面语义、两世界参考、模板等审核与分歧裁定；两模型翻倍。无可用审查者、额度、实际耗时或价格证据，不能称资源已落实；原有模型曾用30–60分钟规划/144次，不能外推当前新任务、第二模型或审核耗时。这个规模只用于开发性可行性示意，不提供效应估计功效保证，更不改变原拟合预算。

## 三、近邻和可主张的增量

本轮定向阅读原论文/摘要，不是系统综述，也未读取任何公开数据实例或核对其许可、版本与重叠。

| 近邻 | 已有内容 | 与候选的关系 |
| --- | --- | --- |
| [一致查询回答](https://www.scs.carleton.ca/~bertossi/papers/finalCQA.pdf) | 在不一致数据库及修复定义下研究跨修复成立的答案 | 世界不变答案不是新理论；候选的自然语言封闭世界与数据库修复定义不自动等同。 |
| [QACC](https://aclanthology.org/2025.findings-naacl.99/) | 人工标注检索冲突，分析开放域问答和多模型表现 | 已研究真实检索冲突；本候选只给定人工构造证据，也不能据此声称能解决自然RAG。 |
| [Wang等](https://arxiv.org/html/2310.00935v3) | 同一上下文分别询问冲突与非冲突片段，显式检测上下文和参数知识的问答范围冲突 | 固定上下文换问题并非首创；两外部世界与生成行为有任务差异，差异本身不证明价值。 |
| [Yang等多源记忆](https://arxiv.org/html/2605.30087) | 合成多来源冲突、确定性参考、单来源和融合基线、选择性作答 | 已有很强的受控多源/选择性近邻；其真值与来源扰动设计不等同于本候选明示许可世界、同答案/异答案的配对对比。本轮未证其缺少任何等价子集。 |
| [TrustDABench](https://arxiv.org/html/2608.24145) | 结构化数据任务分设证据冲突导致不可答与保持答案的格式扰动，并评估拒答及稳健性 | 冲突、拒答和表述稳健性各已出现；其冲突算子要求不同值导出不同答案，稳健性算子维护唯一答案。本轮未发现其将两个许可世界下答案相同/不同做同题配对，不等于已证明没有。 |
| [NatConfQA](https://aclanthology.org/2025.uncertainlp-main.13/) | 自然多答案冲突的细粒度关系和回答评估 | 提醒人工有限世界不覆盖自然冲突及多答案关系，不能用词面差异宣称现实分布有效。 |

可证伪的**窄候选**是：在先验明示两世界和无优先级的受控任务中，模型能否同时对跨世界答案一致的问题给出确定回答，对不一致问题保留分支；比较经过等价审核的两种表达后，两类行为如何变化。若仅观察到对某一词更敏感、单来源错误或无依据选择，尚不足以成为新机制或论文贡献。要论证研究价值，需在新独立材料、多措辞及至少另一个可用模型上显示超出上述近邻的清楚比较，并给出具体使用场景；即便做完也不能单凭未找到同题论文宣称首创。

**结论：暂停确认实验和新一轮GPU采集，保留现有先导与可审查复验设计。** 后续若有新的可核实评审或资源证据，应先完成用途容差、语义参照和评审安排，再决定是否新立开发性准备；若仍无法形成有价值的对照或独立参照，停止确认分支。当前不写就绪运行器、不自动创建新题或请求执行GPU。原v1/E1-r1门禁false、正式独立批准0、标签null、原拟合预算0、380正文封存；不自动扩样、重训、阈值搜索或patching。
