# 冻结probe的测量总表与研究去留判断

日期：2026-11-09，Asia/Shanghai。按用户要求仅整理既有结果并决定去留；不重跑13次前向、桥接或缓存审计，不新增评分、数据、模型前向、拟合、阈值或层搜索。分析者已见项目历史、材料、模型输出和probe结果；以下“作者参照”均不是独立金标准。口径和范围是事后确定，不能称前瞻验证。

## 判断标准和总体决定

将probe作为某一范围内的证据状态测量工具，至少需要：范围中的状态和适用输入有明确、可追溯的参照；同一范围内充分、不足、冲突及表达变化的结果和未定项有完整分母；在固定读出下，错误及稳定错误不会使拟议用途失效；这些判断不能只依靠看过结果后挑选子集。若用于声称“probe已检测不足但生成没有遵循”，还须在**同一输入**上建立不足参照、读出和行为的可信对应，且不能将离线读出冒称生成器内部的因果决策。

**决定：暂停把现有旧chat L28三分类probe作为可靠的证据语义测量工具或‘已检测不足但未行动’的依据。** 已有数据支持它是对所构造编辑敏感的探索性读出，但尚不支持一个可推广、经过独立语义验证的三状态工作范围。原发布构造任务及本地已见数据上的结果仍然有效为其各自范围内的报告，不将本轮开发材料上的失配外推为所有RAG、模型或隐藏状态失败。一个冻结线性probe未能可靠读出，不等于相关信息在隐藏状态中不存在。

## 判定依据与可用边界

- **不足是关键缺口。** 迁移I中，两表达各8/30读refuse，A/B双端均读refuse为7/30；绑定I的24条均读answer，12个v1/v2对照均稳定不符构造参照。绑定输入是回答已见后的状态重算，不是当时同步的probe记录；这些受限参照仍不支持把该probe的refuse读出当成跨任务可靠不足检测器。
- **冲突有方向信号，但非充分的可信范围。** 迁移C中A、B分别23/30和24/30读conflict，22/30底题两表达均符合作者参照；同时S/K也常读conflict。尤其等token六题的三种充分核心版本均读conflict，不能把conflict类别当成普遍可靠的冲突判断。作者参照、语义范围和已见数据阻止把22/30当独立召回或从中挑出事后合格范围。
- **连续概率与类别不是同一判定。** 既有迁移S→I不足概率53/60上升、S→C冲突概率54/60上升；绑定S→I不足概率24/24上升，I类别仍全部answer。读出有方向性响应，不认证语义或可部署的校准/阈值。等token六题否定−中性概率差D均值+2.68pp、P +6.56pp，但附注词汇、位置、语义和格式同时不同；不可认作否定词因果效应。
- **同批读出与行为已留作探索。** 迁移作者不足60条中，probe读refuse的16条有1条实质作答，其他44条有22条作答；分组底题组成不同，A/B类别混合只有2题且均不作答，不能据此确认稳定同题预测优势。绑定I行为不提供目标代码24/24，但probe没有一条读refuse。均是暴露参照，前者不能升级为‘模型已可靠检测不足却没行动’，后者不证明状态无信息。

## 与相关工作的区别及下一研究选择

原论文 [Knowing Before Answering，arXiv v1](https://arxiv.org/html/2608.27661v1) 已研究三状态线性读出，也包含提示稳健性、长上下文、自然域迁移、随机标签控制及生成层patching；不能把这些一般方向或“首次从读出走向生成”说成新贡献。它报告的原始任务/模型范围和本项目Qwen2.5-3B、自由回答chat模板、作者构造材料并不等同，当前本地结果不是对原论文总体效果的反驳。

[Hewitt 与 Liang 的控制任务论文](https://arxiv.org/abs/1909.03368)已明确提出探针表现与表征解释之间的区分及selectivity；本项目不能把“probe可能利用捷径”本身说成首创。潜在可检验方向是**在同一个固定证据状态任务内，分别测量作者/独立参照、语义关系变化与表达/构造变化下的三状态读出，以及与同输入行为的对应**。这是待验证的问题陈述，不是已成立的新方法或创新性结论；真正区别需完整核查相关数据与实验，并有能隔离比较的材料和可审计参照。

本轮联网成功读取上述原论文和探针方法原始页面，后续一组网页请求返回`connection failed`，原因未知；该失败未说明服务器训练环境或数据损坏。此次是有限定向对照，不是系统综述，也不能保证找全近期近邻；后续若提出论文创新性，须再核对最新原始文献与方法。中断期间发生的连接故障不影响上述本地数据汇总。

后续优先收缩为“冻结probe的证据状态测量边界”，保留可追溯负结果；不进入同批probe—行为因果解释或直接设计新GPU。若以后研究问题确需新方案，先明确独立或可审计语义参照、底题级划分、等价与反事实对照、固定主指标和停止条件，再单独决定实验；不为六题数值追加措辞/位置网格。
