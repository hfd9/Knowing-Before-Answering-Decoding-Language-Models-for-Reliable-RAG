时间按 Asia/Shanghai。沿用[已冻结的配对材料、逐世界参照与去留口径](../2026-11-23-rule-applicability-paired-v1/README.md)。每次生成输入一个题面。使用本地 Qwen2.5-3B-Instruct，CPU FP32、SDPA、16 线程及贪心解码，每批四个独立输入。强直接和模型抽取的输出上限分别为 256 和 160 token。开始前核对模型文件及依赖版本。每批先写尝试记录，再保存完整提示、输入及生成 token、原始文本和结束状态。新输出封存后重放，再连接对应作者参照。材料预检已经重放过参照，模型输入仅包含公开题面和路线指令。采集异常保留该批尝试与已完成记录。
