# 公开问法的紧凑输出开发复核

沿用上一轮一条公开真实消防问句及三个作者附加日期场景、原摘录、作者参照和 Qwen2.5-3B-Instruct CPU 贪心配置。上一版四条均触及 160 token 上限。本版冻结 160 token 上限和韩文 JSON 输出格式，分别要求动作、针对两个可能安装日的类别判断、依据编号及追问事实。对原问无证据包且无日期，记录模型回答，不计与三个作者参照的比较分母。

三个附加日期场景评分包含正确动作、所有应讨论日期的结论、所需证据及询问安装时间。完整结束、格式无效、截断分别记录。自由文本或不符合格式的输出不会自动归为安全。保留第一版截断记录，不合并为额外独立题目。法律参照由知情作者核对、未经独立法律复评。[来源与第一版记录](../2026-11-25-natural-question-v1/README.md)
