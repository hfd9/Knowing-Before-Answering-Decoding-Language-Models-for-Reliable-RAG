# 两题 CPU 演练与12个开发候选

2026-11-18，Asia/Shanghai。用户要求先以数值、类别各一题完成CPU题设核查、实际排重、模拟隔离和逐支评分，再补足12题。**两题受限CPU演练完成；已形成12个知情开发候选并进行结构复算与允许范围文本筛查。36个问题均有短文本无法比较的部分，语义近似及独立参照仍未闭合，因此不宣称12题通过无碰撞/独立确认，也不放行实时运行。** 无模型调用、GPU或380正文访问。

## 两题先行

[两题公有输入](public.json)与[逐世界参照](reference.json)分文件，来源、显式穷尽、各世界问题答案及证据列于[先行验收](pilot-acceptance.md)。数值34/58与类别VX3/LM7各配Y/Y、N/N、不同三个问题。来源冲突不自动推出穷尽；穷尽和两者均可能是人工题设前提。类别初稿曾把“适合低温”误当“不适合干燥”，冻结前已补充明确否定，不能将作者发现当独立评审。

生成端[CPU模拟脚本](../../../scripts/query_determinacy_two_case_cpu.py)仅读公有输入和模拟响应，不读取参考；输出及预期SHA封存后，[评分脚本](../../../scripts/query_determinacy_two_case_score.py)先核输出SHA，再验证参考SHA并连接。两种哈希由同一操作者记录，不是防特权篡改或OS级隔离证明。参考包含作者逐世界答案和必须匹配的来源/规则短句；评分核查世界值、答案及引文，引用命中不是一般语义充分性证明。

## 12个开发候选

先行两题CPU验收之后新增10题，形成[12题公有输入v2](public-12-v2.json)与[12题参照v2](reference-12-v2.json)，包括6数值/6类别、36问，各12个Y/N/U。[受限复算](material-verification.json)逐题解析比较或规则表，验证两个来源引文及每世界答案；[材料生成器](../../../scripts/query_determinacy_development12_material.py)和[独立实现的受限检查器](../../../scripts/query_determinacy_development12_verify.py)由同一知情助手编写，不是独立语义金标准。2项测试复建材料并验证错误答案、缺失引用被拒绝。

新增候选的第一版发现5道类别题的异答均为“甲是／乙否”，于是**在任何模型输出之前**将J8E4和V5D2改为反向，保留[第一版公有材料](public-12.json)、[第一版参考](reference-12.json)及[第一版筛查](overlap-12.json)。v2每类异答方向分别为4/2，仍不完全平衡；12题共用少数模板及合成条件，不能作为自然RAG或新颖性证明。

## 实际排重与人工复核边界

[12题筛查结果](overlap-12-v2.json)覆盖535个不同获准旧问题、2829个不同获准旧背景或文档；分别比较36问题和12背景。规范化精确命中0，适用长度条件下背景的包含/8字符片段命中0；筛查重放逐字一致。所有36问题都有短侧比较不适用，共12840个问题配对的包含及片段结果为unknown，不能当0命中。

作者查看许可的110个不同查询可判定性问题，发现先行数值问题的阈值/谓词与旧题接近，类别规则表问题与旧包装题型相近；新增十题同样大量复用数值阈值及属性表范式。短问题须继续逐题审视，其余425个旧问题未完成语义人工比较；未列历史、模型预训练、380正文和语义改写均未覆盖。无文本命中不证明完全未见或无语义碰撞，保留unknown。这些是知情开发候选，不是独立样本或论文确认集。
