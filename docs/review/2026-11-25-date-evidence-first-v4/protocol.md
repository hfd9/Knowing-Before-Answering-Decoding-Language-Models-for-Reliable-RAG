# 多数一致的开发验收与未见条款留出

沿用第三版题面、比较符和出处定位、日期排序、逐条件范围提示、人工参照和严格评分。选择范围条件的三个次序中至少两个给出的同一判断。三次各异则保留资料不足。原实现按候选分数求和，明确不适用控制案的两次反驳被一次资料不足的分数压过。此调整来自只看已知规则的开发结果。[第三版协议](../2026-11-25-date-evidence-first-v3/protocol.md) · [第三版结果](../2026-11-25-date-evidence-first-v3/README.md)

用冻结本版的 CPU 路线重新跑同一 20 格，严格要求 20/20，再封存提示、实现、评分、开发结果和模型环境。只有该冻结记录存在并验证通过才开始查找新条款。新规则来源的角色标签按证据段标识，不固定角色对应字母。规则排布、范围摘要或条件编排与版本日期的任何人工规范化均单独记录。留出六格格型、严格判据和失败处置沿用第二版预定口径。[留出设计](../2026-11-25-date-evidence-first-v2/protocol.md)

固定记录同答缺日期无谓追问、异答缺日期误给唯一、明确日期正确有据的分子和分母。各格仍独立记录所有字段、逐日分支、引文、动作以及追问事件。单条规则的通过限于带来源锚点的受约束题面，对跨条款规模评估保留独立材料。
