# 真实问法与日期补充的 CPU 开发检查

使用一个公开的韩文消防咨询原问题，另构造同一问题的旧日安装、新日安装和缺安装日期三个限定场景。来源、改写范围和原文法规依据见[来源说明](source.md)，模型输入与评分口径在生成前固定于[协议](protocol.md)。原始问答的官方回复与本轮构造场景的作者参照分别保留。

四条生成均达到 160 token 上限，均被标记为截断。原问题回复提及医疗机构和地方规定，却未给出可核验的第 30 条及附则依据。旧日变体先说旧版未列入，再转向新版，截断使其最终结论未知。新日变体在截断前声称新版不适用，和题面明确的生效日安装事实及作者参照相冲突。缺日期变体在截断前写出旧新条款差异，也写出当前未被排除的判断，后续被截断，最终立场未知。逐条输出及 SHA 见[输出](outputs.json)。

四条均未形成完整有据的严格通过输出。单条真实问题带有作者补充材料和非独立的知情法律参照，该次检查提供的是接口和失败线索。完整原始消息、生成 token 与模型状态见[归档](raw.zip)。四次 CPU 生成批次现场 279.63 秒。可重放的命令为 `PYTHONDONTWRITEBYTECODE=1 /large_disk/wf/miniconda3/envs/kba-rag/bin/python docs/review/2026-11-25-natural-question-v1/run.py check`。
