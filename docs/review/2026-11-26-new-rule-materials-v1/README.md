## 候选选择和来源

按选择前协议定向检索官方来源，并检索现有 `docs/records/*.md` 与 `docs/review/*` 来源记录中的对应规则编号、名称和金额。范围内未发现以下两条已在本项目使用；这不是对预训练、其他目录或封存 380 的排重证明，没有访问封存正文。搜索先发现 SEC、FTC、IRS 等线索；FTC 交叉任职门槛涉及其他条件和生效日核对，本轮不选作为金额单条件试运行，不因模型结果筛选。

1. **SEC 合格客户的管理资产单项门槛。** 2016 订单的投资顾问管理资产条件为至少 100 万美元；2021 订单自 2021-08-16 生效，条件提高为至少 110 万美元。对一个新合同，仅询问立即签约后的管理资产这一项，不判断其他资格途径或完整合同是否合法。题面只允许签约日为 2021-08-15 或 2021-08-16。2021 订单不一般追溯适用旧合同；这也是构造新合同而非续约案情的原因。[2016 SEC 订单](https://www.govinfo.gov/content/pkg/FR-2016-06-20/html/2016-14450.htm) · [2021 SEC 订单](https://www.sec.gov/rules/other/2021/ia-5756.pdf) · [SEC 变更说明](https://www.sec.gov/files/rules/final/2021/ia-5904-fact-sheet.pdf)。
2. **劳动所得税收抵免的投资收入单项限制。** IRS 官方年度调整说明：2024 年开始的纳税年度，所列投资收入超过 11,600 美元时该项使抵免不被允许；2025 年开始的年度门槛为 11,950 美元。问题仅问这一投资收入限制是否单独导致不允许抵免，不问纳税人是否满足全部资格。两种假定年度开始日为 2024-01-01、2025-01-01；它们是相距一年的日历年起点，不是相邻的两个事件日。[IRS 2024 年度调整](https://www.irs.gov/irb/2023-48_IRB) · [IRS 2025 年度调整](https://www.irs.gov/irb/2024-45_IRB) · [IRS 年度门槛表](https://www.irs.gov/credits-deductions/individuals/earned-income-tax-credit/earned-income-and-earned-income-tax-credit-eitc-tables)。

材料中的 E1/E2 是来源中的短摘录；版本元数据、问题和案情由作者明确标注并整理。摘录对应来源、适用日期和判断范围由助手依据上述页面核对，尚未保存来源网页完整字节或获取独立法律复核。IRS 提醒官方公报的具体适用需考虑后续法规及事实；此处不作个人法律或税务结论。[IRS 对官方指导的说明](https://www.irs.gov/privacy-disclosure/tax-code-regulations-and-official-guidance)。

来源权利初查：文本出自美国政府的 SEC 官方命令和 IRS 年度收入程序，[GPO 对政府文件的说明](https://www.govinfo.gov/about)指出政府作品通常可重印，同时提醒政府文件可能含第三方受保护材料。这里仅摘录相关政府规范性文字并注明来源，不作所有 IRS 页面、衍生数据或后续公开发布权限均已核齐的断言；具体分发和独立法律复核仍需核对。

## 冻结管线的适配限制

本草稿以每规则两条原文摘录加作者版本元数据提供给两个 7B 路线；旧 3B 抽取器要求恰好四段证据，并要求两个日期相邻。IRS 的两个日历年起点不相邻，因此不能无损地直接使用旧管线。即使对 SEC 人为拆成四段，也会引入额外的作者段落及范围角色结构，改变材料。尚未对该草稿运行旧管线或实现无损输入适配；它不能被算作已就绪的同题第三路线。主比较仍是同一 7B 的直接与逐版提示。
