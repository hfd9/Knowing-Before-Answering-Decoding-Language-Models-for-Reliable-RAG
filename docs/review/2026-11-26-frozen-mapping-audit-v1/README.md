# 冻结抽取器的无损映射与输入公平性核查

状态：已暴露材料上的离线接口审计，不是新留出、模型对照实验或评分结果。目标是将同一四题的旧冻结 3B 管线结果与 7B 两条文本路线接入共同的评审记录，先保留它们实际提供的信息。

## 映射结果

[逐项映射](mapping.json)含四道题的 4 条旧候选和 8 条 7B 首轮输出。每项保留完整来源对象（包括原动作、逐日分支、引文、错误、token／状态或来源中的其他字段），再提供一个只读视图；7B 的完整输入与原始 token 也保留。旧结果中的 `checks` 是历史知情参照检查字段，不输入模型，不作为独立金标准。对应来源的 SHA-256 均在文件中；7B 归档 seal 和尝试记录先核对。

| 案例 | 冻结候选实际输出 | 映射方式 |
| --- | --- | --- |
| SSA 同答、异答 | 两题均在字段核验时报 `event not supported by cited rule`，无 outcome。 | 标 `pipeline_error`，保留错误；不虚构 `UNRESOLVED`、拒答、追问或分支。 |
| 赠与同答 | 结构化 `ANSWER_Y`，原有两日结论和证据。 | 保留结构化动作和原逐日字段。 |
| 赠与异答 | 结构化 `ASK_DATE`，含 `gift` 事件及两日结论和证据。 | 保留结构化动作、事件和逐日字段；不伪造系统已经向用户提出了自然语言问题。 |

不能以 3B 的两个管线错误断言其作出了谨慎决定；也不能把程序内部 `ASK_DATE` 直接算成已生成、用户可理解的追问。结构化结果与自然语言回复需要预先规定展示与行为评分：只评已存在的字段，若将来实现文字展示，应先冻结无损规则并标明展示器。此处不生成文字、不填答案、不重算作者标签。

## 共同材料与关键差异

脚本核对 7B 计划中的四道题均包含与旧公开包一致的问题、案情及四段证据原文，两个 7B 提示均如此；这只证明公共材料包含关系，不代表全部提示、模型看到的信息或系统运行过程相同。

| 方面 | 旧冻结管线 | 7B 直接／逐版路线 | 比较含义 |
| --- | --- | --- | --- |
| 模型与推理 | Qwen2.5-3B；CPU 上对多个选择提示计算分数，随后确定性求值。 | Qwen2.5-7B；GPU 上两种生成提示。 | 模型、硬件与方法同时变化；不能把差异归因于抽取／求值方法，也不能声称这是同模型对照。 |
| 范围来源 | 定位模型需先选范围段；程序通过作者整理的 `scope_claims.source` 与选中段比较，匹配及引用校验成功才生成条件判断任务。 | 两个提示均直接出现作者整理的范围断言及“derived from [E2]／[E3]”。 | 7B 明确看到来源标签；旧管线先自行定位但在下游使用来源标签作门控。作者结构介入发生在不同位置，不能称两者无差别地获得相同角色信息。 |
| 数据形状 | 四段；两段各能解析两个日期和一个金额、区间不重叠；题面可行日期为相邻两天。 | 直接给定四段、事实、日期范围及人工范围陈述；文本路线不受相同硬编码形状约束。 | 共同材料是作者整理的受控子集，不能据此认定管线支持任意完整法规。 |
| 输出 | 管线结构化动作与分支；失败可无有效结果。 | 开放文本、标识引用、条件式回答、矛盾或截断均可能。 | 保留形式与失败，不把内部动作直接等同于用户界面回答。 |
| 调用和成本 | 多个 3B 选择前向／确定性求值；历史包报告整批调用和计算成本。 | 每题各一条 7B 生成，最多 512 token。 | 调用次数、token、计算设备和时间口径不同，须分别报告；整批 36 格成本不应直接摊到四题当实测。 |

对 7B 材料隐藏已知范围来源标签可形成**未来额外对照**，但会改变既有输入，必须单独定义和运行，不能将本批 7B 结果事后改称不知来源。若尝试让冻结 3B 管线与 7B 完全同底座，必须先证明只更换模型不会改变冻结方法的其他部分；无此对照时只能如实报告两个整体系统。现有 3B 权重或算力无法使用时，不可伪造同模型结果。

## 完成检查与下一步

四个映射边界测试覆盖管线错误不冒称拒答、结构化追问不冒称文本、字段冲突拒绝及原始文本和截断保留。`python3 scripts/answer_change_frozen_mapping_audit.py --verify` 重建映射并核查 7B 封存；旧 3B 的历史完整重放结果见工作记录。无新生成、GPU、评分或模型参数变更。

映射审计解决了历史四题如何保存和展示，但没有实现一个适合新规则的完整在线接入；条件是材料可构造成冻结管线支持的形状、来源断言人工角色如实披露、无自动修正，且逐路线输出和失败可验证。下一阶段应冻结开发试运行的评分和比较协议：优先比较同一个 7B 的直接／逐版路线；旧 3B 为附加系统级对照，必须单独披露信息及模型差异。固定协议后才选择两条新开发规则，不能把旧四题作为未见样本。
