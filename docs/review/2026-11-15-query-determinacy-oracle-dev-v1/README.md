## 方法和对照

离线模拟以人工判读的已有单世界回答为输入，并假设两个可能世界已知；本轮固定一个**可自动解析的受控方法**，检验这个假设下的输出，而不再依赖先看答案的人工作最终立场解析。每个问题分别生成甲、乙两个明确单世界输入，各调用模型一次；将结果按固定规则合成。对同一问题另各调用一次双来源、双候选直接回答，故每个问题4次生成。单世界内容直接由构造者给出，是**理想化世界枚举器**：本方法不读取真实来源来抽取、去重或证明世界穷尽，计算成本为两次模型调用，不能当作成本相等的端到端对照。

新虚构12底题（6数值+6原子代码）×3问题（两世界同为是、同为否、不同）×4条件=144输入、36个底层问题。数值分歧题的存储world_a是/否各3/3，代码分歧world_a均为是但显示顺序3/3；这是设计限制。明确代码互异且无包含/同义；数值/代码题型和双世界表达沿用前轮家族，材料由已看旧结果的同一助手设计，虽然底题数值和代码新建，也不能称独立确认或与380封存材料已证无碰撞。

四条件统一要求“请仅输出一个答案：是、否或无法确定。”[固定解析器](../../../scripts/query_determinacy_oracle_parser.py)先去首尾空白，允许去掉**最多一个**末尾的句号、英文句点或叹号，再精确匹配“是”“否”“无法确定”；多余文字或其他格式记X，非EOS/空输出记T。单分支如果为U或X，组合记X；任一T则组合T；两分支均为Y/N时，相同则输出对应Y/N，不同才输出U。不能将单分支不确定冒充世界之间有分歧。解析和组合程序已绑定清单，绝不在看到结果后悄悄放宽规则；可另记人工语义分析，但不得覆盖固定主结果。

[评估器](../../../scripts/query_determinacy_oracle_evaluate.py)固定每个问题连接两分支与两直接回答，分别计正确、过度保留、无依据唯一回答、错误、不可解析/分支未解决及技术缺失；按题族和答案一致/分歧分组，报告全部计划分母、两次调用成本和逐题配对。36个问题嵌套在12底题内；不把四次生成或三个问题视为独立底题。若字面格式不合法，不靠人工或关键词自动改正确；逐项原输出保留以分析失败原因。最终正确仅指固定参照和解析口径，不认证模型推理过程。
