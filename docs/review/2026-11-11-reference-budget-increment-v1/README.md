**尚不能声称独立语义参照、可用资源和实质论文增量已落实。** 在有限研究用途下，可提出一个清晰的90%性能下限作讨论，但它不是用户已接受的要求，不是新数据上的结果，也不恢复原拟合预算。原有独立性条件、冻结决策、材料权利和资源缺口没有因为提出数字而闭合。新增一篇行为研究表明，按充分/不足/冲突构造同题证据梯度和人工抽查本身也已有近邻；其是否完成完全相同probe测量无法仅凭定向阅读断言。维持[此前的阶段去留](../2026-11-11-original-material-feasibility-v1/README.md)：当前不构造新确认材料。

## 2. 具体候选用途与容差：可计算但未采纳

提出供决策的候选用途：在预先界定的原创受控五文档分布上，冻结同一旧chat L28读出；对每个S/I/C，底题的A/B两端均有可审计参照、关系保持且均被正确分类才计该状态的联合成功。应单列单端混淆、A/B翻转、两端稳定但不符、不可判和处理失败。此为**候选测量标准**，不是应用方已经接受的要求，也不是新的执行协议。

如果将每个状态的联合成功率最低可接受值**假设**为90%，用单侧同时95%下界（每状态α=0.05/3，Bonferroni）评估，仅作为成本/精度的数学示例，在每状态底题可视为独立同分布二项样本时：

| 底题数 n | 本状态不成功数 | 每状态单侧下界 | 六输入/底题总输入 | 每输入双评的基础审核次数 |
| ---: | ---: | ---: | ---: | ---: |
| 39 | 0 | 0.90034 | 234 | 468 |
| 39 | 1 | 0.85462 | 234 | 468 |
| 80 | 0 | 0.95011 | 480 | 960 |
| 80 | 1 | 0.92675 | 480 | 960 |
| 80 | 2 | 0.90651 | 480 | 960 |
| 80 | 3 | 0.88779 | 480 | 960 |

计算用项目Python环境 `scipy.stats.beta.ppf(0.05/3,n-f,f+1)`；n=39和80、零失配的数值与[此前示意](../2026-11-09-probe-source-feasibility-v1/README.md)一致。本机默认python3缺scipy；改用项目现有环境完成计算。n=39要在该严格标准下通过需要零失配，即使真实联合成功率为95%，单状态零失配概率也仅约13.53%；n=80要求至多2失配，单状态在真实95%时通过概率约23.06%。三状态共用底题，不能把这些单状态概率直接相乘。它们不是完整功效/预算分析，不表明90%对任何部署足够，也不是对未知未来数据的预测。

审核次数是完整覆盖、没有unknown或重审时的下限式任务量；两表达均需逐槽验证，两次判断不自动独立。若unknown或失败存在，需在设计时规定覆盖率及如何处理，不能无条件剔除；保守将其计为不成功是一种待评审的选择，会影响所需底题及解释。原创样本若是便利构造或底题相互依赖，上述二项区间不能自动推广到自然域甚至某个未定义的人工材料总体。金额、评审工时、可行覆盖率、GPU端到端耗时及误差容忍目前均无测量依据；不能从旧运行的单次前向计时线性推算。原拟合预算0，必要GPU由用户按既有分工执行，仍需新条件及代码门禁审查。

## 3. 新增近邻：证据充分性梯度的行为研究

[Zhang和Wu，Evidence Sufficiency Benchmark（2026）](https://www.techscience.com/cmc/v89n1/68467/html)报告从SQuAD和HotpotQA各100题构造五级证据，包括充分、部分、无关、无上下文和冲突；按作者描述，共1,000个证据级输入，三种提示，七个模型。作者对200个分层样本做内部人工检查，既检查证据级别也检查自动回答分类；这种作者内部检查并非本项目所需的已认证独立评审。文中主要研究**最终回答/弃答行为**与证据等级的关系；我们在所读页面未见与本项目相同的生成前冻结L28三分类probe或完整审核的两表达联合正确率，不代表论文之外没有相同工作。论文的“数据及代码将在接受后公开”为作者声明，本轮没有核实可用仓库、版本、许可、实例重叠或数据。它进一步表明“同题充分—不足—冲突梯度”“人工抽查”和“证据敏感性”并非新贡献。

此前[KBA](https://arxiv.org/html/2608.27661v1)已有同题三状态probe及提示稳健性，[ContextConflict](https://arxiv.org/html/2609.03148v1)已有冲突/一致配对probe，[Hidden Commitment](https://arxiv.org/html/2610.38296v2)已有同qid顺序、单文档及改写一致控制。潜在差异仍是可信参照下同一冻结读出对三状态**同时**测正确性与表达保持稳定；未找到某篇完全相同不等于证明首创或论文价值。针对新的ESB只做定向阅读，非系统综述；尚无实际新数据和实验支持差异。
