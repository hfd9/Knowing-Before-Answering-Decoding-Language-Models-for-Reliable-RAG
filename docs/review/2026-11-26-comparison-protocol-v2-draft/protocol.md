# 版本信息是否改变答案：多规则比较协议 v2 草案

状态：**选择未来新规则之前的候选草案，尚未冻结、未选择规则、未放行运行**。本草案在 SEC／IRS 两条开发规则及其全部首轮输出已暴露后制定；这些规则不可成为 v2 的未见验证规则。继承[两规则开发协议 v1](../2026-11-26-new-rule-development-protocol-v1/protocol.md)中不冲突的固定提示、两路线、独立会话和失败处理，并以本文件的修改为准。真正选取未来规则前，须固定本草案版本、具体来源用途、评分表、生成实现、测试和执行计划；若继续修改，应记录版本和当时暴露。

## 研究范围和可用性

主要对照是同一 Qwen2.5-7B-Instruct 的直接回答与逐版比较；不将 7B 称为已验证的强模型，不以旧 3B 历史结果当同题方法消融。先评价完整材料下的阅读和回应，再在语料库与工具固定后研究真实检索。旧管线仅在其材料形状及模型资源均可满足时作为披露差异的附加整体系统。

目标是 8–12 条在协议冻结后选择的不同规则，每条有同答／异答各一条缺日期题及旧、新日期对照，共 6 题；两路线首轮分别为每规则 12 次，总 96–144 次。缺日期共每规则 4 个模型输出，明确追问的每条输出最多两条日期续轮，总续轮上限 64–96 次；两日期从该首轮独立分叉。实际调用数、截断、缺失及成本须报告。此数量用于探索性去留，不声称统计功效或总体分布代表性。

材料参照须由能够独立判断相应法规的人在查看模型输出之前复核版本、范围、例外、日期与分支，记录实际身份角色、暴露、分歧及解决方式。当前没有已确认的独立法律复核资源；未落实时只能准备或运行明确标记为知情作者的**开发材料**，不能将其称为独立验证、正式法律 gold 或论文确认实验。来源、复核、预算及 GPU 运行计划不因本草案而自动放行。

## 保留足够的来源语境

每个版本所引原文至少保留相关条件句的主体、比较关系、所判断的法定事项及不可缺少的限定；不能仅从谓语中段开始而把规则归属全部交给题面。若必要限定涉及相邻句或其他条文，应同时提供并保持来源 ID；无法在合理上下文和可用权限内保留必要内容的候选排除或记 unknown，不以作者改写替代可验证原文。

原文逐字摘录、来源提供的生效／年度适用说明、作者为试验限定的日期窗口及假设案情分开标示，均列来源、版本、取用时间和复核依据。作者元数据若把原文的生效条件或年份放在摘录以外，必须明确标识并可追溯；不能把作者陈述计作原文引文。对来源不同页面之间的映射保留证据，不能用发布日期替代适用日期。摘录长度、再发布或第三方权利未明确时仅本地核查，不自动放行公开分发。

每规则材料的模型侧输入在两路线完全相同；不显式向任一路线披露作者参照、same／different 标签或另一题的金额。允许向两路线同时提供有来源支持的版本日期元数据，但不得提供人工预先判定的最终结论。证据完整性由独立复核者或在无独立资源时由知情作者分别记录，不能因为模型看到了两个编号就自动认定两版证据充分。

## 评分字段：缺失日期与回复

每个输出先独立标注以下可观察事实，给出原文位置、评审者、暴露及 unknown 原因，再依协议汇总；不要从最终答案倒推出模型内部过程。

1. **日期认知**：用户提供日期／未提供日期；输出有无把未提供的具体日期作为已知事实。题面只提供两个可能日期，不等于用户已经选择其中一个。明确写“如果日期是……”属于条件分支，不属于虚构实际日期。语义无法判断时标 unknown。
2. **结论承诺**：无条件唯一结论、完整正确的条件式结论、明确追问、证据不足、局部条件、内部矛盾或未知，可以多标签；输出若同时明确给出矛盾的无条件结论与分支，不只取有利的句子。
3. **唯一性判断**：两版同答或异答是否由输出明确表述，或由正确完整的逐版结论可靠支持。仅给碰巧正确的一个值或只说“日期可能有影响”，不能直接推定正确识别。
4. **日期虚构与错误唯一分开**：记录（a）未给日期却当作实际日期；（b）输出是否明确作无条件唯一结论；（c）是否将虚构日期作为事实后只回答该分支。报告 b 的词面率、c 的单独率和二者并集，不把这一事后修订应用于 v1 的旧分数。若交互文字含糊，保留 unknown 与宽松区间。
5. **已知日期**：分别评实际日期的结论、其他日期的事实错误及整体自相矛盾；不把其他日期错误全部忽略，也不因对照讨论合理就判错。

对每规则缺日期的同答／异答配对分别报告唯一性判断成对正确率、内容有效性成对正确率和**内容及充分引用**的成对正确率。条件式答案如完整准确，可以作为有效回复；明确请求能区分版本的事件日期也是有效澄清，但要单列尚需用户交互。实际用户已给日期时重复追问该日期不有效。未知、格式失败、截断和未运行均单列；计划分母、已运行分母及参照可判定分母都展示，不能只报告可评分子集。

## 引用和后续回合

逐命题记录版本日期、阈值、比较符、适用条件和案情事实由何处支持；机械 ID 出现、旧式精确 ID 匹配及语义充分性为不同字段。证据 ID 出现在回复中不自动支持全部命题；事实来自题面时允许在语义层引用题面，但显式 F1 与否另报。独立盲评不能落实时，语义结论必须标为知情作者判断和 unknown 边界，不发布为独立有据率。

只有首轮明确要求用户提供所需事件日期时，才将其两日期分叉纳入真实追问后指标。保存触发判断及理由、第一轮原始文本和 token；“取决于日期”、完整条件回答、泛称信息不足或主动补充日期均不自动计作追问。若无真实追问，后续指标分母为 0、记未定义。主动补充日期实验如另做，必须独立命名、分母和结果分开。

## 分析与去留

输出每条规则各自的同答／异答配对、已知日期、逐版分支、引用、虚构日期、内部矛盾、无谓追问及运行代价，不把变体当成独立规则。对两路线同时报告绝对数、逐规则得失和样本局限，不根据本草案事后挑选单一成功指标；不承诺统计显著或证明泛化。

完整证据下若错误持续且逐版在多条规则稳定改善，可继续研究逐版比较与显式求值器的附加作用；若完整证据表现良好但真实检索漏掉改变结论的版本，则设计同预算反例检索；如果独立法律参照无法落实或较强对照已解决该问题，则先验证软件版本材料。三种情况都还需来源和近邻核查；仅由两条已暴露开发规则的成绩不能决定论文贡献。
