# 合成评分边界与来源合同：冻结前草案

这是一组**虚构的英文示例**和记录合同，不是模型输出、人工复核、法律结论或已冻结评分协议。配套 [JSON](synthetic-boundaries.json) 只供检查字段及样例相互关系，不能从文本自动判定语义。假设 2024 与 2025 分别对应旧、新版本；异答例假设旧版 yes、新版 no，同答例假设均为 no。引用充足性需另评，不由这些标签推得。

| 合成例 | 必须分别保留的观察 | 当前用途 |
| --- | --- | --- |
| same-invented | 两年内容均为 no，最终内容碰巧正确；把未提供的 2024 当成事实；唯一结论和基于虚构日期选边也分别有值。 | 内容正确不等于事实假设正确；整体回复是否有效尚待冻结。 |
| different-conditional | 每个条件都是假设，两支都对，未声称实际日期；内容有效，不自动表示证据充分。 | 防止将正确条件答误记为虚构日期或错误唯一回答。 |
| different-question | 明确请求能区分版本的事件日期，不是已获得最终答案。 | 可计有效澄清；只对真实首轮追问才考虑续轮。 |
| different-invented | 未知实际日时断定 2024 并只答一支；虚构日期、词面唯一结论、选边可同时为真。 | 三项各报，并集按每条回答去重，不能相加当独立错误。 |
| known-repeat | 用户已经给出事件日期，仍只问该日期。 | 记无效重复追问，不计有效澄清。 |
| known-other-wrong | 实际日期结论正确，但额外的另一日期分支有错。 | 实际日内容和整答错误分开；不能用前者代表整答正确。 |
| ambiguous | 文本是否声称实际日期无法稳定判明。 | 保留 unknown 和理由，不按猜测强行二分。 |
| conditional-and-question | 完整条件答与明确追问同时存在。 | 两项事实均记录；是否计一次追问续轮、交互代价如何计算待冻结，不能先改旧分数。 |

## 计数与标注接口

每条计划回答保留固定 ID、规则、案情、日期状态、路线、运行状态及评分版本。运行状态至少区分 `completed`、`truncated`、`failed`、`not_run`；内容与引用另用正确、错误、unknown 或不适用，并保存标注者、证据位置、分歧和原因。截断可做单独描述，不能自动当完整回复；未运行不是模型错误。指标需同时给计划数、完成数、可判定数及缺失原因；分母为零写未定义。主表按规则聚合，同一规则的不同题不能冒充独立规则。

缺日期回答的词面无条件唯一结论（B）与基于虚构实际日期只答一支（C）可以重叠：同时报告 B、C、交集及去重并集；有 unknown 时须报告 unknown 数，不把它默认为否。对于“两明确日期均对而缺日期失败”，同时报告全体组、满足明确日期前提的组和前提未知的组；说明筛选是事后描述性分析。内容、整答一致、引用 ID、语义充分性和格式分别记录。草案不规定尚有分歧的最终回复有效性聚合，也不追溯改写 v1。

## 每个来源的最低记录合同（待冻结）

1. 记录机构、文档标题、稳定原始地址、版本或归档标识、访问时间、获取方式和原始字节 SHA-256；若只能获得网页动态渲染，保存实际使用的可审计快照及其生成方法，不冒称网页原始字节。
2. 每段模型实际看到的原文单独记录来源标识、原文起止定位与逐字摘录、相邻条件和例外；检查摘录与固定快照一致。原文缺上下文、无法定位或依赖遗漏限定时标未解决，不以作者改写充当引文。
3. 将来源原文、上游适用／生效日期证据、作者限定的日期窗口、案情假设和作者参考答案分栏；分别记录定位、依据和复核状态。发布日期、抓取日期和适用日期不可互相代用。对跨页面或跨版本映射逐一记录证据和疑点。
4. 区分本地研究读取、向模型提供、发给复核者、公开再发布原文或派生材料等用途，分别记录权利依据、限制、核验时间、责任人及未解决事项；可访问不等于所有用途获准，未知用途不得标已批准。
5. 记录输入优先复核人的角色、相关能力、以往接触、独立性可能限制、日期和原始复核文件摘要；先保存输入复核，再关联输出。对参照、材料充分性和引用支持的分歧保留双方理由及处理历史；无复核时明确为知情作者判断。
6. 对相同规则两路线校验实际输入及来源元数据一致，保存模板、数据、代码和生成配置版本；复核材料及权限后再选未来规则。此合同是设计清单，既未证明任何来源权利，也不放行选择材料、扩样或运行。

## 未定事项

同答虚构日期整体是否计有效、条件答同时追问的成本归类、unknown 如何提供宽松区间、语义盲评流程与冲突裁决、具体来源许可和独立评审资源仍须在选择未来规则前决定并记录。仅有合成例和结构校验不足以证明评分者一致或协议可行。
