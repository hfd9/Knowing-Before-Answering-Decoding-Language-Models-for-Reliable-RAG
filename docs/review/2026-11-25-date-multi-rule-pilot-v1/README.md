# 六条未见规则的适用日期配对预实验

六条规则、40 格及 48 个适用日期分支在 CPU 运行前封存。核心格按每条规则一个缺日期同答、一个缺日期异答和四个明确日期配置，另以赠与和支票两规则测试范围不符及证据不足各一格。两条路线读相同的日期、规则依据、事实和人工整理的范围条件。本轮采用知情作者参照和历史官方来源，覆盖两种比较符。 [来源、版本和参照](sources.md) · [冻结评分协议](protocol.md) · [运行前锁](freeze.json)

## 冻结抽取的失败定位

冻结路线辨认出六条的比较符，但在采购、众筹和赠与上把范围段误配给一个版本角色。受影响的 20 格全在后续区间解析处停止，原因均为选出的版本段没有两个可核对的日期。这使三条受影响规则各自的异答格没有形成追问或决策。支票、并购和管辖金额三条的全部 20 格通过，两个支票范围控制也通过。

在已暴露的题面上另做版本角色诊断。只让同时含两个覆盖日期和一个整数美元值的段落进入版本候选，从中确定先后。剩余两个段落仍用原有比较与范围分数分配角色。只换定位时，严格结果为 21/40。新增的一格来自已有缺省的范围未知与一条控制参照相合。重新运行原先缺失的 33 个范围选择后，严格通过 40/40。此过程复用预实验的 24 个定位记录及 36 个已生成的抽取选择，保留所有原结果。新增 33 次候选前向、6,111 输入 token、106.88 秒。该诊断的候选条件从这批失败归纳，且依赖题面规范化的日期段。 [诊断实现](version-diagnostic.py) · [逐格诊断](version-diagnostic.json) · [诊断归档](version-diagnostic-raw.zip)

## 范围标注消融与核验

赠与和支票各两个缺日期格的直接路线，带和去掉范围陈述均严格 0/4、逐日结论 4/8、严格引文 0/8，四格均追问。这四格的结果不足以估计人工条件标注的总体收益。主对照仍让两路获得相同的范围条件。 [逐格消融](results.json)

冻结对照实际完成 40 条直接回答及 4 条消融生成，44 条均正常 EOS，输入 27,674 token、生成 3,373 token，生成阶段批次计时合计 731.76 秒。冻结抽取完成 24 个出处定位和 36 个抽取选择，共 60 个前向、13,056 输入 token、107.88 秒。另有已见 OCC 两条接口试跑和 33 个事后诊断前向。直接回答与补充诊断有并行执行时段，阶段计时作为运行量记录。原始包和补充包均重放逐项结果，15 项日期定向测试和既有跨条款重放通过。 [冻结原始包](raw.zip) · [运行器](../../../scripts/query_determinacy_date_multi_pilot.py)

## 研究去留

冻结路线在三条规则上复现出有据答案和追问，另外三条全部卡在版本出处分配。两个方法在异答错误唯一上均为 0/6，这批结果暂时无法比较该错误的改善。正式主实验暂停在预实验结论。事后日期段筛选值得作为明确候选固定，随后用整条未暴露规则复验。该复验宜保留有日期或金额的非版本段，检验筛选能否处理干扰。当前样本只有六条、所有门槛均上调、范围陈述与日期段有人工作业，独立参照仍缺。 [逐规则对照](results.json) · [范围与版本来源](sources.md)
