# 六条新规则的适用日期配对预实验

## 样本与比较

沿用第四版实现、提示、求值器和 Qwen2.5-3B-Instruct 模型环境。以六条完整的新规则为单位评估，`<=` 与 `>` 各三条。每条有一个缺日期同答、一个缺日期异答、四个明确日期对照，共 36 个核心格。赠与和支票各增两个范围控制，总计 40 格、48 个参照日期分支。留出规则和本批任何变体均不回流到冻结实现。题面只测试两段已分开的版本、给定两个相邻可行日期、整美元门槛和带锚点的范围条件。[来源与参照结构](sources.md) · [原冻结实现](../2026-11-25-date-evidence-first-v4/freeze.json)

两条主要路线同题对照。强直接用同一模型在相同 E1–E4、F1 和范围陈述上直接回答，提示明确要求逐日适用版本、等号含义和各角色证据。冻结路线使用既有的定位、字段抽取、范围核查和确定性求值。人工核准字段接同一求值器用于区分输入失误和求值失误。直接路线使用贪心解码、最多 160 个输出 token。冻结路线使用既有下一 token 候选评分与共享证据复用。两路线分别记录实际输入、输出和前向成本。模型提示不含参照。

强直接接口先在已公开的两格 OCC 案情试跑。两条回复都正常结束且 JSON 可读，结论和引文仍有错。冻结前在直接提示中明确按案情金额核对当日门槛、每个分支只引当日版本，以及追问字段填写事件名。此次调整只依据已用案情。本批六条规则在锁定评分前没有模型输出。

额外配对在赠与和支票各两格缺日期核心题上，对直接路线去掉人工拆分的范围陈述，保留原范围摘要与其余共有信息。该小对照只测直接路线对显式条件的响应。当前冻结抽取流程把范围陈述作为输入，删除陈述会按接口返回范围未知，独立的自由原文抽取是后续问题。

## 冻结评分

共同严格终点要求动作、所有适用日期的结论及证据、追问事件或未解决原因与参照一致。按日期分别计结论、引文及二者同时正确。分别计异答错误唯一、同答无谓追问、范围控制错误唯一、明确日期正确有据。保留截断或格式失败，依据明确的最终动作另计错误，避免把格式失败算成安全行为。冻结路线的字段准确率另报，主比较两路共同的面向用户结果。人工字段只作离线诊断。普通结果按六个规则族及配对格报告，不将同一条款下的多个变体当作独立规则。

先用程序逐格重演手写参照。给入相反比较符时检查逐日结论改变且被严格判据拦截。规则选择、来源、参照及评分在正式新规则 CPU 运行前封存。程序读取封存后原样评分，保留未决和失败。格式致失分若影响直接路线解释，允许按相同参照做带原文哈希的知情补核，并列保存自动评分与补核。风险判断关注逐规则收益、错误唯一、无谓追问和范围失败。样本与直接对照结果有跨规则证据时再决定论文主实验设计。
