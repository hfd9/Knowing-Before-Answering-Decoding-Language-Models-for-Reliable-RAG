## 用户执行

在项目根目录、GPU 0 空闲时运行一次。

```sh
time sh shared_pilot.sh
```

运行上限为 26 次、每次 512 新 token，最多 13,312 新 token。建议预留 10–25 分钟作为工程排期，含校验权重、加载、生成及落盘。历史改写结果每次最多 9 个输出 token，无法用于预测此次较长输出的实测总耗时。实际时长以终端的 `time` 及日志为准。已在本机 CPU 端准备 `runs/qwen2.5-3b-query-determinacy-shared-pilot-v1`，检查时进度为 0/26。命令会显示每个已写入槽的状态并打印最终计数。

跑完后报告最终计数及 `time` 输出即可，报错时报告首条 `STOP` 或最后的错误信息。若仅因 GPU 忙或显存不足而在预检时报错，可待设备空闲后重跑同一命令。若出现空输出、截断、模型异常或中断，请保留运行目录，我会核验已有日志再确定处置方式。数据收集完毕后先做 CPU 重放和封存，再核对抽取、逐世界答案、引用、结论和路线成本。若依据两题的输出调整提示、材料或评分，这两题独立记录为工程试跑。
