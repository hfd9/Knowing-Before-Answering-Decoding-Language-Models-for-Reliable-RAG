# 目标绑定与表面线索：可识别性和研究去留

2026-11-12，Asia/Shanghai。应用户要求继续处理研究问题：定向查证直接近邻，建立符号级对照及竞争预测，审查能否在现有门禁内继续。此文件是研究设计分析，不是数据集、执行协议或运行许可；没有创建实验题目或调用模型。

## 判断

**存在一个可检验的、比“probe不稳健”更具体的问题，但仍不能宣称新颖或已具备确认条件。** 在同一问题及相同逐文档词项计数下，仅改变实体和值的配对，固定证据状态读出是否区分目标充分与目标冲突？这能排除仅使用所定义的逐文档无序词袋的解释，但不能排除词序、邻接、位置、句法或其他结构线索，也不能识别模型内部绑定机制。缺证需要另设计，不能由这个两状态对照自动推广。

研究对象为既有 Qwen2.5-3B-Instruct P0末提示token零基L28冻结三分类读出。此问题针对的是**这个读出的测量能力**，不证明模型没有提取关系信息；读出失败亦不能证明所有 probe 或隐藏状态都不含信息。v2尚无输出。

## 符号对照：区分什么

以下是逻辑示意而不是自然语言材料。假设A、B为不同实体，x、y为不同值；每行表示一篇文档明确陈述的实体—值关系；问题固定为A的值，且目标字段同一时间同一范围、每个实体只有一个值、两篇来源无优先级。其他问题、背景及文档固定。

| 状态 | 文档1 | 文档2 | 目标关系 |
| --- | --- | --- | --- |
| S | (A,x), (B,y) | (A,x), (B,y) | A只有x，两篇一致 |
| C | (A,x), (B,y) | (A,y), (B,x) | A同时有x和y，冲突 |

逐文档词袋在S/C完全相同：A、B、x、y各一次，文档1也完全相同。简单Python `Counter` 对两槽检验均为真，按A抽取S的目标值为{x}、C为{x,y}。这是对符号关系及计数的核对，不是对自然语言理解或真实tokenizer的认证。该对照同时使B发生冲突；如果不希望非目标也冲突，需要另行设计并证明，不能把这里当作仅改变目标一个关系。

在固定自然语言模板实现时应检查完整提示与每槽token计数、标点及真实tokenizer；单个占位符置换不保证BPE token数相同。S/C的精确词序和相邻实体—值组必然不同，S的两文档完全重复而C不完全重复：**逐槽词袋相同不等于文档序列重复度相同**。仅凭该对不能归因重复度、实体绑定或其他单一因素。

## 竞争解释与判别范围

| 解释或模型 | 对符号对照的可检验预测 | 若观察相反能说什么 |
| --- | --- | --- |
| 严格逐槽词袋不变的函数 | 两输入输出完全相同，包含各类别分数；假设输入可归结为指定词袋且其余完全相同。 | 分数不同可排除**这个严格不变类**解释，不能排除利用局部词序或位置的表面规则。 |
| 正确目标关系分类 | S判answer，C判conflict；对交换符号及顺序等已审核保持变换持续成立。 | 任一不符是该固定读出在该条件上的反例；没有差异不证明内部无关系信息。 |
| 位置/局部邻接启发式 | 可利用文档2的两个局部配对变化，有些具体规则也会恰好产生正确类别。 | 单一S/C对正确无法排除这类规则；需多次平衡目标、赋值、提及顺序、来源位置，再具体写出规则及预期。 |
| 内部语义绑定机制 | 不对现有观测提出唯一类别或分数预测；语义和简单局部规则在此例可同时成功。 | 输入级变化只证明该输入扰动影响读出，不能定位或证明内部机制；机制性干预属另立研究，现不开展patching。 |

候选后续设计应包括：身份及值标签的成组重命名、各文档关系顺序和文档顺序平衡；独立审核目标关系、时间范围及表达保持；明确非目标冲突处理；事先列出具体词袋/位置/邻接规则和失败分母。以底题为单位报告同题读出、类别及分数，保留unknown。若任何规则需要从数据拟合，须先单独确定训练隔离和预算；原拟合预算仍为0。这个清单不构成批准的新实验协议。
