# 原文抽取与直接答复的开发对照

冻结两个已见条款及六个开发格。每个条款各有缺日期同答、缺日期异答、明确新日三格。显著事实写在 F1。E1–E3 为与出处相绑定的原文短摘，E4 为人工范围摘要。两条路线共用完全相同的规则、案情、日期和问项，区别是末尾接口要求。新材料只作已见条款的开发检验，原六格另作回归。两个条款均以贷款成立时点控制，新检验包含 `>`、`<=` 与两个等号边缘。[公开输入](public.json) · [逐字段来源及知情作者参照](reference.json)

强直接路线由模型给动作及各可行日期的结论和证据；抽取路线由模型单独给比较符、控制事件、规则引用、范围与范围引用、金额、允许区间、已知日期、两个版本及各自引文。提取格式的一般标识和合法类型可核查。所有字段取自模型输出，传入现有确定性求值器，运行中不读作者字段或法律答案。每个逐版答案需绑定规则短摘、适用年度条目、范围摘要与案情，只有两分支均有据才能严格通过。询问必须指向成立日。比较符、金额、有效边界、已知日期等逐字段另计。分出处与等号边界为主，解析失败、未解决及错误唯一分别计数。对异答缺日期格，即使分支行无法解析，可识别的唯一答案也计入错误唯一。

开始生成前，在相同求值和评分路径运行人工核准字段对照以及旧 `>` 替代 `<=` 的负对照，核查前者命中参照、后者在动作一致时仍被判严格失败。用范围不明、覆盖空档、重叠三个程序对照验证不输出唯一结论。现场采用本地 Qwen2.5-3B-Instruct CPU FP32/SDPA、16 线程、贪心、复用之前的最长 160 token 的采集器。每格每路线一条，共 12 次实际调用。保留所有技术或语义失败，不根据是否过线重跑或改评分。人工核准字段一路为定位用对照，无模型生成。

若原文抽取仍出现无依据的唯一答案，先定位并留在已见规则。只有抽取路线提高严格有据结果，在既有边缘未产生错误唯一答案，并完整保留两条规则的同答和异答覆盖，才推进按整条规则留出的准备。单模型及知情作者参照限制研究解释。无拟合或 GPU。原十题继续暂停，380 底题正文封存。
