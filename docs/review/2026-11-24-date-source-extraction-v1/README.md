# 两条已知规则的原文抽取开发对照

本轮把原文信息到结构字段的环节单独拿出来测试。两条路线读相同的 E1–E3 原文短摘、E4 适用范围摘要和 F1 案情。强直接路线给出答复动作及逐日依据。抽取路线给出比较符、事件、范围、金额、可行与已知日期、两个有效区间及证据编号，再接入原结构化求值器。参照路线使用生成前核准字段。两个条款与规则类型此前均已见，每条款测同答缺日期、异答缺日期、明确新日三格。原问答包作为回归，当前六格是开发用改写材料。[协议](protocol.md) · [共同题面](public.json) · [参照及来源](reference.json)

## 生成前核验

人工核准字段经求值和相同评分为 6/6。此前四个 HPML 金额在错误地沿用 `>` 时，四个答复类型仍相同，本轮评分逐项拦下这四个错误。当前三个估价格的同类替换也都未通过。范围不明、两版覆盖空档和重叠分别给出对应的未解决原因。六对路线消息除接口说明外前缀相同，真实 tokenizer 渲染为 498–561 token。两路线格式用合成输出联检。原材料、跨条款检查、既有核验入口，以及 15 项既有定向单元测试均通过。[冻结清单](freeze.json)

## 首版接口

实际 12 条均正常 EOS。强直接 6/6 只交出 `Q|consummation`，没有动作行、逐版结论或引文。抽取 6/6 也无法进入确定性求值器。三个一般金额格中可辨认的年度门槛和区间片段分别正确，仍缺少完整事实行或规则行；三个估价金额格混用行标和控制事件占位词。首版两路线严格结果均为 0/6，且各有 6/6 接口无效。这个 0/6 表示没有可评分的完整回复，弱化了方法比较。保留首版 12 条，另行封存接口修复版本。[首版逐格评分](results.json) · [首版原始输出](raw.zip) · [修复前决策](interface-recovery.md)

## 修复版同题结果

两路线共 12 条新输出。直接线路改用自由文本，抽取改用带键名的 JSON，生成上限从 160 调到 256。首版和修复版各自封存，接口变化和 token 上限变化无法分别归因。修复版 11 条正常 EOS，A1 直接回复达到上限。直接回复经知情核读，逐格以输出 SHA 绑定。抽取依据同一规则程序自动读取。 [修复版原始包](recovery-raw.zip) · [自由文本核读](recovery-direct-review.json) · [逐项评分](recovery-results.json)

| 修复版路线 | 严格正确且有据 | 无效或截断 | 缺日期异答格给出错误唯一结论 |
| --- | ---: | ---: | ---: |
| 强直接 | 0/6 | 1/6 截断 | 2/2 |
| 抽取加确定性求值 | 0/6 | 6/6 字段不完整或无法核对 | 0/2，均未产生答复 |
| 人工核准字段加同一求值器 | 6/6 | 0/6 | 0/2，均正确追问 |

强直接的 G2 已说新门槛高于案情金额，仍判新日豁免并合成唯一答案。A2 将每个年度门槛与它自身比较，忽略案情金额，同样给出错误唯一答案。G3 正确说出明确新日时金额低于门槛，却错误判豁免。A3 在新日等号边界的结论正确，少引比较符证据 E1。按可见标签和结论方向计 3/6，包含一条截断前可辨认同答结论。

六条抽取都返回了完整 JSON。字段内容的事后核对见下表，保留原严格评分。六条均识别成立事件、已知日或缺日期以及两版的门槛和年度起止日。三个一般金额格均提取 `>` 和案情金额，G3 把整个可行区间缩成了已知日。三个估价格的 `<=` 与案情金额均为 `null`，并把候选区间起点写成规则年度起点。六条均把范围标为 `null`，没有提供完整的范围、规则和案情证据编号。有些引用写成条款号，规则和范围概要共用相关条款号，因此程序要求按题面定位实际证据。仅 G1、G2 同时给对比较符、事件、金额、可行日期、已知日期、年度阈值及区间，仍缺完整范围判断与证据绑定。

| 修复版抽取字段 | 逐项正确 |
| --- | ---: |
| 成立事件、已知日或缺日期、两个门槛及各年度区间 | 各 6/6 |
| 比较符、案情金额 | 各 3/6 |
| 可行日期范围 | 2/6 |
| 范围判断、规则证据编号、两个版本的证据绑定、案情证据编号 | 各 0/6 |

两版共完成 24 次真实 CPU 生成，23 次正常 EOS、1 次截断。首版输入 6,320 token、生成 644 token，修复版输入 5,618 token、生成 2,534 token，生成数含 EOS。批次计时分别为 210.88 秒和 1,192.35 秒。前置人工字段对照与修复版的实际字段对照把停止点定位在原文字段抽取和证据绑定。保留该开发诊断，整条规则留出条件未达到。没有新模型或法域上的性能指标。
