# 同题接口修复

首版的首六条直接输出都正常结束，但都只写 `Q|consummation`，没有动作或分支。首批抽取也把行标、日期和引用格式混在一起，无法把原比较当成强直接或完整抽取的有效对测。完整首版照常封存和评分。

同一开发阶段另存一次接口修复。六格共同题面和严格评分保持原样。强直接改为短自由文本，核读是否给出正确动作、所有适用日期下的结论、所需证据和明确的成立日追问。引用格式不限，逐分支仍需支持相同事实和作用。无法明确映射的字段保留未知。抽取改为带键名的紧凑 JSON，严格字段、逐日求值和最终评分沿用首版口径。模型不接收人工参照。在读取本版输出前锁定这一版两套提示和程序。

两路线使用相同的本地 CPU 模型、贪心、16 线程、FP32 和最大 256 个生成 token。各格各调用一次，共 12 条。接口修复有首版输出暴露，两版结果分别记载。没有有效强直接对照、抽取严格结果未改善、同答与异答四格未完整覆盖或发现错误唯一答案时，停止于开发诊断。自由文本由知情助手复核。
