## 可观察的失效

- **把缺失日期当成已知。** 直接路线对 SEC 同答题称日期为 2021-08-16，并称另一日无法判断；对 IRS 同答和异答题均写日期为 2024-01-01，尽管题面明确说未提供。三个回复均只处理一个自选日期，不能作为完整跨版本结论。
- **完整条件回答可以成立。** SEC 异答缺日期的直接回复分别给出旧日满足、新日不满足，与作者参照一致并引用 E1/E2；该形式不是无谓追问或错误唯一答案。引用对各命题是否充分仍须独立语义复核。
- **逐版比较也会比较错。** SEC 异答与 IRS 异答的逐版缺日期回复都给出两版相反于作者参照的结果；IRS 同答题把等于旧门槛错说为超过。它们虽然逐版列出内容，不能因此算正确。
- **已知日期不保证无矛盾。** SEC 异答两个已知日期的直接回答均在同一输出内先后给出相反的实际日结论；不能只取末句。其他已知日期题中亦有错绑版本或把相等当超过的情况。

没有 8 条缺日期回复明确请求用户提供事件日期，按固定协议不生成追问后续轮；追问后最终正确率分母为 0，记未定义而非 0%。标为有无追问是助手阅读后的知情判断，非独立评审。

## 证据与解释边界

本轮已记录每条回复的 E/F 引文 ID，尚未对 24 条逐命题执行独立盲评，不能把内容正确率称为严格有据率。题目事实直接给出金额和时间，语义评分与是否显式引用 F1 分开。SEC 旧日直接回复引用新版本就是一个可观察错绑；源摘录较短，原文语境、作者提供的版本元数据和法律适用范围也需要共同检查。真实来源权利的全部派生用途及独立法律复核仍未闭合。

四道缺日期题、16 条已知日期对照只来自两条规则；不是 24 个独立规则。两路线用同一 7B，但同一题按固定次序独立生成，顺序未随机；不据此推广总体准确率、方法优越性或表明更强模型均会失败。旧冻结 3B 管线不兼容本材料形状，未做同题第三路线。无真实检索，不能评价检索覆盖或漏版。
