# 真正具备版本形状的范围干扰

前一批冻结材料的金额加日期干扰使用 `$17, for`，旧正则由于金额后的逗号未识别到美元整数。保留该批全部输出，另固定本批校正版本。在相同两条法规的范围段写入 `$17.` 后另起句给出两个日期，使范围段同时满足两个日期和一个金额的版本候选语法。其他证据、原案情、人工参照、冻结候选、直接回答提示和评分不变。两条法规各六格，共 12 格。本批在看过原批冻结抽取结果后构造，作为有暴露的干扰测试单列。

原候选应对每条规则返回版本形状歧义，后续求值应未解决。直接路线仍独立处理相同的新增范围段。记录完整模型输入、输出、出处选择和分支评分。候选按可用性、未决、错误唯一和严格指标报告。
