# 两题简化输出 GPU 复跑

按用户要求，将[简化约定](../2026-11-23-shared-pilot-results-v1/simplified-output-contract.md)接入两题工程复跑。数值 D7M4 和类别 N3K6 各三问，固定三条路线共 26 个计划槽。沿用原模型、512 新 token 上限、贪心解码和已有抽取解析器。两题已在原工程试跑中暴露，用于检查格式可读取性、证据和逐世界错误。其余十题继续暂停，数值程序基线等新格式的判断结果出来后再决定是否加入。

新版本为同一背景的原文来源和类别规则加上 S/R 编号。生成时只用公有材料及实际抽取。直接和联合每问生成两条世界行与一条最终行，分支每次生成一条世界行，评分时才合成。执行按同一 schedule，实际抽取每底题一次，联合及分支共享。提示、日志、解析、评分和发布范围由[发布文件](release.json)的摘要绑定。复跑使用独立的新目录。原调查以旧结果及[逐题错误表](../../records/2026-11-23-shared-pilot-error-table.md)为依据。

评分先封存，再读取已绑定的知情参照。分别保留格式、实测候选绑定及参考候选一致性、逐世界正确性、证据支持或反驳、合成与最终标签一致性、异答选边、未解决及成本。证据判定限定两道题的作者参照和精确的来源与规则跨度。新版用证据编号，旧版要求复抄整句，跨版本严格分数的变化涉及合同变更。模型判断比较使用单列的世界标签和最终标签。工程可读目标为每条路线 6/6 问，随后再评估判断与引用质量。

用户在本仓库根目录、GPU 0 空闲时执行一次。

```sh
time sh shared_lines_pilot.sh
```

预留约 5–10 分钟用于排期。上轮同规模的 GPU 预检到最后记录为 23.32 秒，权重校验、启动、末次重放及新输出长度可能改变总耗时。运行实时核查 GPU 0 无计算进程、至少 10 GiB 空闲显存及 BF16 单卡可用。有无效抽取则记录并跳过对应下游槽，遇到空输出、截断或其它生成异常则保留现场停止。设备忙或显存不足在预检时报错时，设备空闲后可重用命令。其他异常请保留目录并报告 `STOP` 信息。完成后报告最后计数，助手核验并评分。

CPU 验证覆盖 26 个测试，包括旧 26 条输出和 18 条显式标签回归、新版 26 槽模拟、错误抽取、截断、来源跨度、证据和语法错误及未提交 attempt 阻断。[实测 tokenizer 检查](cpu-token-check.json)覆盖 26 个提示，使用旧日志的抽取值模拟动态输入，174–331 输入 token。模型七文件和五个依赖版本匹配原发布。CPU 初始运行目录为 `runs/qwen2.5-3b-query-determinacy-shared-lines-pilot-v1`，0/26。真实生成及对可读性的判断待用户执行。
