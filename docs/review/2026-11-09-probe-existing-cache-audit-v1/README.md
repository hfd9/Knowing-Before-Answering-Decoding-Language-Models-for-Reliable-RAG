## 同表达的证据关系：概率方向与类别同时报告

原作者判定暂可接受的S→I关系删除/弱化有58对、29底题；另2对S的义务范围unknown。58对中目标refuse概率上升51对，S/I两端类别同时符合作者参照仅4对，23对两端均不符；58对输入长度全部发生变化。剩余两对也保留在[180对表](relation_pairs.csv)，不能把S的unknown转成错误或正确。严格正差含微小变化，不等于稳定可靠分类。

作者认为S→K兼容支持的58对中23对两端符合参照、27对两端均不符；作者判定的S→C全部60对中目标conflict概率上升54对，但S端2对unknown，已知58对中15对两端均符合参照。所有配对仅是同一30底题的变体，不能当作独立题目。既有[事后配对报告](../../records/2026-10-21-semantic-transfer-paired-analysis.md)已有概率均值、整底题bootstrap及行为分析；本次连接了先前作者验收状态，不另做统计显著性检验。

## 已知混杂与接续决策

原52、80、50单元开发诊断均已完成。此前10个val底题的[输入变化](../../records/2026-10-20-probe-input-shift-verified.md)显示问题和整组文档的变化均可改变读出，但文档包同时改变多个因素；[文档三因素](../../records/2026-10-20-probe-document-factors-verified.md)中预定尾句、背景集合和整体循环均未翻转类别，概率仍有明显变化；[支持事实表达](../../records/2026-10-20-probe-support-expression-verified.md)中六个底题的冗余否定在两种表达下均使conflict概率上升，同时增加20–28 tokens。后者尚无等长度非否定后缀对照：不能把变化单独归因于否定措辞，也不能断言纯长度已经解释它。

当前证据支持冻结probe对证据编辑和部分表面输入变化有响应，也显示其类别与作者参照存在系统失配；尚不能判定隐藏状态只有语义信息或只有构造痕迹。A/B判定稳定并不能弥补参照与独立性限制，行为和读出不一致也不证明生成器使用或忽视某一内部信号。

已进一步对上述六个既有底题构造**仅检验增加文字与否定后缀相对差异的等token长度控制**：保留同问题、背景、两个目标核心及顺序，比较原正面核心、既有否定后缀和有暴露助手构造的中性附注；12对完整prompt token数均相等，不能把等长度视为词汇、位置或语义完全控制。[材料与用户GPU入口](../2026-11-09-probe-neutral-length-control-v1/README.md)已完成CPU准备，真实新前向尚未执行；不会将其称自然泛化或证实否定词因果机制，也不因此重训或扩充底题。
