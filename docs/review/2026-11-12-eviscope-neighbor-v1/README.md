## 原文的具体内容与局限

Deswal 的论文报告 EviScope-v1.1 使用40个源自 SQuAD 的底题，每题充分、含噪、不足、冲突四条件，共160输入；固定问题并通过加入干扰、移除支持或插入矛盾改变证据。其 quartet consistency 要求同一底题四条件均采取正确行动（充分/含噪还要求正确依据）。这是**跨状态和噪声条件的行为联合成功**，不同于本项目候选的**各状态两种语义保持表达均被冻结 probe 正确分类**；两者都以底题为相关单位。

论文称两位外部评审独立、在隐藏来源角色和标签的材料上审核全部160条；报告证据状态及预期行为评审者间一致率0.994、冲突存在一致率1.000。论文同时说明对具体支持文档/片段的外部验证有限，且材料为小规模、SQuAD派生，冲突未涵盖来源权威、时效及多文档综合。以上是**论文报告**，本轮未取得审核原件、复算或认证其隔离。原文[方法及局限](https://arxiv.org/html/2609.17081v1)比仅看摘要更接近本项目参照需求，但原标注不自动认证新增编辑或表达关系。

论文报告 Qwen2.5-7B 两种提示的四条件联合成功0.50与0.15，研究的是生成行为，不能转为本项目 Qwen2.5-3B L28 probe 表现；它也没有提供本项目 v2 的读数。论文页所示 CC BY 4.0 是论文许可，不能由此推定派生数据包或底层 SQuAD 内容的全部使用、改写和再发布权利。
