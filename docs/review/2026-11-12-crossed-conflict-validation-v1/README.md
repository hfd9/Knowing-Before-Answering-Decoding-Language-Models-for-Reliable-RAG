# 目标冲突候选：交叉符号验证与近邻

2026-11-12，Asia/Shanghai。用户要求直接验证问题相关与无关冲突的研究价值，并检查固定问题、固定文档下的简单规则。本轮只做符号枚举、预设函数的逻辑核查和定向文献阅读；没有构造确认题或执行probe。

## 交叉设计的实际检验

沿用[三实体符号条件](../2026-11-12-target-conflict-symbolic-v1/README.md)：文档1固定A→x、B→y、C→z；文档2在三个只交换两个值的排列中选择。每个排列对三个实体各问一次，共3文档组×3目标=9个符号行。每个文档组恰有两个目标冲突、一个目标不冲突；每个目标跨三个文档组也恰有两个冲突、一个不冲突。

实际运行 `python3 -B docs/review/2026-11-12-crossed-conflict-validation-v1/symbolic_checks.py` 退出0，核对：

| 检查 | 符号结果 | 含义 |
| --- | --- | --- |
| 固定两篇文档，改变目标 | 6个目标冲突—非目标冲突对 | 只看文档、不看问题的确定性分数在每对上必然相等；问题本身变化。 |
| 固定目标，改变第二篇文档 | 6个目标冲突—非目标冲突对 | 只看问题、不看文档的确定性分数在每对上必然相等；文档关系变化。 |
| 冲突实体数及词袋 | 每组两实体冲突；文档2均为A/B/C/x/y各一次 | 全局冲突数及逐文档无序词袋相同，但不能排除关系顺序、局部邻接与位置。 |
| 固定目标比较的替换范围 | 6对均改变文档2的全部三个实体—值赋值 | 不是单个赋值的最小干预。 |
| 分类别 | 9行中6目标冲突、3非目标冲突；只看文档或只看问题的最优分类率均6/9 | 不能把66.7%当作目标关系能力；在各自固定组内，常量分数的配对排序按平局计半为0.5。 |

配对和行共享材料，6对及9行不是6或9个独立自然底题。这里只验证指定的三排列、三目标，无随机化或统计估计。若预测函数随机，固定输入的分数不必逐次相等；需固定确定性执行或单独测随机性。若采用决策类别而非连续分数，平局计半是候选评价定义，不是已固定协议。

## 可排除的规则和不能排除的规则

固定文档比较针对文档单独函数；固定问题比较针对问题单独函数。二者联合能暴露一些单侧捷径，但无法证明模型采用目标绑定：例如无需拟合的规则可读取被问实体在两篇文档中的赋值并比较，能在符号任务达到9/9；一个依赖固定相邻位置的文本模式也可能在固定模板中成功。符号程序可以给出设计参照，并不能被称为新自然语言实验金标准。

同时，若无条件把两份有矛盾的来源断言合并为经典逻辑真命题，会发生爆炸原理，不能由此定义“B/C冲突与A无关”。此处的目标参照是**按来源记录各实体的候选值**：A跨来源候选值为单一值则目标充分，A有两个不同值则目标冲突；不要求所有来源断言同时为真。它是刻意限定的证据状态任务，是否适合实际RAG场景须论证。自然语言材料必须明确实体独立、同字段与时间、不同值、来源无优先级、无跨实体唯一分配约束；否则非目标冲突可能改变目标答案或使状态unknown。

## 下一步条件

符号验证支持继续检查自然语言落地的可行性，但不自动放行造确认材料。需要先核查旧标签及应用允许的非目标冲突处置、合法且未暴露材料范围、独立参照与实际评审资源、目标用途容差，定义多个被预测的简单规则，审视残余位置线索；近邻范围及论文价值也要进一步确定。现有已暴露材料不能作为新确认集。
