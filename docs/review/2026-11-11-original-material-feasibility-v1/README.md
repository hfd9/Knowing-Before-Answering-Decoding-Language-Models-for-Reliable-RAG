# 原创受控材料：研究增量、评审资源与去留

2026-11-11，Asia/Shanghai。用户要求只做纸面可行性判断，不先造题或启动实验。本报告引用既有项目记录与定向原论文，不新建样本、评审包、实验协议或模型输出；判断者已见项目历史、读出和结果。未实际测试新的评审会话、服务、人员、价格或GPU环境。

## 决定

**暂停为该方向构造新的原创确认材料，以[现有综合报告](../2026-11-11-frozen-probe-synthesis-v1/README.md)作为阶段成果。** 候选问题可证伪，原创材料有利于控制来源和关系，但当前还没有证据表明具备满足拟定确认用途的独立参照、审核资源、预定容差及足以超出强近邻的实质增量。可选择未来重新审视；这不是证明独立评审不可能，也不是认定所有原创材料无价值。条件未成立时不先构造材料，再以看到的结果推定值得实验。

## 1. 研究用途和问题

固定对象为本项目 Qwen2.5-3B-Instruct、P0自由回答chat输入、末提示token、零基L28、已有scaler/线性分类器/原sigmoid校准及三类argmax。潜在应用是**测量限定范围内的输入证据状态**，不是让probe控制模型生成或解释隐藏状态如何导致行为。

待评估的问题是：在事先界定的五文档和题目分布中，同一底题的充分S、缺证I、目标冲突C及各自两种经审阅保持关系的表达，冻结读出是否在每个状态同时达到预定的参照一致性与表达稳定性要求？正确与稳定分开：两端同类但都不符参照不能算成功。底题而非变体是统计单位，需保留逐状态混淆、两端符合/一端/均不符合、unknown及失败分母。连续概率变化只能描述方向，不是已验证语义置信度或机制证明。

可反驳方向必须预先绑定用途及精度：如果参考、覆盖和样本设计合格且预定失配率或区间不满足用途容差，固定配置在该范围的可靠测量用途不成立；若预定界限达到要求，只支持相应范围，不证明隐藏状态或其他任务。**现无经论证的容差、底题数、分布或审核预算**，不能用旧结果挑阈值；本段是判断问题，不是已锁定试验设计。

## 4. 原创材料的权利、覆盖和成本

自行写虚构场景可减少对受限制外部文本的直接依赖，但**原创形式不自动证明著作权归属、公开/外发权、无复制或没有预训练相似性**。将来需按实际作者、工具、参考材料及用途记录来源和权限；如借用外部文章或服务，还须分别核查条款。它也降低自然性：单一模板、合成名称和可被识别的状态编辑可能被probe利用，不能当作自然域评测。应在前瞻确认前完成明确范围、底题级分割及已允许材料中的近重复检查，不触碰380封存正文；380相关风险仍unknown。

成本必须包含材料编写/溯源、每个状态及表达的完整输入审核、分歧处理、记录与质量控制，而非只看少量GPU前向。过去[评审与数量级分析](../2026-11-09-probe-source-feasibility-v1/README.md)给出的39/80底题、每题六输入和双评仅是特定零失败假设的数学示意，不是可用预算、推荐样本量或预期效果。没有新的审核工时、服务报价或有效覆盖率实测，GPU耗时也不能由旧短输入或单条桥接保证。未来必要GPU由用户执行；原拟合预算0不因新材料或目录恢复。无权限或预算证据时不做确认承诺。

判定：存在**可证伪的特定配置测量问题**，但当前没有足够证据证明其超出已有工作的组合有实质论文贡献。若未来仅能做另一批同模板合成样本，且评审仍为知情作者或无法证明分布增量，预期主要得到另一项局部诊断，不能作为确认或自然迁移；不值得据此默认扩大工作。若未来实际落实独立可审计参照、足够不同而受控的表达和可预先确定的用途/资源，再重新比较近邻与价值，不以本报告视为放行。
