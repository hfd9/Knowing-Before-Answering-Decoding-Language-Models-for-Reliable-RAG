# 现有probe材料：语义参照与文本线索的进一步检查

2026-11-11，Asia/Shanghai。用户希望沿既定RAG内部状态研究继续，并在完成后明确下一步。本轮复用既有6个原创底题×S/I/C×A/B的36个输入及其已保存probe结果；没有新建输入、重新评审、模型前向、拟合或GPU。下面的计算是**看过构造和结果后的事后探索**，不构成确认实验或新的放行决定。

## 新发现：同批材料有很强的文本重复线索

对每个输入，取最终五文档的第1、2槽，将英文转小写，用ASCII字母/数字连续段切词，去重后计算两槽词集合的Jaccard相似度 `|交集|/|并集|`。例如数字时间中的冒号会被切开；该指标不使用模型tokenizer，也不是语义相似度。槽位是检查过材料构造后选择的，指标也是事后选的。每个状态有12个输入，但它们来自同样6个底题、每题两表达。

| 作者构造状态 | 输入数 | 槽1/2 Jaccard范围 | 均值 |
| --- | ---: | ---: | ---: |
| 充分 S | 12 | 0.053–0.250 | 0.161 |
| 缺证 I | 12 | 0.056–0.214 | 0.154 |
| 冲突 C | 12 | 0.692–0.857 | 0.793 |

在每个同底题、同表达的对照中，C的相似度高于S，为12/12；C也高于I，为12/12。原因可直接在材料中观察到：C的槽2复用槽1的陈述框架并替换目标值，而S/I的槽2是另一条背景记录。这个固定槽对上的词汇相似度在本批对C与S/I**没有范围重叠**。它说明本批构造存在可见的、与状态同步变化的表面线索；这不是在未见数据上训练或验证出来的分类器，也没有选阈值。

这个发现使解释更加具体：新批12个C都读成`conflict`，既可能与冲突关系有关，也可能受重复句式、目标值、格式或它们的组合影响。现在没有把这些因素隔离开，**不能据上述相关性断言probe使用了词汇重合，也不能否认probe使用了语义信息**。其他状态、自然文本、其他槽位、其他prompt或模型能否出现这种范围分离均未知。绝对槽位置和两条语句的选择本身可能影响结果。

[36行明细](overlap.csv)保留各输入的交并集大小、相似度、原probe类别及conflict概率；[计算代码](audit_text_overlap.py)和[机器结果](audit.json)记录方法、来源哈希与分母。脚本没有加载probe、拟合或搜索阈值。另用独立短脚本以另一种词切分实现重算36行的交集、并集及相似度，全部一致；两条计算共享原输入，不是独立材料或语义审阅。

## 语义参照：目前能证明到哪里

已完成的[逐题参照复核](../2026-11-11-phase-one-research-gate-v1/semantic-audit.md)检查了36条最终五槽、作者判断及72处引文。缺证判断除了检查未直接给出答案，也按每题检查五槽可否推出唯一值：以已有S/C的两个值仅作思想实验，两个不同取值都可满足I材料的唯一值规则。具体还保留03题“both quays”指代和06题类别名称必须按题内声明理解等边界。这使作者侧结论更可追溯，但审阅者看过结果，引用匹配或假设解释不能替代独立语义评审。

可执行的**参照审核需要解决的问题**已经具体化，以下不是已运行的协议或新增批准：

1. 对每条完整最终输入，评审者要指出问题的实体、字段和条件，分别检查全部五槽；对S引用支持值，对C引用两个相同条件下互斥记录及无法消解的依据，对I解释为什么多个可能目标值仍与全部材料相容。
2. 对A/B分别判断目标及证据关系是否保持；保留`unknown`和分歧。两端都判正确、一端正确、两端不符及类别翻转要分别呈现；不要在连接probe预测后调整原判断。
3. 独立性只能按实际证据报告：评审前固定材料和记录可见范围，保存逐条理由、引文、未决项及原始输出，先封存再连接状态和probe。两个进程、文件夹或同一模型的多次调用不自动证明认知或错误独立；材料本身的重复句式也可能暴露状态。
4. 当前没有已经落实的独立审核者、覆盖率、费用、决定者或经认可的误差容差；也未建立合法的新确认材料与对380的碰撞处置。因而现在不能把上述步骤当成已实现的审核资源或正式金标准。

## 后续对照应回答什么

最有价值的下一项问题是：**在可审计语义参照下，若尽量保持槽位、长度和重复结构，而证据关系改变，固定probe的类别和分数是否仍能区分状态？如果证据关系保持而表达变化，结果又如何变化？** 两种能力需分开核查，再报告是否同时正确；不能只用连续概率上升或类别不变作为成功。

可考虑的控制逻辑是：在同一问题和目标字段下，比较两份高度相似但支持相同值的记录，与两份同样高度相似但支持不同值的记录；另比较目标缺证但同样具有重复结构的材料。需检查是否引入其他可推断答案、歧义、不同文本长度、槽位或格式线索。仅有这些直觉还不是有效对照：真正要运行前需证明最终文本的语义、等价关系、对照差异和适用范围，并先处理参照、材料权利、未暴露底题、资源与研究增量。若使用新材料或模型前向，必须另立适用的设计和门禁；不能把本批事后指标当作预注册结果或用它挑阈值。

只有当这些条件实际成立时，才值得评估是否需要新的确认协议和用户执行GPU；不要求先重跑本批37次前向。若无法建立独立参照或对照仍无法区分文本线索与语义，应继续保留现有结果为固定probe的探索性测量局限，而不是推出单一机制。若以后研究行为关系，需同批绑定生成前状态与实际回答，不能与E1跨批拼接。
