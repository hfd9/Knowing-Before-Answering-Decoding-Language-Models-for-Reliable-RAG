## 事后字段纠正

在查看冻结结果后，按照作者参照将上述两组的规则和范围出处互换纠正，保持求值器不变；对缺失的 14 个比较符及条件选择重新运行模型，另外复用 37 个对应前向。**36/36** 严格通过，每个字段、动作、分支与证据均匹配作者参照。它说明所见故障可以通过联合纠正出处恢复，但这是已暴露材料上的干预结果，并非冻结候选在新规则上的成绩。[干预脚本](intervention.py) · [干预逐格结果](intervention-results.json) · [新增前向原始包](intervention-raw.zip)

本研究为小规模工程诊断，使用知情作者参照和作者构造的范围、干扰与案情，尚无独立法律复核；原规则仅支持题目中限定的窄判断。独立多规则验证和真实问法稳定输出尚未完成，论文主实验未启动。旧十题暂停，380 底题正文封存。

## 后续停止点

下一步先在已经暴露的材料上开发规则段与范围段的区分和证据一致性核验，对同一段获两个角色高分的情况保留冲突、避免凭总分强行绑定；需同时回归等于、略高、略低门槛、同答／异答、明确日期及证据位置变动。修订候选及验收口径先冻结，再用整条未参与开发的新规则留出，不能把本次事后 36/36 当留出。另需独立法律复核真实场景、核实数据使用条款，并先解决韩文接口输出与证据缺失；这些条件未闭合前不扩大为论文主实验。
