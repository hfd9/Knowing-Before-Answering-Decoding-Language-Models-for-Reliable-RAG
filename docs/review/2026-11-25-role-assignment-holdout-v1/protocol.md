# 联合版本角色定位的整条规则留出

沿用开发候选，对含两个日期和一个美元金额的候选段枚举不重叠版本对，结合四个角色的模型分数选择最高分。没有可用组合或分数并列则未解决。范围与字段抽取、确定性求值器沿用第四版。两条规则的原 48 格及同形干扰 12 格离线复用均恢复，四种重新运行模型的标签排列共 24 格通过。该开发结果及候选边界以独立材料为准。[开发协议](../2026-11-25-role-assignment-dev-v1/protocol.md) · [开发结果](../2026-11-25-role-assignment-dev-v1/live-results.json)

先冻结本协议和实现，再选取至少一条整条未见规则。每条规则包含同答与异答两个缺日期格及各自明确两个日期的对照。原题之外，范围段同时加入无关金额和两个覆盖日期，时间区间有一类覆盖两个规则版本，有一类与版本互不重叠。两类分别运行，不应以变体数量取代独立规则数。按固定题面与作者参照评分。当前候选、此前形状筛选候选和强直接共用同一模型、证据、事实及范围陈述。此前候选通过时重用相同的范围前向，若候选版本数不是两个则未解决。强直接沿用上一批的 160 token 贪心接口。模型输出、字段和各候选分数全部封存。

重点报告出处绑定正确、严格有据结果、逐日结论与引文、无谓追问、异答错误唯一、未解决；报告三个日期相关的干扰组和规则数。人工核准字段验证材料参照。出现不重叠的无关金额日期干扰时，要核查程序是否选出错误的版本来源。
