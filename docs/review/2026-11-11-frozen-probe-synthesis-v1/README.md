# 冻结 probe 的证据状态测量：已有结果与研究决定

日期：2026-11-11，Asia/Shanghai。本文只综合既有项目产物，不新增评分、样本、模型前向或拟合。整理者已见材料、模型输出、probe读出和历史判断；这里是探索性研究结论，不是独立验证报告。

## 结论与适用范围

对于本项目的 Qwen2.5-3B-Instruct、自由回答 P0 chat 输入、末提示 token、零基 L28、原标准化线性分类器及原 sigmoid 校准后的三类别 argmax，**已有探索材料不足以支持将冻结 probe 当作可靠的充分／不足／冲突语义测量，也不足以支持“模型已可靠检测不足却没有行动”的主张**。同时，一些受控编辑伴随连续分数按预期方向变化；固定读出不足以可靠分类，不证明隐藏状态不存在相关信息，也不能确定读出由语义还是构造痕迹驱动。

该结论针对指定模型、输入、probe 和已见材料，不反驳其他模型或原论文整体结果。原 chat L28 发布构造类别诊断为 233/300（77.67%）；常见的 80.67% 是另一 L24 分类提示路由器结果，两者不应混用。发布构造类别的历史诊断不等于新分布上的独立语义准确率。配置、来源与近邻见[研究决定](../2026-11-09-probe-research-decision-v1/README.md)。

## E1 行为结果单列

[E1 用户版](../2026-11-09-e1-results-assessment/README.md)是 12 个虚构场景 × S/I0/IU/CT 的 48 条回答；评分者已见历史与条件，v2 对 4 条先答后称不确定的最终立场保守改为 unknown，旧版保留。I0 和 IU 各 12 条的狭义目标字段冲突断言 E 均为 0 yes／12 no／0 unknown；J=W 且 E 亦均为 no。W 分别为 3 yes／5 no／4 unknown 和 5 yes／4 no／3 unknown。该批未观察到预定狭义事件，并不证明条件等效、总体安全或所有解释正确。

E1 协议未采隐藏状态，在现场运行和所检索的元数据范围内未找到可绑定的同批 probe；这不证明其他位置不存在未登记产物，也不能把另一批绑定48当作 E1。同批 probe—行为关系因此未被测量，不能从 E1 证明模型内部检测到不足或解释其因果机制。

## 复验与证据边界

上述数值摘自已有报告而非本轮新分析。历史材料分别记录了来源哈希、输入和 token 连接、手算读出、配对复算及行为引文重放。等 token 新运行的 13 条记录与 attempt 齐全，单条桥接和读出复算一致；未留完整终端日志，因此不能独立认证设备独占和全部运行时来源。CLI 连接严格匹配 52 输入及特征；技术匹配不认证语义和评审独立性。E1 引文与来源重放支持评分可追溯，不使知情评分变成独立金标准。

不要将连续概率当作新分布上已验证的语义置信度；不要把本批选例中的行为比例或未知数清除后结果推广至自然任务。文献对照是定向而非穷尽；KBA 已有同题三状态及提示稳健性，其他近邻已有配对和改写控制。现有组合差异尚未证明新颖，详见[逐篇对照](../2026-11-09-probe-research-decision-v1/README.md)。
