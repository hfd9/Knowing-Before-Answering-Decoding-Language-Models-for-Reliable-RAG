| 纠正字段 | 正确动作 /6 | 正确逐日结论 /10 | 逐日证据符合参照 /10 | 严格通过 /6 | 未恢复原因 |

枚举了六格各自错误字段的 **1,792** 个替换子集，每格只有一个最小严格恢复组合。“全部证据”含比较规则 ID、范围证据列表、案情 ID 和两个年度 ID 五个独立输入项。即使 A3 的旧版不参与答复，冻结解析器仍要求两份完整的版本记录。G3、A3 的输入范围起点仍判错，实际已知日期让求值只取新日，所以动作和逐版评分能通过。A1、A2 没有明确日期，范围起点错误会产生多日的 2024 年分支，冻结的六格包装层会拦截该分支，底层求值器支持一般区间。最小纠正表示在这六条回放和冻结接口上足以恢复输出，完整字段准确率仍应单独检查。
