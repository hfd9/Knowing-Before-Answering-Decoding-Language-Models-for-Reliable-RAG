## 目标和固定设计

[上一轮](../2026-11-15-query-determinacy-prompt-control-results-v1/README.md)在6个旧底题上发现提示敏感性；为了继续诊断，另设8个新虚构底题，其中4个数值、4个类别代码。代码题明确每个记录仅为单个原子标签，不同代码不包含或同义，且问题用显式集合或等号；这是针对旧类别“属于A或B”歧义的修订，仍非独立语义审核。新材料使用与旧题相同的题型、可判定性结构和提示家族，并由见过旧结果的助手设计，因此不能把结果称为严格未暴露确认或估计自然数据性能。

每底题3问题（两世界同为是、同为否、不同）×4条件（单世界甲/乙、双来源/双候选）×2提示（简短回答/逐值判断）=24输入；8底题共192输入。两个双世界表达使用同一对可能值但措辞不同；两提示分别为简短作答和先逐值再给结论，后者改变输出要求。每族显示的两个值顺序各2/2；数值分歧问题在存储的world_a为是/否各2/2，而代码分歧问题的world_a均为是，显示顺序仍各2/2。后者是设计限制，不能称world_a方向完全平衡；实验不证明提示差异来自某个词。假设明确恰有两世界且不提供优先级。

参考由题面确定性规则计算并由[独立解析器](../../../scripts/query_determinacy_fresh_audit.py)从实际呈现内容重算。当前助手撰写两套代码，代码间一致不认证独立语义；评分沿用[合同](../2026-11-15-query-determinacy-development-v1/CONTRACT.md)：最终Y/N/U、矛盾或含混X、技术缺失T分开；逐值提示的明确条件映射错误不能计作正确条件回答；目标正确不等于解释正确。每种提示与双世界表述分别报告答案一致、分歧及单世界三个计划分母，逐题配对两提示并单列未知和失败；按4数值+4类别底题解释，同底题多输出不作为独立样本。仅描述，不做确认性显著性或泛化声称。
