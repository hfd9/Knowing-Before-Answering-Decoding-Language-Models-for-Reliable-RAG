2026-11-09，Asia/Shanghai。依据[已封存的用户版结果](../2026-11-07-e1-user-results-v1/README.md)进行只读整理与文件核查，没有重跑48条、重新评分或新增前向。原评分者是已见研究历史、条件和回答的助手；先封存主张，再连接映射，但这不构成独立盲评或金标准。v2在查看初版后对4条先作答、后称不能确定的最终立场改为unknown，原判和v1保留。结果是12个同模板虚构场景上的探索结果，不是自然RAG发生率、世界真值认证或机制证明。

## 材料与端点

每场景有目标单位T、另一单位O、独立字段f/g及不同值a/b/c，五文档包含同一快照、每单位每字段单值、记录可能分歧及无优先级的规则。原P0提示含问题相关冲突指示；这是结果解释的一部分。下表是[生成前材料定义](../2026-11-06-explanation-scope-materials-v2/README.md)，S指记录相对支持。

| 条件 | 实际记录结构 | 所问T.f的状态 |
| --- | --- | --- |
| S | T.f=a、O.f=b、T.g=c | 记录支持a；不认证世界真值。 |
| I0 | O.f=a、O.g=b、T.g=c | T.f缺记录；其他记录兼容。 |
| IU | O.f=a、O.f=b、T.g=c | T.f仍缺记录；另一单位同一字段两值冲突。 |
| CT | T.f=a、T.f=b、T.g=c | 目标同一字段两值冲突，无记录优先级。 |

12个I0/IU对的问题及四个非编辑槽相同；另一槽将字段f/g互换，已验证长度和token多重集相同，但token位置及语义不同，不能排除其他输入机制。四条首场景smoke计入48。详见[协议](../../explanation_scope_e1_protocol_20261107.md)和[评分合同](../../explanation_scope_scoring_contract.md)。

W是有据保留目标未知且无未撤回具体值；E是明确无据断言**目标字段自身**存在互斥证据；J=W且E，任一为no则J=no，均yes才yes，其他为unknown。S的有据目标回答不要求其全部解释正确；CT的目标冲突识别和无消解选边可以同时出现。公共端点另记未撤回目标值、实质解释、过宽否认已有信息，以及整段解释支持。整段解释不是三值端点：有反证优先contradicted，其次unsupported、ambiguous、supported；无实质解释为not_applicable。

## 与已有迁移研究合看后的决定

保留E1为预定狭义目标事件在本批未观察到yes的有限负结果，暂缓把这条特定解释行为作为下一轮主线。其他控制异常保留为事后线索，不自动扩样追错。E1本身不能裁决探针问题。

下一项**研究问题优先考虑测量有效性**：冻结probe在证据状态改变、表达/字段位置和材料构造改变时，到底能否稳定跟踪经过可追溯语义审核的状态。现有证据同时支持保留两种可能，而非断言只有一种：

- [既有240变体迁移](../../semantic_transfer_conclusions.md)中，S→I不足概率平均上升18.08个百分点、53/60上升；S→C冲突概率平均上升20.84个百分点、54/60上升。它们显示对构造编辑的方向性响应，编辑同时改变多个表面特征，不能单独区分语义与构造痕迹。
- [另一批绑定48的事后probe](../../records/2026-10-21-behavior-binding-probe-results.md)中，I的24条行为上均未给目标代码，旧probe却全部判answer；S→I不足概率24/24上升。连续分数有响应与冻结三分类失败同时存在，不能凭argmax失败断言隐藏状态完全无信息，也不能凭概率响应认定已经可靠测量语义。
- [校准诊断](../../records/2026-10-21-probe-calibration-diagnostic.md)显示该绑定批次I在校准前后均为answer，校准使部分S变成conflict；撤销校准不能修复缺证分类。原始读出与校准是可区分环节，但这不是唯一根因。
- [一次固定重训](../../records/2026-10-21-semantic-transfer-exploratory-retrain.md)在已见的12个评估来源底题上由57/96到62/96（作者参照），对应配对重采样区间跨0，同时充分→冲突误报减少、冲突召回18/24降至11/24。该批标签和评分有历史暴露，不是独立准确率；评估已见、不恢复前瞻性，也不重置原一次拟合预算。

因此现有证据**尚不能判定probe读到的是语义状态还是构造痕迹，也不能证明两者互斥**。如果未来另立研究，应先明确可审计语义参照、底题级隔离、固定输入模板与探针和测量指标、成对扰动及表面特征控制、已见数据与真正未见数据的用途，并预先规定比较与停止规则；先判断是否已有合适缓存可回答，再单独决定是否需要新协议与用户执行GPU。此处是研究决策要求，不是已批准的运行计划。当前不追加采集、调层、阈值搜索、重训或patching；380个保留底题继续封存。
