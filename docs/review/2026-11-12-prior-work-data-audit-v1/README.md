## 结论

**Wang等的先例比“也研究冲突识别”更接近：它已经在同一上下文上分别提问冲突和非冲突片段。** 其Task 2要求判断该上下文与模型自身知识在问题答案上是否冲突，属于上下文—参数知识的显式二分类；本候选是给出两个外部来源时，对有唯一目标答案的自然回答及目标冲突误归属做评估。两者有可核查的任务差异，但不能据此自动证明论文创新或确认实验可行。原评分字段候选保留，不把任务差异升级为已验证贡献。

## 评分候选的边界复核

已形成的[评分候选](../2026-11-12-target-conflict-rubric-feasibility-v1/README.md)把目标答案A、目标冲突归属T、非目标冲突说明O和其他主张X分开，未审、技术失败及unknown分离。其联合U只用于参考确定、目标唯一且任务只要求回答目标的S0/SO；CT不能套用“声称目标冲突即错误”。当指令要求披露所有冲突时，遗漏其他对象冲突的可接受性会改变，应另立用途而非沿用U。这些规则是可复核的候选，不是经过评审的语义金标准，也没有实际新评分。

另一个须预先裁定的边界：`grounded_correct`表达的是答案被给定文档支持，不能证明模型生成时确实利用了文档；要测来源使用需另立来源干预/行为证据。`T=no`表示没有未撤回的明确目标冲突声称，不保证全文其它事实都正确，因此X独立保留。
