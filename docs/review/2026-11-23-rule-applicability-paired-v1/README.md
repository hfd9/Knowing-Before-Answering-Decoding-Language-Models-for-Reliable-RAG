## 材料和参照

每个版本同时给出 W1 和 W2 两份地位相同、类别判断相冲突的来源。R1 与 R2 是两类的默认条款，结论相反。R3 在规定方向的授权成立时覆盖其中一条默认规则。F1 是两种解释都适用的共同授权登记，并完整列出唯一一笔有效授权。先在两种来源假设下各自判断适用规则与准入结论，再将同答记为唯一 Y 或 N，将确定的异答记为 U。至少一边无法判定时记为 X。

每个底题有两个授权方向和两种等义表述，共四个版本。角色对照只互换 F1 中的两个组名。措辞对照保持授权的主体、客体、条款优先、适用性和答案，同时改变 R3 和 F1 的表述。每次作答只看到一个版本。开发与留出按底题及规则和事实的措辞族切分。每个留出措辞族各有一题唯一准入和一题唯一不准入，两个底题分别覆盖 W1、W2 的默认规则。使用虚构题面，参照由知情作者从文本逐世界核对。

## 比较口径

- **有向解析器**从原文抽取 R3 所需的授权方向、优先关系、例外结论和 F1 的实际授权方向，然后调用程序求值。
- **强直接提示**读取完全相同的六条原文，报告同一组结构字段、逐世界适用性、决定性规则、结论和证据 ID，再输出合并标签。
- **模型抽取后程序求值**从原文提取与有向解析器相同的结构字段，调用同一求值器。W1/W2 的类别与 R1/R2 的固定句式由两条结构化路线共用的程序读取。

严格通过要求授权方向、规则结构、两世界的适用性、决定性规则、结论和合并标签均正确，并逐世界精确命中预定证据 ID 集合。每个底题的四个版本都通过才算一次成功。另保留两种配对的严格结果、可比较版本的非预期措辞翻转、角色反转未产生预期转换，以及参照为 U 时输出 Y 或 N 的逐项风险。结构或输出格式失效单列。对每条模型路线分别比较，需要净增至少两个完整底题、两个留出措辞族各有至少一个获益底题，且异答题上没有新增的无依据唯一答案。技术性无效输出会使相应路线的去留判断不确定。此口径用于四题诊断的去留判断，统计外推另需材料。
