- **一侧支持句式，8 条。** 全量与选择性分别为 1/8、2/8 严格正确且有据，收益集中在 M02。选择性少用 696 token（4,056 → 3,360，少 17.2%），逻辑调用均为 8。错误唯一答案 2 → 0，其中 M02-1-reverse 恢复为有据 U，M02-2-reverse 变为无效输出。选择性在另外三个混合版本也输出裸 `null`，无效共 4/8。把边界例计入后，选择性总 token 少 996（少 7.3%），无效 6/27 均为裸 `null`。这些节省包含未产出可计分结果的短输出。
- **边界例，3 条。** 冻结程序三条均正确且有据为 X，其余路线严格通过均为 0。强直接有一条合并标签为正确 X，但逐世界证据不匹配。强直接全部 27 条可计分，合并标签符合 12/27，逐世界证据集合符合 14/54，严格有据仍为 0。全量抽取与选择性路线的完整结构精确匹配分别为 1/27、2/27。

## F1 方向核验与错误归因

复用同一批抽取记录开关核验。按可计分的抽取，原文方向可核验 5 条，其中 3 条确认、2 条识别反转。另 21 条原文核验器未覆盖，1 条抽取无效。开启后 M02-1-reverse 从错误唯一 Y 转为 X，M02-1-match 从错误 U 转为 X。净拦 1/5 个错误唯一答案，新增 2 个未解决。严格有据条数 3 → 3，未观察到严格正确被置为未解决，也没有挽回成严格正确。双侧新措辞中的三个错误唯一答案全部保留。

按已封存作者参照核查五个全量错误唯一答案，C03-1-reverse 与 M02-1-reverse 都是 R3 精确、F1 方向反转。事后仅把实际生成的 F1 换为参照，固定同一求值器，两条均由 Y 恢复为严格有据 U。其余三条单改 F1 后仍输出 Y，三条均有 R3 字段失配。作者参照下的 F1 反转在两个底题、两个措辞族重现，原文核验只确认并拦下其中一个底题，未达到预先固定的跨族原文核验拦截判据。上述事后字段替换仅用于归因。

## 去留与核验

当前方法保留为受控工程诊断，暂停以选择性补字段为主贡献的 C 类候选稿及 B 类扩展。同族两个版本的局部改善和混合对照的 token 节省均有记录。双侧新措辞完整底题的净增为 0，选择性路线较冻结程序新增 3 个错误唯一答案，未满足留出门槛。角色反转失效有可重放证据，独立语义参照、跨族实用核验和相对近邻的研究增量仍未成立。选题退回可行性判断，保留两侧字段输入质量这一工程问题。原剩余十题继续暂停。

材料构造和 32 格诊断可重放。19 项既有相关 CPU 测试与新增定向合成联检通过。留出原始 ZIP 解包后重放真实提示和生成 token，结果逐字节相同。另用独立聚合脚本复算 27 条、65 次实际生成和全部路线的逻辑成本、分组指标与核验转移。V1 和 V2 的源指纹分别在提交 `0392605` 和 `afa96f2` 核对。无 GPU、拟合或封存正文访问。
