# 新受控探索：从冻结probe走到一批可解释的新结果

日期：2026-11-11，Asia/Shanghai。状态：**规划完成，材料、代码和采集尚未开始**。用户选择有限受控探索路径，要求规划后面做什么；该计划是探索性工作安排，不是旧v1/E1-r1放行或独立确认协议。

## 要回答什么，结果有什么用

在少量新原创虚构场景中，对**同一目标问题**分别给出充分、缺证、目标冲突的五文档，并为每种状态准备两个表达。固定旧 Qwen2.5-3B-Instruct、P0 chat 模板、末提示token、零基L28及原scaler/线性分类器/校准器和三分类规则，检查：

1. **状态变化：**同一场景、同一表达中，S→I与S→C时，类别是否按作者参照变化？原始三类概率变化如何？
2. **表达变化：**同一场景、同一状态中，A→B是否保持类别？若稳定，是否两端都符合参照？

这会补充一批新构造场景上的实际冻结读出，而不重复已有六题等token对照或 E1。作者及当前助手已知研究历史；这批材料与评分属于**知情开发探索**，不会产生独立确认准确率，不证明自然RAG泛化、隐藏状态无信息或模型故意不遵循。新场景也不能保证不与模型预训练相似。

原S/I/C每版均为完整五文档输入；尽量固定同题问题与不涉及目标关系的槽位。对产生冲突或缺证所需的改动如无法限制为单槽，必须记录其余变化和解释限制，不能为了看起来干净而隐藏修改。A/B不要求机械等token：记录真实token数和文档槽，不能将差异归因单个词或语义因素。材料使用权和来源须逐项记录；原创叙述本身不自动证明权利或无重叠。

## 逐步推进与交付物

1. **准备材料和作者参照（CPU）。** 建立独立的新材料文件与新run目录，保存场景、问题、五槽、S/I/C、A/B及具体编辑记录。对36条逐项形成作者侧引用、目标实体/字段/条件、S唯一支持、I缺证依据、C互斥证据和表达关系判断；明确由有历史暴露的助手完成，保留unknown。保留逐题原始材料和哈希，不混入正式标签或旧确认集。检查已获许可的旧材料重复线索，380正文不读，未覆盖的碰撞与预训练暴露保留unknown。
2. **审核与固定。** 用独立于构造代码的CPU检查重建36条/180槽、同底题共用内容、计划差异和引用。逐条知情语义复核必须先于新probe输出封存；若无法确认某个状态或A/B关系，记unknown并停止该批后续采集，先记录原因，不能事后选出有利子集或把unknown改为通过。若实际出现额外复评，记录角色、材料可见范围和暴露，不因新会话或匿名ID称其独立。评审与固定只针对本探索，不改变旧门禁。
3. **准备新的用户执行路径。** 基于已有[等token运行器](../../../scripts/probe_neutral_length_control_20261109.py)和[技术核验](../../../scripts/verify_probe_neutral_length_control_20261109.py)审查哪些部分可复用；新材料、顺序、依赖或代码变化须新run目录和指纹。实现时明确只做decoder prefill与冻结读出，绑定问题/文档、完整提示/token、模型文件、原probe、层及版本。先用临时合成数据检查完整性、损坏、未提交attempt及桥接失败停机，不把合成测试当真实GPU验证。不得改动已完成run或通过修改原指纹绕过门禁。
4. **由用户运行GPU。** 仅在材料、知情参照、代码、锁、设备预检、时间估算及失败处理完成并完成适用的新探索路径审查后，提供具体命令；用户按既有[GPU执行约定](../../records/2026-11-09-gpu-user-execution-preference.md)运行。桥接候选沿用先前门槛：36层最大相对L2≤0.02、probe概率最大绝对差≤0.01；实际适用性及来源须在新锁中核实，失败即停止并保留产物。遇到未提交attempt、损坏、异常或中断，停止并保留现场，不自动重试或补零。当前没有命令、没有真实run，也没有可靠的端到端耗时；准备完成时给出估算及其依据，不将旧13条的前向秒数当总耗时。
5. **核验与分析。** 用户完成或报错后先核对计划、尝试、输入/token哈希、桥接、特征、冻结probe及输出完整性，再重算类别和概率；不以自动摘要替代逐项来源。完整时分别报告18个A/B状态对、12个S→I与12个S→C关系对（每类关系对仅来自6底题的两表达），以及单元混淆和逐底题证据。概率变化只作描述，不以36个输入假装36个独立底题；技术失败、unknown、未审和已确认的语义争议分开列出。

## 结果如何改变后续决定

- **若多数底题的同状态A/B变化已经改变类别，或状态改变时持续与作者参照不符：**记录发生在哪些具体材料及方向，保留为该配置在新受控材料上的探索性失配；不追加措辞网格、换阈值或声称普遍失效。
- **若两表达类别稳定但都不符参照：**报告稳定错误；不能把稳定性描述成语义可靠。
- **若状态区分及两表达都符合知情参照：**记录支持这些新场景上可读出的证据，与旧失败并列；不以6题追认90%可靠性、改变旧结果或宣称问题已解决。
- **若参照无法形成、桥接失败或采集不完整：**保留失败/unknown和发生阶段，不计算完整结果、不自动补采；先检查材料或技术原因，只有另行明确的新版本才可处理。任何情形下，是否开展更大研究都要重新评估其可审计参照、范围、预算和相对近邻的价值。

这些分支是预先约束的解释规则，不是按6题设置的显著性检验或自动放行门槛。每个最终报告必须明确6底题、构造与评审暴露、每类分母和所有失败。
