# 先定位证据的第二版开发与整条规则留出协议

沿用首版的原六格、12 个门槛两侧及等号边界、2 个范围控制，参照与严格通过口径保持一致。首版两规则均把比较原文同时选作范围出处。本版将四个原文候选直接列在定位问题的选项中，再取四角色一对一分配的最高总模型分数。四段材料各承担一个角色是本研究题面的输入约定。证据 ID 本身无角色含义。比较符由模型在已定位的规则摘录上选出。范围判断在已定位的范围证据及 F1 上单独完成，明确区分范围被证实、不满足及资料不足。日期、美元整数、事实来源和事件匹配用程序按各角色读取，底层求值器沿用原实现。[首版协议](../2026-11-25-date-evidence-first-v1/protocol.md) · [首版结果](../2026-11-25-date-evidence-first-v1/README.md)

开发实际通过 20/20 后，封存开发结果、原始选择记录、模型环境、实现、协议和材料哈希。仅在冻结文件已产生后查找一条整条留出的新规则。新规则仍使用四个可区分的证据段、一个事实段、原求值器支持的比较符、整美元数、两个候选日期和两段带起止边界的有效版本。单独记录任何来源规范化或日期区间编排。预定六格为同答和异答各一个缺日期案情，以及两种案情各补旧日和新日的四个控制。严格指标要求所有字段、分支、引文和动作一致，另列同答无谓追问、异答错误唯一、明确日期有据。六格共用同一法律规则，阶段结果用于判断是否向多个条款扩展。

模型不读人工参照。只采 CPU 下一 token 选择分数，保留失败和完整归档。若留出仍卡在抽取，定位失败字段，保留结果，后续方法调整或选材调整需另开开发版本与新的未见规则。
