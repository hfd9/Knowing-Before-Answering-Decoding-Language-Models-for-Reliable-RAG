## 评分草案 v0：先标注，再汇总

每个输入记录规则 ID、成对 ID、可行日期区间、证据覆盖、实际工具、问题允许的回答方式及参照来源。人工参照注明知情程度；边界和适用范围存在争议时标 unknown，并保留原因。评审先看题面、回答与证据，不告知路线身份；评估参照的独立性另行记录。不同版本段的覆盖、适用范围和例外必须可以核对。

逐项标注为 yes / no / unknown / not-applicable，附原文引用及理由：

1. **能否唯一确定**：是否明确判断在题目所限日期内同答／异答；回答只给正确唯一答案而不解释跨版本时，唯一判断标 unknown，不能凭正确数值推测推理过程。完整且正确的逐版分支可支持同答／异答判断；单纯问日期不证明知道异答。
2. **回复实质**：无条件最终结论、完整条件分支、部分分支、追问、证据不足／请求检索、其他或未解决；可以多标签，并核对是否自相矛盾。无条件给出唯一结果且随后又写互相冲突的分支，标为冲突，不自动按有利部分评分。
3. **结论与证据**：逐日期范围或版本标结论对错，逐项评估引用是否对应版本并支持比较规则、阈值、适用范围与题目事实；未提供引用、引用不存在、引用不充分和不可判断分开。旧严格证据 ID 匹配与语义充分性分别报，不把一种替代另一种。
4. **可用性**：同答且证据完整时，正确有据的直接结论或完整正确的逐版分支有效；异答且允许条件回答时，完整有据的条件回答有效。异答要求唯一结论时，问能确定相关事件日期的问题可作为当前轮有效澄清；若允许条件回答但系统只问日期，也单列为有效澄清并计交互成本，不能称已提供最终答案。空泛追问或索取已知日期无效。缺有效版本且能检索时看是否实际检索；封闭材料标证据不足，不假设工具存在。
5. **过程与失败**：原始输出、格式错误、EOS／截断、调用失败、引用支持、覆盖缺失、角色错绑和规则应用错误分别记录；失败原因不能判定时记 unknown。不得仅凭最终错误推断绑定错误。

配对两个主指标分别统计（主要分母为所有已验收计划对；unknown／无效单列且不计正确，同时给出可判定子集比例）：

- **唯一结论判断成对正确**：同答、异答两题都满足第 1 项的正确判断。仅直接给出正确结果不自动证明知道答案跨版本不变。
- **回复有效性成对正确**：同答和异答两题按对应任务设定均满足第 4 项。追问式成功与无需进一步交互的完整答案分别报告，补日期后正确率的分母是实际收到有效追问及预设日期回复的轨迹，同时报所有异答题的轨迹覆盖。

错误唯一答案率、无谓追问率、逐版正确／有据率、引用充分性、格式失败、覆盖率与消耗分别给分子和完整分母；按整条规则分组显示。路线比较中无效及失败不得从主分母悄悄删除。对仅输出动作的冻结求值器，如确无显式理由或引文则按现有输出评分，不自动补全；若为满足新接口需写适配器，先说明适配只做无损呈现并冻结，不能修改求值结果。

## 合成评分演练：仅检查手册逻辑

设日期只可能为 D1 或 D2，版本证据完整；金额 A 在两日均为 Y，金额 B 在 D1 为 Y、D2 为 N。下表假设所说结论均有正确充分引用。

| 题型 | 回答 | 唯一判断 | 当前轮可用性 | 备注 |
| --- | --- | --- | --- | --- |
| A | “两版均为 Y，因此无需日期，答案 Y。” | 正确 | 有效 | 无需追问。 |
| A | “Y。” | unknown | 有效 | 数值正确不能证明跨版本判断；证据仍须独立评估。 |
| A | “请提供日期。” | unknown | 无效 | 记无谓追问。 |
| B | “D1 为 Y，D2 为 N，取决于日期。” | 正确 | 接受条件回答时有效 | 不记错误唯一答案。 |
| B | “需要哪一天发生？” | unknown | 有效澄清 | 必须补日期后另评最终答案；不能推断系统已比较两版。 |
| B | “Y。” | 错误／未知需看是否声称唯一 | 无效 | 无条件唯一结论记错误唯一风险；未说明理由时唯一判断本身记 unknown。 |
| B | “答案 Y；D1 为 Y，D2 为 N。” | 冲突 | 无效或 unknown 待复核 | 不能忽略无条件结论，只按条件段给满分。 |

其中“唯一判断”是可观察的显式判断或由完整正确逐版结论蕴含的判断；不会因为单次答案正确就推断模型内部过程。上表是手工思想实验，不是系统输出测试，也不证明评分者一致性。

## 已暴露真实输出的知情演练

[旧归档](../2026-11-25-role-assignment-holdout-v1/raw.zip)中一对日期缺失题的原始直接输出完全相同：动作 `ANSWER_N`，同时给出旧日 N、新日 Y，未追问。

| 已暴露案例 | 作者参照逐版 | 知情演练判断 |
| --- | --- | --- |
| `ssa-S0` | Y、Y | 无条件动作 N 与参照不符，旧日分支 N 与参照不符；输出自身的两个分支有差异，不能给同答唯一性判断记正确。动作和分支又不一致，回复无效。 |
| `ssa-D0` | Y、N | 两个分支分别与作者参照相反；无条件给出 N，不能把其当作正确完整的条件式回复。无条件结果在缺日期时构成唯一答案风险；显式给出两种分支说明它在文本中表达版本有差异，但不能据此说分支正确或回复有效。 |

这里采用已知作者参照，保留依据及暴露，不是独立裁定；表内只评可直接比较的动作和结果，证据语义充分性尚未逐条核验。两个例子也不能代表整批表现。该演练揭示一个评分细节：是否识别版本异答与逐版结论方向正确是不同字段，应分别标注；输出自相矛盾时不能仅取有利的一段。
