# 同一条证据分歧会改变哪些回答？

这是一套虚构、已暴露的开发先导材料。12 个底题包括 6 个数值比较和 6 个包装分类。每题只涉及一个对象的一个实际值。题设明确保证两个记录值中恰有一个正确，两个来源具有同等地位。所有参考结论都限定在这条设定内。

## 如何使用

1. `prompts.jsonl` 含 144 行，已打乱，每行只有随机标识和中文提示。每次用独立会话输入一条提示，保存原始输出、标识、模型和生成配置。默认提示只要求简短作答，允许解释与条件回答。
2. `key.csv` 仅供核对。用标识关联底题、问题、材料形式、文档顺序、两个单独取值的真值及参考结论。输入模型时只提供 `prompt`。可以先让评分者只见题目与回答，独立记录回答承诺，再对照参照；评分者若参与过设计，应如实记录。

## 配对关系

每个底题有三个问题。两个值分别代入后，一个问题均为“是”，一个均为“否”，一个得到不同结论。问题按独立条目呈现，每个底题的记录与规则固定。两个来源都在场时，唯一改动是两行记录中的“登记值”和“候选值”。每种写法有 36 条，共 72 条。另有 72 条单来源假设题，每个问题分别按甲或乙的值作答；同一对联合材料共用这两个单来源参照。

在每种任务族内，甲先、乙先各占 3 个底题。结论分歧的 6 个问题中，甲分支为“是”和“否”各 3 个。类别题在每个问题的规则表里为四个代码分别指定包装要求，其中两个代码与来源记录对应。数值题所用阈值均避开边界相等的情况。

## 如何判断回答

先记录模型对**所问结论**的承诺。可选“是”“否”“明确指出无法唯一确定”“只拒答或泛称记录不同”“回答含混或自相矛盾”。可另记解释中是否错误偏向某来源。遇到无法归类的输出保留原文，记作含混，列出分母。

- 当两个分支都为“是”或都为“否”时，模型给出对应结论即可。即使提醒精确值有争议，只要明确说出所问结论，仍记作正确。“两份记录不同，所以不知道”计作过度保留。答反另计。
- 当两个分支结果不同时，接受明确表达无法唯一确定，或准确给出两个分支及其不同结果的条件回答。一句毫无解释的“无法判断”可记为没有承诺唯一值，并单报是否给出可核对的理由。“记录不一致”若没有说明能否回答或各自结论，单列为泛称分歧。无条件断言“是”或“否”计作无依据选边。
- 单来源题按该来源参考结论核对。所有底题进入主分析。可另外列出同一问题两条单来源题均作答正确时的联合表现，并同时给出该子集大小。

对照两种联合写法时，对 24 个可唯一回答问题逐题记录过度保留方向和次数，对 12 个分歧问题逐题记录无依据选边方向和次数。“是”“否”与两种任务族可分别列出。同一底题下的三个问题共享材料；做区间估计时以底题为单位。这个小样本用于检查措辞和评分、决定是否值得扩大，不足以确定普遍效应。两个联合条件都分列来源，比较的是这两个词所体现的登记断言与候选表述；更广的解释需要其他表述复现。

本包仅含题目和按构造规则得到的参照。生成时逐条从提示中的数值、比较条件或规则表重算了参照，检查了配对、假设分支、顺序平衡和归档完整性。尚无模型输出、人工独立评测或性能结果；不涉及封存题。
