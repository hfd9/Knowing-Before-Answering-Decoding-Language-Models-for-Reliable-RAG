## 2. 已有48材料的语义验收：知情部分

以[48条结构表](review/2026-11-07-explanation-scope-audit/item-structure.csv)、原文及作者解释为依据，知情助手确认全部目标/字段/记录与四条件结构相符；目标及其他单位同字段引用文本与槽位匹配。I0/IU的12对各改一个文档槽，既有独立解析/有限域见证和真实tokenizer复验支持约定内的构造；本轮重放逐项结构表与保存文件相同。它们是输入证据，不产生独立语义标签。

实际作答语义中要锁定三点：

1. S仅表示一条提供记录支持某目标值；记录可能出错时它不证明世界真值。最终报告S端点时必须说明是按现有合同的**记录相对支持**评分，而非声称真实值获认证。
2. I0/IU的目标缺口与其他单位冲突分开。IU不存在同时满足全部冲突赋值的世界；已有局部修复见证说明在各保留分支下目标仍有多个可能值，但不证明所有现实解释都如此。
3. E只针对明确无据的目标字段或目标答案冲突断言；只准确说明另一单位冲突为no，指代不清为unknown，没有解释另计。`W`、`E`和整段支持均保留各自结论，不从一个端点推另一个。

这些是已知材料条件下的助手判断；原草案要求的独立性审计及符合最终协议的关键语义审核不能由此冒称完成。未见新48回答，未给输出评分。
